# 여러 학생 지도 제안 직접 마무리 (2026-09-13)

사용자의 직접 마무리 지시에 따라 root가 G007 독립 검토의 재현 결함을 수정했다. 앞선 독립 리뷰의 BLOCK / REQUEST CHANGES를 승인으로 바꾸어 인용하지 않는다. 이후 판정은 root의 코드·계약 점검과 실제 회귀 결과다.

## 수정 및 확인

- apply/undo는 읽기 예외가 반복되어도 복구 장벽을 유지한다. recovery는 장부를 읽기 전부터 장벽을 세우고 확인 후에만 푼다. 부분 apply와 undo의 지속 읽기 실패·복구 검사가 통과했다.
- 교사 내용을 가진 장면은 목적지가 일대일로 확정될 때만 변경한다. AI 장면의 교사 이음말·근거별 해석도 보존하고, 기존 주제 연결 변경은 거부한다. AI가 작성한 메모는 AI 출처로 저장한다.
- 화면 밖 run별 실행 소유권으로 batch·개별 생성·주제 재제안을 조정한다. 재진입 복구는 현재 실행 중인 작업을 취소하지 않는다. 두 실행기와 개별 생성의 중첩 검사가 통과했다.
- 개별 작업 종료는 stopped를 보존한다. 중단할 attempt는 저장 갱신 안에서 확정한다. 중단 경합과 재개 검사가 통과했다.
- busy·로그인·사용량 오류는 묶음을 일시 정지하고 나머지 학생은 queued로 유지한다. 근거 없는 학생은 N명 확인 간격에서 제외한다.
- 뼈대 재선택은 주제 선택 후 그 주제의 장면만 다시 제안한다. 나머지 주제·연결·자리 미정·원본은 보존한다. 주제별 재제안 회귀 검사가 통과했다.
- 실제 전송 근거와 위치만 왕복하는 잠금 근거의 집계를 구분한다. 다른 영역 원문은 전송하지 않고 기존 위치만 잠금 번호로 보존한다. 다른 영역 근거를 가진 주제의 고정 뼈대 교체는 적용 전에 거부한다.
- 현재 TeachingClass에는 별도의 subjectId가 없고 과목별 수업반 id와 subject 표시명이 있다. 임의 식별자를 만들지 않고 classId를 사용한다. 복원 시 현재 학기를 확인한다.
