# ADR-093 · 생활기록부 화면 단순화 — 집중 보기가 기본, 보조 공간은 하나, 실행 상태는 스토어가 든다 (2026-09-08)

- 상태: 채택 · 구현·검증 완료(2026-09-08, 미커밋). ultragoal `record-workspace-simplification-20260908` S0~S5. 결과는 `docs/progress/2026-09.md` 2026-09-08 절. 실기기·실제 AI 왕복은 오너 확인 항목.
- 설계서: `docs/02-design/features/record-workspace-simplification.design.md`
- 관련: ADR-085(3차 UI — 두 곳 수정) · ADR-088(분량 조절 — 결정 7 을 구현에 맞게 이행) · ADR-092(대행 QA 10건 — 보존)

## 배경

2026-09-08 화면 검토(`docs/03-analysis/record-workspace-simplification-20260908.md`)에서 1440px 에 전용 학생 패널(320)과 쌤핀 AI(384)가
동시에 붙어 본문이 잘리고, 30명 목록의 행마다 조작이 반복되고, 근거 카드 한 장에 조작 5~7개가 항상 붙어 있는 것이 확인됐다.
설계 중 코드에서 결함 둘을 더 찾았다: 패널이 학생마다 새로 만들어져 "남은 학생 모두" 큐가 2명째에서 끊기고(P6), 분량 조절 결과가 패널 인스턴스에만 있어
학생을 잠깐 바꾸면 사라진다(P7). 오너는 같은 날 "초안 생성 대상 학생을 여러 명 직접 고르기"를 추가로 요청했다.

## 결정

1. **기본 화면은 학생별 집중 보기**(학생 목록 + 한 학생의 넓은 본문). 예전 30명 목록은 **전체 훑어보기**로 남기고 보기 선택을 `Settings.recordDraftViewMode` 에 기억한다.
   연속 편집·Ctrl+Enter 다음 학생·필터·진행률·일괄 생성·복사·내보내기는 두 보기 모두에서 된다.
2. **오른쪽 보조 공간은 하나.** `RecordDraftSidePanel` 은 [AI 초안] [근거] 두 탭이고, 눌렀을 때만 열리며 닫으면 폭이 0 이다.
   **쌤핀 AI(범용 대화)는 이 패널에 넣지 않는다**(오너 피드백 2026-09-08: 이 화면의 AI 는 초안 쓰기라 범용 대화가 같은 자리면 헷갈린다). 대신 이 화면에서는
   쌤핀 AI 도크와 초안 패널이 **둘 중 하나만** 열린다 — 도크가 열리면 패널이 닫히고, [AI ▸]·[AI 도움]·[근거 N건]은 도크를 닫는다.
   (처음 구현했던 "도크를 패널 슬롯에 포털로 그리기"는 같은 날 제거했다.)
3. **실행 상태는 화면이 아니라 스토어가 든다.** 새 `useRecordAiRunStore`(저장 안 함)가 초안 생성 큐(scope 단위)와 분량 조절 단계(학생·영역 단위)를 든다.
   패널·탭·학생을 바꿔도 실행과 결과가 살고, 결과는 **요청한 학생의 칸**으로만 간다. ADR-088 결정 7("후보를 부모 화면에")을 이렇게 이행한다.
4. **초안 생성 대상을 직접 고른다.** 학생 목록(두 보기 모두)의 체크 상자로 고르고 AI 패널의 [고른 N명]으로 실행한다. 이미 초안이 있는 학생이 섞이면 먼저 알리고,
   각 학생 미리보기에서 [바꾸기]/[뒤에 붙이기]를 고른다(손으로 쓴 글을 소리 없이 덮지 않는다).
5. **근거 카드는 겉면에 내용·출처·상태, 조작은 선택했을 때.** `AI 제외됨`·`원본과 내용이 달라요`·자동 제외 이유는 겉면 배지로 남긴다. 토글·수정·원본·삭제는 카드를 고르면 나온다(클릭·Enter/Space, Tab 접근).
   마우스 올리기만으로 나타나는 조작은 만들지 않는다.
6. **AI 패널은 설정 → 생성 중 → 결과 단계로 나눠 보인다.** 공급자·모델은 한 줄 요약 + [바꾸기]. 비교는 좁은 패널에서 위아래로. 분량 조절은 접이식 그대로.
7. **폭이 모자라면 짓누르지 않고 접는다.** 패널 열림 기준으로 본문 560px 을 못 확보하면 학생 목록을 선택기로, 그래도 모자라면 패널을 별도 보기(sheet)로. 수업 관리에서는 초안 탭 진입 시 학급 목록을 접고 나갈 때 복원한다.
8. **행이 다시 만들어질 때 미저장 글을 되살린다 — 단, 저장본보다 새로울 때만.** 부모 등록부(`liveDraftTextRef`)는 글과 **고친 시각**을 함께 들고, 저장본의 `updatedAt` 보다 새 글만 `initialLiveText` 로 넘긴다. 한도 초과로 저장이 거부된 글은 살고, 타이핑 뒤 AI [반영]으로 갱신된 저장본은 옛 글에 덮이지 않는다(리뷰에서 잡은 데이터 손실 경로).
9. **초안 큐는 영역·과목·수업반(scope)별로 따로 든다.** 한 영역의 "남은 학생 모두"가 도는 동안 다른 영역에서 시작한 실행이 그 큐를 지우지 않는다.

## ★기존 결정 수정

- **ADR-085 보강 2 §4-5** "[AI 제외] 토글은 겉에, 배지는 없앤다" → **상태 배지는 겉에, 토글은 선택했을 때.** 오너의 원 우려("여기서 켜고 끌 수 없다", "숨긴 조작은 없는 조작")는 겉면 배지 + 하단 바 일괄 토글로 대신 지킨다.
- **ADR-085 §4 "오른쪽 패널이 늘 보인다"**(암묵) → 눌렀을 때만.
- ADR-088 결정 7 은 구현이 어긋나 있던 것을 스토어로 이행(결정 자체는 유지).
