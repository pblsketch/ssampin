# ADR-118: 근거 관리 실행 취소와 다시 실행

- 날짜: 2026-09-13
- 상태: 채택

## 결정

근거 관리의 공용 이력은 최근50개 작업을 세션 메모리에 보관한다. Ctrl+Z는 실행 취소, Ctrl+X는 다시 실행이다(사용자의 명시한 단축키). 입력창/IME 조합/다른 화면의 단축키는 가로채지 않으며 입력칸의 Ctrl+X 잘라내기는 유지한다. 학생·문맥 전환과 창 재진입은 이력을 초기화한다. 새 편집은 redo를 비운다.

근거·주제·장면·메모·연결·AI 적용·뼈대 적용 및 지도 좌표를 대상으로 한다. 개인 뼈대 라이브러리 설정, 원본 관찰/누가기록, 선택·확대·접기 상태는 제외한다. 다학생 엑셀 가져오기는 명시한 학생 전체를 한 작업으로 취소한다.

## 저장과 보호

스토어 쓰기 관문이 락 안에서 읽은 최신 before와 성공한 저장 after를 게시한다. 작업 journal은 실제 변경된 ID만 합치므로 동기화로 메모리에 새로 읽힌 값은 사용자 변경으로 오인하지 않는다. 동일 ID의 두 저장 사이에 외부 변경이 감지되면 이력에 충돌을 표시해 취소로 덮어쓰지 않는다. 여러 단계의 저장/부분 실패는 마지막 저장 완료 시 한 작업에 담는다.

복원은 기존 주제→근거 파일 락 안에서 최신값을 확인하고 변경 항목만 교체한다. 최신 기록이 기대값과 다르거나, 주제 소유·장면 연결·주제 연결 대상·순환·원본 중복을 깨뜨리는 복원은 쓰기 전에 차단한다. 두 번째 파일 쓰기 실패는 첫 파일을 복구하며 이력 커서를 옮기지 않는다. 좌표 포트는 학생 키를 고정해 비동기 도중 학생이 바뀌어도 다른 학생 위치에 쓰지 않는다.

기존 토스트별 snapshot 복원은 제거하고 공용 실행 취소/다시 실행으로 통합한다. 한 원본을 저장→주제로 이동→장면에 배치하거나 AI 전체 적용하는 동작은 한 항목이다.
