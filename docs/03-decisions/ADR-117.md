# ADR-117: 지도 미분류 접근과 근거 보존

- 날짜: 2026-09-13
- 상태: 채택

## 결정

지도 상단에 미분류·자리 미정 건수를 상시 표시한다. 목록은 전역 미분류와 주제별 장면 미배치 근거를 함께 보여 주며 주제/장면 선택 후 넣기를 제공한다. 캔버스의 드래그 경로도 유지한다.

근거 관리의 삭제 동작은 미분류로 돌리기로 교체한다. 저장한 근거의 id, 내용, 메모, 원본 연결과 AI 제외 상태를 보존하며 threadId 및 장면 배치만 해제한다. 단일 장면 연결 해제는 다른 연결을 유지하고 마지막 연결이면 주제의 자리 미정에 둔다.

원본 후보는 저장에서 반환한 실제 id로 곧바로 장면에 배치한다. 이미 저장된 원본이 있으면 동일 id를 사용하고 중복 생성하지 않는다. 저장/배치 실패는 성공으로 표시하지 않으며, 생성된 근거를 삭제하지 않고 다시 배치할 수 있게 남긴다. 장면 배치 중 연속 클릭을 막는다.
