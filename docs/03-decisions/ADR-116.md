# ADR-116: 뼈대 선택창 닫기와 직접 만든 뼈대·주제별 장면 추가

- 날짜: 2026-09-13
- 상태: 로컬 구현, 미배포

뼈대 선택창 위쪽에 스크롤해도 남는 닫기 버튼을 두고 창 내부 Escape도 닫기로 처리한다. 닫기는 현재 주제나 근거를 변경하지 않으며 주제에서 다시 열 수 있다.

선택창의 새 뼈대 만들기에서 이름, 장면의 역할과 이름, 순서를 직접 정한다. 교사 판단은 기존 규칙대로 하나를 유지하며 위치는 바꿀 수 있다. 장면 개수는 기존 상한을 따른다. 저장만으로 주제의 기존 뼈대를 바꾸지 않고, 저장 후 이 뼈대 깔기로 적용한다. 근거와 메모를 포함하지 않는 기존 개인 뼈대 저장 경로를 사용해 다른 주제에서도 재사용한다.

주제 카드와 주제 상세에는 장면 추가를 제공한다. 기존 근거와 장면을 유지하며 새 과정 장면을 더하고 카테고리·이름 편집을 연다. 기존 장면 상세의 사이에 끼우기도 같은 경로를 사용한다.

개인 뼈대 저장이 실패하면 해당 목록의 낙관적 화면 갱신을 되돌려 같은 이름 재시도가 가능하게 한다. 실패한 요청의 목록이 여전히 현재 값일 때에만 되돌리며 다른 설정이나 뒤이은 변경을 덮지 않는다. 입력은 유지한다.

브라우저의 가상 자료에서 닫기·Escape·재열기, 저장 실패·동일 이름 재시도, 순서와 이름 저장, 명시적 적용과 되돌리기, 원문 보존, 주제별 장면 추가, 새로고침 후 재사용을 확인했다. 자세한 검사 결과는 월별 진행 기록에 남긴다.
