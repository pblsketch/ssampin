# ADR-128 — 쌤도구 '참여교실'을 '퀴즈·설문·토론'으로 바꾼다

- 날짜: 2026-09-21
- 상태: 채택, 로컬 구현 · 미배포
- 관련: [ADR-125](ADR-125.md)(문항 유형으로 만들기)·[ADR-126](ADR-126.md)(유형 통합)·
  [ADR-127](ADR-127.md)(시각 언어)로 도구의 성격이 바뀐 뒤의 이름 정리.

## 발단

오너가 "이 도구의 제목이 직관적이지 않다"고 했다. 실제로 이름이 하는 일을 말하지 못한다.

- **장소처럼 읽힌다.** '참여교실'은 공간 이름 같은데 실제로는 선생님이 진행하는 활동이다.
- **'교실'이 겹친다.** 앱 안에 이미 `교실 화면`·`교실 약속 정하기`가 있다.
- **옆 카드와 구분되지 않는다.** 쌤도구 격자에서 바로 옆이 `객관식 설문`·`주관식 설문`인데
  무엇이 다른지 이름만으로는 알 수 없다.
- 오너 자신도 이 도구를 설명할 때 "퀴즈, 설문, 토의 토론"이라고 불렀다.

## 결정

이름을 **`퀴즈·설문·토론`** 으로 바꾼다(오너 선택). 카드 설명
"퀴즈로 확인하고 토의·토론으로 생각 나누기"는 그대로 둔다.

### 이름은 상수 한 곳에서만 정한다

`src/adapters/multiSurvey/participationBranding.ts` 의 `PARTICIPATION_TOOL_NAME`.
화면 여섯 곳이 이 상수를 읽는다 — 쌤도구 카드(`ToolsGrid.tsx`), 듀얼 모드
(`toolRegistry.ts`), 즐겨찾기(`toolDefinitions.ts`), 목록 화면 제목, 편집·진행 화면 머리글,
학생 휴대폰 화면(`<title>`·brand).

**이번에 이 문제가 실제로 있었다.** 앞의 두 목록은 '참여교실'인데 **즐겨찾기 목록만
'복합 유형 설문'** 이라는 더 옛 이름으로 남아 있었다. 쌤도구 목록이 세 군데로 나뉘어 있어
한 곳만 고치면 또 갈라진다.

### 이름 안에 가운뎃점이 있으므로 `이름 · 단계` 로 잇지 않는다

편집·진행 화면 머리글은 `참여교실 · 활동 편집` 이었다. 새 이름을 그대로 넣으면
`퀴즈·설문·토론 · 활동 편집` 이 되어 점이 엉킨다. 이름과 단계를 **별도 요소**로 나눠
이름은 강조색 굵게, 단계는 흐린 색으로 나란히 둔다.

## 대안

| 후보             | 왜 고르지 않았나                                                                          |
| ---------------- | ----------------------------------------------------------------------------------------- |
| 묻고 답하기      | 짧고 따뜻하며 `자리 뽑기`·`서명받기` 와 결이 같지만, 옆의 `주관식 설문` 과 구분이 약하다. |
| 실시간 문답      | `실시간 담벼락` 과 말투가 맞지만 '문답'을 옛 '질문 받기'로 오해할 여지가 있다.            |
| 학생 응답 모으기 | 오해 여지는 가장 적으나 사무적이고, 퀴즈처럼 맞히는 성격이 덜 드러난다.                   |

## 영향

- 저장된 자료·도구 식별자(`tool-multi-survey`)·코드 파일 이름(`Participation*`)은 **바꾸지 않는다.**
  이름은 표시용이고, 식별자를 바꾸면 즐겨찾기·듀얼 모드 설정이 끊긴다.
- 공개 가이드(`landing/src/content/docs.ts`)의 제목·본문을 고치고 **이전 이름을 한 번 적어 둔다**
  ("이전 이름 참여교실") — 옛 이름으로 찾는 선생님이 있다.
- 가이드에 남아 있던 **옛 19종 유형 목록**도 이번에 15종으로 고쳤다(ADR-126 반영 누락분).
  끌어서 순서 바꾸기·교실 화면 띄우기 설명도 더했다.
- 챗봇 지식은 출시 때 다시 넣는다(KB ingest는 서버 상태 변경이라 승인 범위에서만).

## 지킴이

- `participationBranding.test.ts` — 즐겨찾기 목록이 상수와 같은 이름을 쓴다.
- `ParticipationFlow.test.tsx` — 편집 화면이 이름과 단계를 **각각 따로** 그린다
  (한 문자열로 이어 붙이면 두 조회가 동시에 성립하지 않는다).
