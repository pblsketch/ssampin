# ADR-143 — 내 API 키(BYOK) 구현: 키는 main 프로세스 금고에만, 고정 주소로만, 모든 AI 기능이 같은 통로를 쓴다

- 날짜: 2026-10-24
- 상태: 채택 · **v2.5.6 출시(2026-10-24, `8404ed24`)** — 오너 실기기 확인 없이 출시(오너 결정)
- 결정자: 오너 요청(2026-10-24 "BYOK 로 api 키를 입력… 일반 선생님도 쉬운 uiux… 키가 절대 유출되면 안 됨… 생기부 작성에서도 활용")
  위에서 구현 세부는 이 문서가 정한다.
- 관련: [ADR-142](ADR-142.md) 결정 7·8(무료 경로 없앰·BYOK 허용) · [ADR-082](ADR-082.md)(본인 구독 CLI) · [ADR-090](ADR-090.md)(이미지 첨부)
  · [ADR-141](ADR-141.md)(암호화 저장소가 없으면 메모리에만)

## 결정

### 1. 키는 main 프로세스만 연다

- 금고: `userData/byok/<서비스>.key` — `safeStorage`(윈도우 DPAPI·맥 키체인)로 암호화. **데이터 폴더(getContentRoot)가 아니다** —
  데이터 폴더는 OneDrive·구글 드라이브 폴더로 옮길 수 있고, 백업(`*.json`)·드라이브 동기화가 그 안을 훑는다.
- 암호화를 못 쓰는 PC 에서는 디스크에 쓰지 않고 그 실행 동안만 메모리에 둔다(ADR-141 과 같은 규칙). 카드가 그 사실을 알린다.
- 고른 서비스·모델은 `userData/byok/active.json`(키 아님, 평문).
- **화면(렌더러)으로 키를 돌려주는 IPC 가 없다.** 화면이 받는 것은 서비스별 "키 있음 + 끝 4자리 + 디스크 저장 여부"와 고른 모델뿐.
  기존 `secure:read`(아무 키나 읽는 통로)와 저장 자리를 일부러 갈랐다.
- IPC 는 우리 앱 창의 **최상위 화면**에서 온 요청만 받는다(`isTrustedSender`).

### 2. 키는 정해진 세 호스트로만 나간다

| 서비스       | 대화 주소                                                          | 키 확인(요금 없음)                       |
| ------------ | ------------------------------------------------------------------ | ---------------------------------------- |
| 제미나이     | `generativelanguage.googleapis.com/v1beta/openai/chat/completions` | 모델 목록(키 필요)                       |
| 오픈라우터   | `openrouter.ai/api/v1/chat/completions`                            | `GET /api/v1/key`                        |
| 오픈코드 Zen | `opencode.ai/inference/openai/v1/chat/completions`                 | 키를 붙인 모델 목록(가짜 키 → 401, 실측) |
| 오픈코드 Go  | `opencode.ai/inference/go/openai/v1/chat/completions`              | 위와 같음                                |

- 사용자 지정 주소를 받지 않는다. 보내기 직전에 https·허용 호스트를 다시 보고, `redirect: 'error'` 로 리디렉트를 따라가지 않는다
  (따라가면 키가 실린 머리글이 그 주소로 간다).
- 화면은 "어느 서비스·어느 모델"만 고른다. 모델은 서비스가 준 목록에 있는 것만 받는다(비싼 모델로 몰래 바꾸지 못하게).
- 오류 본문은 갈래를 정하는 데만 읽고 버린다. 로그에는 상태 번호와 갈래만, 키(원문·앞뒤 절반·키 모양 덩어리)를 지운 뒤에 남긴다.
- 동시 요청 3개, 대화 80턴·40만 자, 도구 64개 상한. 앱을 끄면 진행 중 요청을 끊는다.

### 3. 모든 AI 기능이 한 통로를 쓴다

- `AiRunProviderId = 'claude' | 'codex' | 'apikey'`. `useConnectedOwnAiProviders()` 가 고른 키가 있으면 `'apikey'` 를 함께 돌려준다 —
  AI 패널·생기부 초안·근거 정리 보드·분량 조절·근거 지도 일괄 생성이 모두 이 목록으로 고르기 단추를 그린다.
- 생기부 쪽(`askOnce`)은 `apikey` 면 1층 규정을 system, 근거 묶음을 user 로 보낸다(CLI 의 `--append-system-prompt` 자리와 같다).
  규정 배급·분량 게이트·별칭 가리기는 그대로다.
- AI 패널은 쌤핀 AI(Solar)와 **같은 모양**(`ApiKeyAssistPort`): 모델이 도구를 고르면 앱이 이 컴퓨터에서 조회하고, 이름을 가린 결과를
  `[앱에서 조회한 결과]` 턴으로 실어 다시 묻는다. 쓰기는 제안 카드 → 선생님 [실행]뿐. 연락처 차단도 그대로.
  지시문은 앱 안에 있다(오늘 날짜(서울)·별칭 그대로 쓰기·평문 지시) — 서버 시크릿 프롬프트를 쓸 수 없는 통로라서.
- **쌤핀 AI 로 몰래 넘기지 않는다**(폴백 없음). 키 통로가 실패하면 갈래별로 말한다:
  `key-missing`·`key-invalid`·`key-no-credit`·`key-rate-limited`·`key-model-unavailable`·`key-network`·`key-timeout`·`key-provider-error`.
- 이미지 첨부는 이 통로에서 첫 판에 받지 않는다(서비스마다 그림 지원이 달라 "보냈는데 안 봤다"가 생긴다).
- 쌤핀 AI 동의 없이 키만 쓰는 선생님도 자료를 불러오고, 쓰기 제안 [실행]·받아쓰기 나누기를 쓸 수 있게 관문을 넓혔다.

### 4. 모델 목록은 쌤핀이 거른다

- 대화용이 아닌 것(음성·그림·임베딩·실시간·연구 대행)과 **무료 모델**(보낸 내용을 학습에 쓸 수 있음)은 뺀다.
- 오픈라우터는 Anthropic·OpenAI·Google 만, 유료·글 출력·도구 지원 모델만, `:batch` 같은 변형 제외.
- 오픈코드는 OpenAI 형식으로 부를 수 있는 집안(GLM·Kimi·DeepSeek·Mistral)만. 클로드(anthropic 형식)·GPT/그록/뮤즈(responses)·
  제미나이(google 형식)·큐원(판본마다 다름)은 이 주소로 못 부른다(opencode.ai/docs/zen·go 표).
- 추천: 제미나이 `gemini-flash-latest` · 오픈라우터 `anthropic/claude-haiku-5.5` · 오픈코드 `glm-5.3`. 키를 넣으면 추천 모델로 바로 쓴다.
- `temperature` 는 보내지 않는다(추론 모델 일부가 400). 출력 한도 패널 4096·초안 8192 토큰, 시간 한도 90초·180초.

### 5. 화면

- 설정 > AI 연결 맨 위 「내 API 키로 연결」 카드: 1단계 서비스 고르기(제미나이 "처음이라면") → 2단계 번호 붙인 순서 + [키 받으러 가기]
  (주소는 main 의 표에서 꺼낸다) → 3단계 비밀번호 칸에 붙여 넣고 [연결 확인]. 붙여 넣기 군더더기(따옴표·`Bearer`·`NAME=`·보이지 않는 글자)는 걷는다.
- 성공하면 입력값을 곧바로 지우고, "내 AI" 스위치를 켜고 답하는 AI 를 「내 API 키」로 바꾼다. 연결된 키는 끝 4자리·사용 중·모델 고르기·
  [이 키로 쓰기]·[키 지우기](확인 한 번)로 보인다.
- 「요금은 선생님 계정」「쌤핀 서버를 거치지 않고 고른 서비스로 바로」「학생 이름은 가림」을 처음부터 보이게 둔다.
- AI 패널 머리·생기부 초안 패널에서도 모델을 바꿀 수 있다(같은 값).
- 디자인 에이전트 검토 반영(2026-10-24).

### 6. 적대 보안 검토(2026-10-24)에서 나와 고친 것

키가 화면·로그·디스크·백업·동기화·다른 호스트로 새는 길은 **없다**고 확인됐다(검토 범위: 위 파일 전부 + 크래시 기록·CSP·분석 오류 추적).
대신 "키는 안 새도 **돈·정책은 샐 수 있는**" 틈과 옛 결함이 나와 모두 고쳤다:

- **요금 폭주** — 화면이 고장 나거나 악성 글이 끼면 대화 통로를 무한히 부를 수 있었다 → main 에 분당 30회·하루 600회 상한(`key-rate-limited`).
- **모델 허용 목록 우회** — 목록을 못 받으면 아무 모델이나 고를 수 있었고(fail-open), `active.json` 을 바깥에서 고치면 무료·학습 이용 모델로
  보낼 수 있었다 → 목록을 못 받으면 거절(fail-closed), 보내기 직전에 쌤핀 규칙으로 다시 검사.
- **키가 엉뚱한 회사로** — 제미나이 칸에 오픈라우터 키를 넣으면 확인 요청이 그 키를 구글로 보냈다 → 모양이 다른 서비스 키면 **보내지 않고** 알려 준다.
- **지운 키로 계속 요청** — 키를 지우거나 바꿔도 진행 중 요청(최대 180초)은 옛 키를 썼다 → 그 서비스 요청을 끊는다.
- **클립보드에 남은 키** — 저장에 성공하면 클립보드가 같은 키를 들고 있을 때 비운다(윈도우 클립보드 기록).
- **바깥 페이지** — 창이 바깥 주소로 넘어가도 preload 가 남는다 → 쌤핀 dist 폴더·개발 서버 화면만 받는다(경로로 비교 — 한글 사용자 이름의 %인코딩 차이 대비).
- **리눅스 평문 키링** — `basic_text` 백엔드는 암호화로 치지 않는다(메모리에만).
- **옛 결함 2건(같은 종류)**: `secure:read/write/delete` 와 `data:read/write/writeIfUnchanged/remove` 가 이름을 검사하지 않아 `../` 로 데이터 폴더 밖을
  읽고 쓰고 지울 수 있었다(`../byok/active` 로 금고의 모델 파일을 덮어쓸 수도 있었다). 보안 저장소는 글자 규칙 + 경로 이중 확인, 데이터 파일은
  **하위 폴더는 그대로 받고 바깥으로 나가는 것만** 막는다.
- 남긴 위험(문서로만): main 프로세스 크래시 덤프(`userData/crash-dumps`, 올리지 않음)에 복호화된 키가 있을 수 있다 — 선생님께 덤프를 받을 때 알릴 것.
  같은 사용자 권한의 악성 프로그램은 DPAPI 를 풀 수 있다(OS 한계).

## 확인한 것 (2026-10-24, 로컬)

- 실제 제미나이 키(.env, 값 출력 안 함)로 IPC 처리기 전 구간: 틀린 키 → `key-invalid` · 저장 → 추천 `models/gemini-flash-latest`, 쓸 수 있는 모델 16개 ·
  패널 1왕복 도구 호출(`get_events {"days":7}`) → 2왕복 조회 결과로 평문 답(별칭 유지) · 초안 한 문단(생기부 문체) ·
  응답·로그·디스크 어디에도 키 원문/앞뒤 12자 없음.
- 가짜 키로 오픈라우터·오픈코드 Zen·Go 모두 `key-invalid`. 오픈라우터 공개 목록에서 걸러진 모델 91개(추천 맨 위).
- 단위 테스트: 금고·클라이언트·IPC(모든 통로의 응답에 키 없음·상한·fail-closed·지우면 끊김·클립보드)·규칙·포트·askOnce·상태 스토어·
  데이터 파일 이름 검사.

## 하지 않은 것 · 남은 것

- **오픈코드 Go 는 남긴다(오너 결정 2026-10-24, "이정도면 남겨도 되지 않나").** 문서가 "OpenCode 와 비슷한 요청을 보내는 코딩 에이전트용,
  남용 감시"라고 적는 점은 카드의 주의 문구로 알린다. 쌤핀은 요구하는 `x-opencode-session`·자체 User-Agent 를 보낸다. 제재 신고가 오면
  `API_KEY_SERVICES` 에서 `opencode-go` 한 줄을 뺀다.
- 실제 오픈라우터·오픈코드 **유효 키**로는 확인하지 못했다(키 없음). 실기기(설치본)에서 safeStorage·창 신뢰 판정도 확인 전.
- ADR-142 결정 7(무료 Solar 경로 없앰)은 **v2.5.6 출시 준비에서 함께 했다**(오너 「이번에 정리」): 실험실 스위치를 안내 카드로 바꾸고, 저장된
  `enabled` 는 불러올 때 끈다(`useAssistStore` merge — 폴백도 함께 멎는다). 관찰 [학생별로 나누기]는 구독·내 API 키로도 열린다.
  서버 `ssampin-assist` 함수와 그 시크릿은 그대로 두었다(옛 버전 앱이 부를 수 있다 — 정리는 따로).
- **개인정보처리방침은 고쳐 두었다(국·영, 미공개)**: 제10조에 「내 API 키로 연결」 문단(직접 전송·요금은 키 주인·키는 OS 암호화로 PC 에만·
  오픈라우터/오픈코드의 전달·제미나이 무료 등급 학습 이용), 제공자 정책 줄에 OpenRouter·OpenCode 와 "쌤핀의 처리위탁(제11조)이 아님",
  제13조에 "직접 연결한 구독·키로 보내는 것은 쌤핀의 위탁 이전이 아님" 한 문단. 랜딩은 푸시하면 바로 공개되므로 **앱 출시와 같은 푸시로** 낸다.
- 출시 전: `/docs` 가이드
  (설정 > AI 연결 > 내 API 키, 서비스별 키 받는 법·요금·한도 설정), 챗봇 KB.
