# ADR-139 — 쌤도구 타이머 디자인·기능 개선: 창에 맞춰 커지는 원, 네 모드가 함께 도는 탭, 단계 타이머, 발표 흐름, 화면 이동 안내

- 날짜: 2026-09-24
- 상태: 채택 · 구현 완료(커밋 `871e6274`, 푸시 보류·미출시) · 오너 실기기 확인 전
- 분석: [timer-uiux-20260924.analysis.md](../03-analysis/timer-uiux-20260924.analysis.md) · 화면 설계:
  [timer-uiux.design.md](../02-design/features/timer-uiux.design.md)
- 요구사항 정본: `.dryforge/spec.md`(개발 도구 폴더 — 저장소에는 올라가지 않는다. 이 ADR 이 결정을 모두 옮겨 적었다)
- 원칙: [ADR-134](ADR-134.md)(줄 세우기·벌주기 금지)
- 결정자: 오너 (2026-09-24 대화 — "모두 진행", 이어서 질문 16개에 답함)

## 발단

오너가 "파란 동그라미와 시간이 너무 가깝다"고 짚었다. 코드로 재 보니 숫자 폭(약 288px)이 원 안지름(274px)보다 넓어 숫자가
**원을 뚫고 나갔고**, 원은 어떤 창에서도 300px 고정이라 교실 TV 전체화면에서도 작았다. 분석 중 결함 여섯 가지(발표 예고
알림이 설정 무시, 발표 '내 파일' 알람 무시, 🔊 가 타이머 알람을 못 끔, 화면을 떠나면 안내 없이 꺼짐, 모바일 옛 사본,
직접 입력 창 Enter·Esc)와 교사에게 필요한 기능이 나왔고, 오너가 전부 진행을 승인했다.

## 결정

### 모양

1. **원과 숫자 비율(B안)** — 숫자 폭 = 원 안지름의 약 62%(60~65%). 원은 고정값이 아니라 **도구 영역의 빈 공간에 맞춰**
   숫자와 함께 커진다(최소 200px, 평소 최대 640px, 교실 화면 960px, 두께는 지름 비례 8~24px). 타이머 도구에서는 배율
   조절(50~200%)을 숨긴다 — 창 맞춤과 겹치면 세로로 넘친다. A안(원만 480px)은 노트북에서 너무 커서 버렸다.
   (`Timer/timerGeometry.ts`, `useTimerStageSize.ts`, `TimerDial.tsx`)
2. **원 색** — 평소 / 경고(남은 시간 ≤ 경고 기준, 전체 > 기준) / 임박(≤10초, 전체 >10초). 경고 기준은 **예고 알림 시점**,
   꺼져 있으면 60초(오너 선택 "예고 알림 기준"). 짧은 타이머는 주황을 건너뛴다. 발표의 옛 규칙(10초 노랑·5초 빨강)은 없앴다.
   평소 색은 테마 색이되, 테마 색이 경고색과 헷갈리는 테마(선셋·크래프트·크래프트 다크·모노·뉴트럴 둘)에서는 `sp-info` 로
   바꾼다 — 색상(hue)·채도 계산으로 판정해 새 테마에도 자동 적용된다(`domain/rules/timerColor.ts`, `--sp-timer-ring-normal`).
3. **상태 표시** — 대기 중에도 ± 단추를 쓴다. 일시정지면 숫자가 천천히 깜빡이고 "잠시 멈춤", 진행 중이면 "오후 2:35에 끝나요".
   시간 종료 화면은 세 모드가 같은 모양(크게 "시간 종료", 초과 "+MM:SS", 배경은 인라인 `var(--sp-bg)` — 회귀 #82).
4. **글꼴** — 숫자 굵기 700 을 실제로 불러오고(`index.html`·`mobile.html`), 콜론 폭을 0.32em 으로 좁힌다.
5. **부채꼴 표시**(데스크톱, 동기화 설정) — 숫자는 부채꼴 **아래**에 둔다(경고색 면 위 글자는 테마에 따라 안 보인다).
6. **탭 아이콘** — 타이머 `timer` · 스톱워치 `av_timer` · 발표 `co_present` · 단계 `stairs`.

### 동작

7. **탭을 바꿔도 계속 돈다**(오너 "뒤에서 계속") — 네 모드를 모두 그려 두고 보이는 탭만 바꾼다. 숨은 모드도 끝나면 알람이
   울리지만 그 탭으로 저절로 넘어가지 않는다. 탭에는 남은 시간·"종료" 표시. **단축키는 보이는 탭에만** 간다.
   팝업으로 옮기면 네 모드 상태가 모두 간다. (`Timer/ToolTimer.tsx`, `timerShellContext.ts`)
8. **음소거는 타이머 소리도 끈다**(오너 "같이 끈다") — 종료 알람·예고·단계 전환음 모두. 끄는 순간 울리던 소리도 멈추고,
   본문·팝업 창이 서로 맞춰진다. 화면 깜빡임·종료 표시는 그대로, 미리듣기는 들린다. (`timerAudio.ts`)
9. **알람 반복** — 한 번(기본)·3번·확인할 때까지(3초 간격, 5분 한도). [확인]·리셋·다음으로 넘김·음소거·팝업 이관·화면이
   사라짐 중 하나면 즉시 멈춘다. **발표 종료 알람은 설정과 관계없이 한 번** — 발표 중인 학생을 끊지 않는다.
10. **프리셋 직접 편집**(오너 "목록을 직접 편집") — 1~8개, 5초~99:59, [기본값으로]. 동기화되는 설정 `timerTool`.
11. **마지막 시간·활동 이름**(최근 8개)은 **이 기기에만**(`timer-local`) — 자주 바뀌는 값을 동기화 설정에 두면 두 PC 에서
    프리셋·단계 편집이 덮인다.
12. **교실 화면**(오너 "시간만 크게") — 단추 또는 F. 프리셋·±·설정·탭·머리글을 숨기고 원·숫자(·활동 이름·끝나는 시각)만.
    마우스를 움직이면 [멈춤/재개]·[나가기]가 3초 보인다. 화면을 누르기만 해서는 멈추지 않는다(전자칠판). 발표·단계는
    **지금 할 수 있는 다음 동작 단추 하나**를 더 보인다(오너 "다음 단추 하나 추가"). Esc 는 교실 화면만 나간다. 들어갈 때
    창 전체화면을 켜고 **자기가 켠 것만** 끈다. 병렬 칸에서는 칸만 채운다. 발표 준비·단계 목록 화면에서는 켜지 않는다.
13. **화면 꺼짐 방지** — 도는 동안·교실 화면 동안(막을 수 없는 환경이면 조용히 넘어간다).

### 새 탭 · 발표

14. **단계 타이머**(오너 "새 탭") — 단계(이름·시간) 1~20개, 반복 1~10, "마지막 바퀴의 마지막 단계 건너뛰기"(모둠 순환의
    마지막 자리 이동). 단계가 끝나면 **전환음과 함께 저절로** 다음 단계(오너 "자동으로 넘어감"), **예고 알림은 모든 단계마다**
    (단계 길이가 예고 시점 이하면 건너뜀). 저장은 동기화 설정 `stepSequences`(20개). 예시 둘(생각-짝-나누기, 모둠 순환).
    (`domain/rules/timerSteps.ts`, `Timer/StepsMode.tsx`)
15. **발표 흐름** — 명단 불러오면 번호순 자동, 발표 시간 직접 입력, **[발표 마침]**(일찍 끝냄 — 오너 추가), 발표 뒤
    **질문 시간**(기본 꺼짐, **선생님이 눌러야 시작** — 오너 "선생님이 넘김"), **[나중에]**(맨 뒤로, 한 학생 한 번, 흐른 시간
    버림)·[건너뛰기]. 자동 진행은 질문 시간이 켜져 있으면 '질문 끝'에서만 2초 뒤, 기다린 2초는 초과로 세지 않는다.
    상태 8가지와 Space·→ 동작은 표 하나(`domain/rules/presentationQueue.ts`)를 따른다. R 은 어디서나 [처음으로].
16. **발표용 예고 알림은 따로**(오너 "따로 두기") — 켜고 끔·10/30/60초 전, 기본 켜짐·30초. 알림음은 타이머 것을 함께 쓴다.
17. **발표 화면은 학생을 망신 주지 않는다(ADR-134)** — 넘긴 시간은 **작고 흐리게, 교실 화면엔 숨김**(오너 선택). 시간
    기록은 **눌러야 보이고**(오너 "누르면 보기") 이름·쓴 시간·"+0:35"만, 색·순위·정렬 없음, 저장하지 않음.
18. **명단은 이 PC 에만**(오너 "명단만 이 PC에") — 명단·순서·발표/질문 시간·자동 진행을 `timer-local` 에 기억한다.
    학생 이름이라 동기화 목록에 넣지 않는다. [명단 비우기]로 지운다.

### 화면 이동

19. **화면 이동 안내**(오너 "안내 창 띄우기") — 진행 중이면 모든 페이지 이동(사이드바·뒤로·Esc·명령 팔레트·앱 안 이동
    이벤트·위젯 창·파일 열기)에서 [팝업으로 옮기고 이동]·[끄고 이동]·[머무르기]. 첫째는 팝업으로 옮길 수 있을 때만(본문 창이고 병렬 모드가 아닐 때 — 웹의 도구 별도 창 포함).
    기본 초점은 [머무르기]. 병렬 칸 Esc 는 [끄고 닫기]/[머무르기], 칸 X·도구 교체는 묻지 않는다. 모바일은 앱 안 이동·시스템
    뒤로 가기에서 묻는다. 옮기기가 실패하면 이동하지 않는다. (`stores/useLeaveGuardStore.ts`, `common/LeaveGuardDialog.tsx`)
20. **다른 도구 [본문으로 가져오기]를 왕복으로**(오너 "구조를 고쳐 묻기") — 팝업은 본문의 **답을 받은 뒤에** 닫힌다.
    [취소]·시간 초과면 팝업에 그대로 남아 이어서 돈다. 본문 창이 없으면(메모리 절약 모드) 다시 만든 뒤 넘긴다.
    (`electron/ipc/toolPopup.ts`, `toolPopupBridge.ts` — 웹 팝업도 같은 왕복)
21. **창 X 는 묻지 않고 자동 팝업**(오너 "자동으로 팝업") — 본문 창이 숨거나 없어지는 모든 경로(위젯·아이콘·옆핀 전환,
    트레이, 메모리 절약 파괴)에서, 진행 중이거나 끝났는데 확인 전이면 먼저 팝업으로 옮긴 뒤 숨긴다. 옮길 것이 없으면 즉시
    숨기고, 실패하면 숨기지 않는다. '완전 종료'는 대상이 아니다. (`electron/main.ts` `prepareMainWindowForHide`)

### 범위

22. **모바일은 타이머·스톱워치만**(오너 선택) — 새 모듈을 쓰되 발표·단계·프리셋 편집·부채꼴은 없다. 알람 반복은 늘 한 번.
    모바일은 PC 설정 저장소를 불러오지 않아 따라갈 수 없다. 옛 사본(`Tools/ToolTimer.tsx`, 1,551줄)은 지웠다.

## 버린 안

- **앱 전체에서 계속 도는 타이머**(다른 화면에 가도 계속) — 앱 구조를 크게 바꿔야 한다. 안내 창 + 팝업으로 대신한다.
- **창 X 에서도 묻기** — 본문 창이 사라지는 순간이라 오너가 자동 팝업을 따로 골랐다. 메뉴 이동의 안내 창과 합치지 않는다.
- **발표 기록 저장·색 강조·정렬** — ADR-134.

## 알려진 한계

- 앱을 완전히 끄거나 새로고침하면 타이머는 사라진다.
- 창이 가려진 채 끝나도 창을 앞으로 띄우지 않는다.
- 모바일 알람음 설정이 저장되지 않는 기존 한계는 그대로다.
- 반복 알람을 멈추면 그 순간 울리던 **다른 탭의 소리도** 함께 멈춘다(소리를 한곳에서 모아 끊는다).
- 도는 중에 ±로 남은 시간을 예고 시점 안까지 줄이면 예고 알림이 곧바로 울린다.
- 단계 타이머에서 ±로 늘린 뒤에도 원의 비율·경고색은 원래 단계 길이를 기준으로 한다.
- 웹(브라우저)에서도 [팝업으로 옮기고 이동]이 보인다 — 웹에도 도구 별도 창이 있어 머리글의 팝업 단추와 맞췄다.
- 공용 대화상자(`common/Modal.tsx`)의 첫 초점 지정이 처음 열릴 때 무시되던 문제를 함께 고쳤다 — 같은 기능을 쓰던 다른 창
  네 곳(학생 수 줄이기 확인·실시간 응답 켜기·쿨메신저 가져오기·자리 기록)도 이제 원래 의도한 단추에 초점이 간다.
