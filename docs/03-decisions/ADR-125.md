# ADR-125 — 참여교실은 문항 유형으로 만들고 같은 화면으로 체험한다

- 날짜: 2026-09-21
- 상태: 채택, 로컬 구현·미배포

## 결정

참여교실의 새 활동은 퀴즈·토론 목적을 먼저 선택하지 않는다. 문항 유형을 자유롭게 섞어 한 참여 주소에서 진행한다. 기존 활동의 목적 필드는 호환용으로 유지하되 새 활동은 `activity`를 사용한다. 채점·결과 공개·개인 결과는 각 문항의 정답 유무를 따른다. 정답 없는 응답은 오답과 정답률 분모에서 제외한다.

문항 유형 선택은 이름·설명·학생 입력 체험·결과 미리보기로 구성하며, 명시적인 추가 버튼을 눌렀을 때만 빈 문항을 만든다. 예시 문항과 체험 응답은 저장소에 기록하지 않는다. 학생 페이지 생성기를 편집 미리보기에도 사용하고, sandbox iframe의 메시지는 해당 프레임에서 온 것만 받는다.

순서 배열·순위·이미지 위치·숫자·점수 배분·2축 평가·아이디어와 투표·여러 항목 척도를 추가한다. 기존 선택형은 이미지 보기를 지원하고, 질문 받기는 공개 후 공감을 받는다. 이미지 파일은 문서에 포함할 수 있는 PNG·JPEG·WebP·GIF 데이터로 변환하며 개별 파일 2MB 제한을 둔다.

새 입력은 공개 설정과 비공개 정답을 분리한다. 좌표는 이미지 대비 0~1, 항목 응답은 고유 ID로 저장한다. 기존 텍스트 응답 운반 경로에 JSON을 담되 서버와 도메인에서 문항별 구조·범위·합계를 검증한다. 순서 배열의 공개 항목 정렬은 정답 순서와 독립적이며 새 항목 ID는 무작위다.

아이디어·질문 공감은 공개 단계에서만 허용하고 서버가 참여자·문항·회차·대상을 검증한다. 중복 전송은 표를 늘리지 않는다. 재응답 때 이전 표는 회차 이력으로 보존하고 현재 표를 비운다. 활동 원본과 실행별 결과 스냅샷은 분리한다.

## 이유와 영향

교사가 수업 목적은 직접 판단한다는 사용자의 요구를 따른다. 유형 이름만으로 조작과 결과를 예측하기 어려우므로 직접 체험을 제공한다. 기존 도구와 저장 자료 접근 경로는 유지하며 자동으로 덮어쓰거나 손실 변환하지 않는다.

실제 학생 HTTP/WebSocket 왕복, 혼합 문항 채점, 결과 저장·재읽기, 원본 삭제 후 결과 보존, 미리보기 무저장과 편집 취소를 검사한다. 로컬 검증은 학교망 터널이나 실제 여러 휴대폰 검증을 대신하지 않는다.
