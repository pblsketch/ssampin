# ADR-112: 연결점으로 장면 차례와 근거 참조를 편집한다

- 일자: 2026-09-13
- 상태: 채택, 로컬 구현·브라우저 검증. 배포하지 않음.
- 관련: ADR-108·111, [연결 편집 설계](../02-design/features/record-scene-connection-editing.design.md)

## 결정

1. 장면의 다음 연결점을 다른 장면의 시작점에 놓으면 대상 장면을 바로 뒤로 옮긴다. 한 주제 안의 단일 차례를 유지하며 클릭·키보드로도 연결한다. 선은 1.25px로 유지한다.
2. 앞 장면이 달라진 기존 이음말은 삭제하지 않고 확인 대상으로 보존한다. 확인 전 AI에게 확정된 관계 설명으로 보내지 않는다. 되돌리기는 이전 차례·메모·확인 상태를 함께 복원한다.
3. 한 근거를 같은 주제의 여러 장면에서 참조할 수 있다. `RecordEvidence.threadId`가 주제 소속의 정본이고 원본은 복제하지 않는다. 화면 카드는 하나이며 참조마다 연결선을 표시한다.
4. 새 연결점 드래그는 참조 추가, 기존 연결 끝점 드래그는 해당 참조 이동이다. 연결 해제는 해당 참조만 없앤다. 마지막 참조가 없어져도 근거는 자리 미정에 남는다. 이미 연결된 대상에 놓을 때 기존 연결 메모를 덮어쓰지 않는다.
5. 연결마다 ‘이 장면에서 쓸 부분’을 200자까지 저장한다. 원본 공통 메모와 구분하며 해당 연결 이동 시 보존한다. AI에는 원문을 한 번, 장면별 참조와 부분 메모를 별도로 보내며 익명화·금지 정보 필터를 적용한다.

## 범위

이 결정은 근거끼리 임의의 인과관계 화살표를 추가하지 않는다. 장면 차례 편집과 자료 참조 편집을 제공한다. 자유 좌표로 주제·장면을 배치하는 기능과는 구분한다. 구체적인 검증 결과는 [월별 기록](../progress/2026-09.md)에 남긴다.
