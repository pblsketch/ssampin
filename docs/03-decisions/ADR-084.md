# ADR-084 — "내 AI" 2차: 고르기를 화면으로 꺼내고, 첨부를 연다 (2026-09-05)

### 배경

v1 출시 준비를 마친 뒤 오너가 화면을 보고 네 가지를 지적했다. 코드를 확인해 보니 넷 다 사실이었다.

1. **공급자(Claude/Codex) 고르기가 AI 패널 헤더에만 있다.** 그것도 연결이 1개 이상일 때만
   나타난다. 실험실 카드에는 고른다는 개념 자체가 없다.
2. **생기부 초안은 공급자를 아예 못 고른다.** `runProvider` 가 고른 값이 없으면
   `connected[0]`(= 목록 순서상 항상 claude)로 조용히 정한다. 둘 다 연결한 선생님이
   패널을 한 번도 안 열었다면 초안은 말없이 Claude 로 나간다.
   ★실기기 QA 문서 §2.2 에 "패널에서 Codex 를 고르고 오세요"라는 주의를 달아야 했던 것이
   이 설계가 어색하다는 신호였다.
3. **모델 선택이 설정 > AI 연결 안에만 있다.** 모델은 "이 질문을 얼마나 꼼꼼히"라는
   그때그때의 판단인데, 바꾸려면 설정에 들어갔다 나와야 한다.
4. **패널에 첨부·이미지 붙여넣기가 없다.** 핸들러가 0개이고, 밖으로 나가는 형식 자체가
   텍스트 한 덩어리(`AssistPort` 의 `content: string`)다.

### 결정

**D-A. 공급자 고르기를 쓰는 자리마다 둔다.** 초안 화면의 [이 학생만 / 남은 학생 모두] 옆에
공급자 칩을 둔다. 둘 다 연결됐을 때만 보인다(하나면 고를 게 없다).
→ _대안 기각_: "설정에 기본 공급자를 둔다"는 **설정 어딘가의 값이 딴 화면 동작을 조용히
바꾸는** 구조라 나중에 원인을 못 찾는다.

**D-B. 모델 선택을 패널로 올린다.** 설정 > AI 연결의 모델 드롭다운은 **그대로 둔다**(기본값
성격). 패널에서 고른 값이 이번 대화에 우선한다.

**D-C. 첨부·이미지 붙여넣기는 구독 AI 일 때만.** 쌤핀 AI(Solar)로는 보내지 않는다 —
서버 비용이 사용량에 비례해 늘고, 그건 "쌤핀이 새로 비용을 요구하지 않는다"는 전제를 깬다.
연결이 없으면 첨부 자리를 아예 안 보여 준다.

**D-D. 사진 속 얼굴·이름은 기술로 막지 않고 안내한다.** 지금 가리는 장치는 **글자만** 본다.
사진에 찍힌 얼굴·이름표·명렬표는 그대로 나간다. 이걸 자동으로 막으려면 이미지 인식이
필요한데 그건 별개의 큰 일이다. **첨부 자리 옆에 상시 안내를 두고**, `/docs` 에도 적는다.
→ 오너 결정(2026-09-05). 막는 척하지 않고 사실대로 말하는 쪽을 택했다.

**D-E. "대화를 디스크에 안 남긴다" 원칙을 바꾼다 — 단, 쌤핀 안에만 쌓는다.**

- **쌤핀 자료 폴더에 대화를 쌓는다.** 지난 대화를 다시 보고 이어서 물을 수 있고,
  백업·삭제가 쌤핀 안에서 된다.
- **`--no-session-persistence` 는 그대로 유지한다.** 이걸 빼면 Claude Code 자체 폴더
  (`~/.claude`)에 쌓이는데, 그건 **쌤핀이 보거나 지울 수 없고 백업·개인정보방침 밖**이다.
  기록을 남기려는 목적(다시 보기·이어 묻기)은 쌤핀 쪽 저장으로 다 얻는다.
- ★코덱스는 `~/.codex/sessions/` 에 **이미** 남긴다(우리가 끄지 못한다). 이건 사실대로 안내한다.

### 결과

- 초안이 어느 AI 로 나가는지 화면에서 보이고 고를 수 있다.
- 모델을 질문마다 바꿀 수 있다.
- 이미지를 붙여 물어볼 수 있다(구독 AI 한정).
- **대화가 이 컴퓨터에 남는다.** 되돌아보기가 가능해지는 대신, 지우는 길을 같이 만들어야
  한다(설정에서 "대화 기록 지우기").
- `/docs` 사용자 가이드와 실험실 고지 문구를 같은 작업 단위에서 고친다 — 특히
  "사진 속 얼굴은 가려지지 않는다"와 "대화가 이 컴퓨터에 남는다"는 **새 사실**이다.

### 후속

- 이미지 인식 기반 얼굴·이름 가리기(별개 작업, 미착수).
- 대화 기록 보관 기간·용량 상한(1차는 무제한, 실사용 보고 결정).
