# ADR-135 — 관찰 기록 응원(잔디) 1차: 한 바퀴 반 카드·내 잔디·핀 응원, 기록 알림과 같은 기준

- 날짜: 2026-09-23
- 상태: 채택 · 구현 완료(미출시) · 오너 실기기 확인 완료(2026-09-24)
- 원칙: [ADR-134](ADR-134.md)(줄 세우기·벌주기 금지) 위에서 정한 화면·계산 규칙
- 요구사항 정본: `.dryforge/001/spec.md`(개발 도구 폴더 — 저장소에는 올라가지 않는다. 이 ADR 이 결정을 모두 옮겨 적었다), 화면 설계: `docs/02-design/features/observation-cheer.design.md`
- 결정자: 오너 (2026-09-23 대화 — 아래 결정마다 오너가 고른 답)

## 발단

선생님이 학생 관찰을 **고르게, 꾸준히** 남기도록 쌤핀이 쌓인 기록을 보여 주고 응원하기로 했다(ADR-134).
중·고등 교과 선생님은 수업반 5~6개 × 30명 안팎을 맡으므로 학생 200명 가까이를 한 화면에서 다뤄야 한다.
이미 출시된 '관찰 기록 알림'이 학생을 부르는 기준과 따로 놀면 종과 알림이 다른 학생을 가리키게 된다.

## 결정

1. **무엇을 세는가** — 담임 누가기록은 **출결만 빼고** 모두, 수업반 관찰기록은 모두 센다. 여러 명 기록은 학생마다
   센다. 날짜는 기록에 적은 `date` 이고, 같은 날짜는 만든 시각 → id 순서로 줄 세운다. 오늘보다 뒤 날짜는 그날이
   올 때까지 어디에도 넣지 않는다. (`domain/rules/observationEntries.ts`)
2. **기록 알림도 같은 기준으로 바꾼다(출시된 동작 변경).** 출결만 적힌 학생도 이제 알림이 부른다. 공백 날수·예약
   날짜·미기록 수에서 **방학 날을 뺀다**. '당분간 빼기'한 학생은 팝업·윈도우 알림 예약·수업 직후 알림·미기록 수에서
   모두 빠진다. (`useReminderScheduler`·`useReminderOsPush`)
3. **학사일정은 나이스 학교 일정만** 쓴다. 선생님이 만든 일정·구글 일정은 제목에 '방학'·'평가'가 있어도 쓰지 않고,
   숨긴 일정도 뺀다. 여러 날 일정은 끝 날까지 펼친다. 방학식·종업식은 등교일이다. 학사일정이 없으면 공휴일도 넣지
   않는다 — "학사일정이 없는 선생님은 보정하지 않는다"(오너: "대부분 학사일정을 불러올 거야").
   (`domain/rules/schoolCalendarDays.ts`, `adapters/hooks/useObservationCheerContext.ts`)
4. **한 바퀴(반 카드)** — 담임반과 보관하지 않은 수업반마다 카드 하나. 구성원 모두를 한 번씩 기록하면 한 바퀴다.
   **학기마다 새로 시작**하고, **끝난 바퀴는 그대로 둔다** — 카드·학기마다 마지막 끝 지점과 끝낸 바퀴 수를 저장해,
   지난 날짜로 더한 기록·지운 기록·전입생이 끝난 바퀴를 되돌리지 않는다. 머리글은 "한 바퀴까지 N명" / "한 바퀴 완료"
   뿐이고 기록 건수·바퀴 차수는 보여 주지 않는다. 칸에는 명렬표 번호만(섞인 반은 "반-번호", 학년까지 섞이면
   "학년-반-번호"). (`domain/rules/observationLaps.ts`, `observationCardRoster.ts`)
5. **끝 지점 파일은 설정과 따로 둔다** — `observation-laps`(병합형 동기화 파일, `{ records: LapMark[] }`).
   설정은 동기화 때 통째로 한쪽이 이기므로, 앱이 저절로 쓰는 값을 넣으면 설정 충돌이 잦아진다. 두 값이 만나면 끝 지점은
   **더 뒤**, 바퀴 수는 **더 큰 값**. 내려받기·충돌·빈 봉투(looksLost) 경로 모두 이 병합을 쓴다.
   끝 지점은 **메인 창**이, **이 컴퓨터에서 관찰 기록이 새로 추가된 카드**만, 그 끝 지점 기록이 **이 컴퓨터에서
   추가한 것**일 때만 저장한다. 빼기·다시 넣기처럼 구성원만 바뀐 때, 휴대폰에서 동기화된 기록·출결 기록이 들어온 때,
   다른 반에 기록한 때는 저장하지 않는다(실수로 뺐다 넣으면 원래대로 — 최종 검토에서 잡은 결함을 이렇게 고쳤다).
6. **당분간 빼기** — 칸 메뉴에서 2주·한 달·이번 학기 끝까지. **그 반에서만** 빠지고(key 가 반 범위를 담는다),
   기간이 지나면 저절로 돌아온다. 한 바퀴와 기록 알림이 **같은 목록**을 쓴다. 칸 메뉴·설정 [다시 넣기]는 누르는 즉시
   저장하고, 설정 화면 [저장]은 그 사이 바뀐 목록을 덮지 않는다(`withLatestExclusions`). 옛 `excludedStudentIds` 는
   기간 없는 빼기로 읽는다. (`domain/rules/reminderExclusion.ts`)
7. **칸을 누르면 그 학생·그 반으로 글쓰기 단계가 바로 열린다 — ADR-122 결정 2의 예외.** 특정 반 카드의 칸을 누른
   것 자체가 저장 위치를 고른 행동이다. 다른 진입(칩·단축키)은 지금처럼 고른다. 바탕화면 위젯 창에서는 메인 창을 띄워
   같은 상태로 연다(`dashboard#quick-student-record-direct:<kind>:<반>:<학생>`). 저장에 성공하면 빠른 기록 창을 닫는다.
8. **내 잔디·연속 주는 선생님 자신의 셈** — 카드가 있든 없든 모든 관찰 기록을 센다(보관 반·전출 학생 포함, 빼기 무관).
   평일 칸, 진하기 4단계, 칸에 숫자·이름 없음. 연속은 **주 단위**, 쉬는 주(방학·시험·평일 모두 공휴일)는 건너뛰고,
   빈 보통 주 **한 주는 괜찮고** 달력상 바로 이어진 두 주가 비면 끊긴다. 문구 우선순위: 이번 학기 기록 0건 →
   "첫 기록을 남겨 볼까요?"(숫자 없음) · 연속 1주 이상 → "N주째 꾸준히" · 그 밖 → "이번 학기 기록한 주 N주".
   (`domain/rules/observationStreak.ts`)
9. **핀 응원은 두 가지뿐** — 오늘 **이 컴퓨터에서** 처음 저장한 관찰 기록, 이 컴퓨터가 끝 지점을 새로 저장한 한 바퀴.
   빠른 기록·담임 기록·수업 관리·알림 창·쌤핀 AI·외부 AI 연결(AI 브릿지)의 저장이 모두 '이 컴퓨터'다. 동기화로 들어온
   기록은 응원하지 않는다. 같은 응원은 이 컴퓨터에서 한 번(첫 기록은 하루 한 번, 바퀴는 (카드, 학기, 바퀴 수)마다).
   표시는 이 컴퓨터에만 두고(localStorage) 동기화하지 않는다. 토스트는 저장한 창에서만, 곧 닫히는 별도 빠른 기록
   창에서 저장했으면 카드 핀 줄에만 남는다. (`adapters/stores/observationCheerSignal.ts`)
10. **화면 위치** — 대시보드 '학생 빠른 기록' 카드 맨 위에 핀 줄 한 줄, 크게 열면 [잔디](기본)·[담임 기록] 두 탭.
    새 화면을 만들지 않는다. 메인 창과 바탕화면 위젯 창이 같은 카드를 쓴다.
11. **켜고 끄기** — 설정 > 기록 알림의 '응원·잔디' 스위치, 처음부터 켜짐(값이 없어도 켜짐). 이 스위치와 '제외 학생'
    목록은 알림을 꺼 둬도 흐려지지 않는 자리에 둔다. 끄면 핀 줄·탭·응원만 사라지고, 결정 1·2·6은 그대로 적용된다.
    옛 '제외/관심 학생' 줄은 '관심 학생'(추후 지원)만 남긴다.
12. **교과·부장 선생님도 카드를 본다** — 모든 기본 구성에 카드를 넣고, 이미 쓰던 선생님은 명렬이 있으면 맨 끝에
    **한 번만** 붙인다(대시보드 구성에 표시). 선생님이 빼면 그대로 둔다.

## 왜 이렇게

- **한 바퀴(추천안) vs 시들기**: 시들기(기록이 오래되면 칸이 옅어짐)는 벌주기로 읽힌다(ADR-134). 한 바퀴는 채우는
  방향만 있고, 끝나면 새로 시작해 "고르게"를 자연스럽게 요구한다.
- **끝난 바퀴 고정**: 계산만으로 두면 지난 날짜 기록·삭제·전입으로 "완료"가 사라졌다 나타난다. 성공을 되돌리지 않는다.
- **주 단위 연속 + 한 주 여유**: 일 단위 연속은 수업 없는 날·출장에도 끊겨 죄책감을 만든다.
- **알림과 같은 기준**: 종 붙은 학생은 언제나 알림이 부를 수 있는 학생이어야 두 기능을 믿을 수 있다.

## 대안과 영향

- **새 화면 한 장**: 오너가 빠른 기록 카드 안(탭)을 골랐다. 적용하지 않는다.
- **끝 지점을 설정 파일에**: 동기화 충돌·다른 설정 소실 위험. 적용하지 않는다.
- **학사일정 없는 선생님 보정(공휴일만 넣기)**: 추석 주가 쉬는 주로 잡혀 규칙이 흔들린다. 적용하지 않는다.
- **2차·3차로 미룬 것**: 반 흐름(학생 × 주), 오늘의 3명, 관찰 질문 카드, 금요일 정리, 관심 학생, 학기 돌아보기.
- 확장 창 위에 문서 끝으로 띄운 작은 메뉴는 Esc 를 먼저 받을 길이 없어서, 확장 창이 Esc 를 받으면 맨 위 메뉴부터
  닫게 했다(`adapters/utils/overlayMenuStack.ts`). 빠른 기록 창이 떠 있는 동안에는 확장 창이 초점 가두기와 Esc 를
  양보한다.
