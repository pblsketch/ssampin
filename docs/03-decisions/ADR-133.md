# ADR-133 — 퀴즈·설문·토론과 겹치는 옛 도구 5종을 목록에서 내린다 (실시간 담벼락은 남긴다)

- 날짜: 2026-09-22
- 상태: 채택, 로컬 구현 · 미배포 · 오너 실기기 확인 대기
- 대상: 쌤도구 목록 · 즐겨찾기 고르개 · 분할 화면 고르개 · [정리하기]
- 관계: [ADR-128](ADR-128.md)(개명) · [ADR-129](ADR-129.md)(문항 유형 묶음) 이후 정리
- 결정자: 오너 (2026-09-22, "실시간 담벼락은 내버려 두고 나머지는 내려줘")

## 발단

쌤도구에 **같은 일을 하는 입구**가 여럿이었다.

| 내린 도구          | 퀴즈·설문·토론 안의 같은 기능 |
| ------------------ | ----------------------------- |
| 📊 객관식 설문     | 객관식 투표 · 객관식 퀴즈     |
| 📝 주관식 설문     | 서술형                        |
| ☁️ 워드클라우드    | 워드클라우드                  |
| 📏 가치수직선 토론 | 가치수직선                    |
| 🚦 신호등 토론     | 신호등                        |

## 조사 — 이미 반쯤 내려 있었다

`2b53bd0f`(2026-09-21)가 `ToolsGrid` 안에 `integrated` 라는 **id 목록을 박아** 쌤도구 목록에서만
이 다섯을 걸렀다. 그래서 **목록에는 없는데 다른 데서는 그대로 보이는** 상태였다.

| 자리                             | 그때                  | 지금           |
| -------------------------------- | --------------------- | -------------- |
| 쌤도구 목록 · 전체 보기          | 이미 내려감           | 내려감         |
| 즐겨찾기 위젯의 도구 고르개      | **남아 있음**         | 내려감         |
| 분할 화면(듀얼) 도구 고르개      | **남아 있음**         | 내려감         |
| 쌤도구 [정리하기] 목록           | **남아 있음**         | 내려감         |
| 공개 가이드 `/docs` 의 도구 목록 | **남아 있음**(37가지) | 내려감(32가지) |

## 결정

### 1. 내리는 기준을 `hidden` 한 곳으로 모은다

`integrated` id 목록을 지우고 `ToolCard.hidden` 으로 통일한다. 목록과 [정리하기]가 **같은 바탕
(`catalogTools`)** 을 쓰게 해서, 한 곳만 고쳐 반쪽이 되는 일을 없앤다.

### 2. 지우지 않고 숨긴다

도구 컴포넌트·경로·저장 자료를 **그대로 둔다.** 되돌리는 것도 한 줄이다.

- 이미 **즐겨찾기에 담아 둔** 도구는 계속 열린다(`getToolDefinition` 은 그대로 찾아 준다).
  고르는 목록에서만 빠져 **새로 담을 수 없다.**
- 이미 **분할 화면·별도 창에 띄워 둔** 도구도 계속 돈다(`isDualToolId` 유지).
- 예전에 만든 템플릿·지난 결과는 **[퀴즈·설문·토론] → [이전 도구와 저장 자료 열기]** 로 연다.
  이 문은 `2b53bd0f` 에서 이미 만들어 두었다(`ParticipationClassroom` 의 `legacy` 분기).

### 3. 실시간 담벼락·교실 약속 정하기는 남긴다

오너 결정. 실시간 담벼락은 문항–응답이 아니라 **카드 보드**(칸반·자유 배치)라 겹치지 않는다.
교실 약속 정하기도 만약–그러면 약속이라는 다른 흐름이다.

## 하지 않은 것

- 옛 도구의 **템플릿·지난 결과를 새 도구로 옮기지 않았다.** 저장 공간이 다르다. 옮기려면 별도 작업이다.
- 옛 도구 코드를 지우지 않았다. 지우는 것은 새 도구가 실제 수업에서 한 학기쯤 쓰인 뒤에 볼 일이다.
