# ADR-114: Terra와 Luna의 근거 중심 상세 서술을 앱 기본 지시로 적용

- 날짜: 2026-09-13
- 상태: 로컬 구현, 미배포

## 결정

이전 독서와 작문 자료 비교에서 시험 호출에만 적용했던 상세 작성 지시를 Codex Terra/Luna 사용자의 앱 요청서에 기본 적용한다. Sol 및 다른 모델의 기본 지시는 유지한다. 서버 공통 규정이나 사용자의 저장 설정을 변경하지 않으며 업데이트한 앱이 선택 모델에 맞게 요청서를 만든다.

시험 문구의 고정 1500바이트, 7~8문장, 핵심 장면3개는 옮기지 않는다. 지도와 학교별 목표가 우선이다. 대신 근거에 있는 대상, 판단 기준, 수정 과정, 명칭·수치·기간, 부정 명제 및 조건부 판정을 구체적으로 보존하도록 요구한다. 읽은 실험을 학생이 직접 수행한 활동으로 바꾸거나 일반적 칭찬으로 늘리지 않는다.

상세 지시는 실제 전송 근거가 남아 있고 목표에 비해 얇지 않을 때에만 추가한다. 제외된 근거로 충분성을 판단하지 않는다. 선생님 추가 지시 앞에 두어 선생님이 간결한 문체를 지정할 수 있다. 기존 장면 순서 검사, 쉼표 정규화, 분량 목표 및 초안 비교·적용 절차는 유지한다.

## 검증

모델 선택부터 실제 전송 요청서까지의 화면 컴포넌트 시험과 요청서 단위 검사를 수행한다. 별도 교사 추가 지시 없이 실제 Codex 모델로 기존 독서와 작문 자료를 작성해 확인한다. 실제 출력의 상세함, 분량 및 생략 여부는 서로 구분해 기록하며 단일 사례를 일반 성능 보증으로 확대하지 않는다. 결과는 월별 진행 기록에 남긴다.
