# ADR-111: 근거 지도를 가지형 배치와 직접 편집 중심으로 바꾼다

- 일자: 2026-09-13
- 상태: 채택, 로컬 구현 및 검증. 배포하지 않음.
- 관련: ADR-106·107·108·109, [설계](../02-design/features/record-evidence-map-manyfast.design.md)

## 배경

사용자가 Manyfast 예시처럼 정리 결과의 노드·연결·메모를 한눈에 읽고, 요소를 직접 수정하며, AI는 의미와 맥락을 고려해 초안을 제안하도록 요청했다. 기존 가로 장면 열은 화면을 넓게 쓰고 글자를 작게 줄여야 했다.

## 결정

1. 학생 → 주제 → 장면 → 근거 가지로 표시한다. 장면은 세로 순서이고 카드와 메모의 공간을 함께 계산한다. 소속 선과 장면 순서 화살표를 구별한다. ADR-108의 근거 사이 임의 화살표 금지는 유지한다.
2. 카드 클릭은 상세 열기다. 초안 포함 선택은 별도 체크 상자로 한다. 전체 구조는 근거를 접어 읽으며 축소로 글자를 지나치게 작게 만들지 않는다. 보기 상태는 문맥·학급·학생·영역별로 구분한다.
3. 근거 추가·삭제·다른 장면/주제로 이동, 카드 앞에 삽입 및 목록 위/아래 순서 변경은 기존 저장 경로를 사용한다. 장면과 메모를 편집하며 장면 삭제는 근거를 보존하고 되돌릴 수 있다. 메모는 대상에 붙여 표시한다.
4. AI에 포함 가능한 기존 장면의 교사 메모 맥락을 익명화해 보낸다. 제외된 근거를 포함하는 장면의 해석은 보내지 않는다. 단순한 시간 순서나 공통 단어를 인과·성장으로 해석하지 않도록 명시한다. 장면 이유와 관계 이음말을 분리해 받는다.
5. AI가 제안한 장면 순서를 저장 시 임의로 바꾸지 않는다. 평가 장면은 하나 유지하고 누락 시 기본 자리를 보완한다. 적용 전 근거/주제가 바뀌면 다시 제안받도록 하며, 명시적 적용 이후 이전 장면 ID·메모 출처·주제 이음을 복원할 수 있다. 기존 장면 메모가 제안으로 바뀐다는 사실을 미리 알린다.
6. 메모 저장 실패 시 입력을 보존한다. 같은 항목 재클릭을 포함해 편집 대상을 떠날 때 미저장 메모를 확인한다. 넓게 보기의 메뉴와 알림은 작업 공간 안에서 열어 클릭·키보드 접근을 유지한다.

## 검증 범위

전체 테스트 767파일·10,553건 통과(10건 건너뜀), TypeScript 오류 0, ESLint 오류 0(기존 경고 136), 회귀 검사 117건 통과. 후속 수정의 대상 테스트는 월별 기록을 따른다.

가상 자료로 브라우저 두 진입 경로, 메모 저장 및 순서 readback, 실제 포인터 드래그, 장면 추가·삭제·복원, 근거 추가, 학생 전환을 확인했다. 밝음/어두움과 1280·1440·1920 화면을 캡처했다. 실제 구독 AI 가상 사례 1건에서 무관한 기록 제외와 비교·수정·결과 관계를 확인했다.

설계의 교사 사용성 시험, 200근거 성능 수치, 패키징된 Electron의 Windows 배율 검증은 이 기록의 통과 주장에 포함하지 않는다. 독립 메모의 자유 좌표 편집이나 임의 그래프 연결은 이번 결정에 추가하지 않는다.
