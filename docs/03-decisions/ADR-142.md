# ADR-142 — 도움말 챗봇을 Claude Haiku 5.5(WIF) + 제미나이 임베딩으로 옮기고, 쌤핀 AI 는 무료 경로 없이 본인 구독·본인 키로만 쓴다

- 날짜: 2026-10-24
- 상태: 채택 · 챗봇 부분 **운영 적용**(서버 함수 배포·DB 079/080 적용, 앱 출시와 무관) · 쌤핀 AI 부분은 결정만(구현 전)
- 결정자: 오너 (2026-10-23~24 대화 — "Claude 로 하고, 쌤핀 AI 는 구독·키로", "구분하자", "id 페더레이션 방식으로", "20달라로 해",
  질문 2개에 "제미나이 임베딩(추천)"·"무료 경로 없앰")
- 관련: [ADR-048](ADR-048.md)(챗봇 Solar 전환) · [ADR-061](ADR-061.md)(쌤핀 AI 공급자 업스테이지) · [ADR-082](ADR-082.md)(본인 구독 BYOS)

## 발단

- **챗봇이 2026-10-13 부터 멈춰 있었다.** 업스테이지 조직의 무료 크레딧(웰컴 쿠폰·설문 보상)이 10-14 만료되고 결제 수단이 없어
  키가 `403 API key suspended due to insufficient credit` 로 정지됐다. 챗봇은 질문 → 벡터 단계가 맨 앞이라 모든 질문이 500 이었다.
  마지막 정상 답변은 2026-10-12 23:39(UTC). (2026-08-25 구글 키 무효화 때와 같은 모양의 사고가 두 번째다.)
- **새 키도 30분 만에 같은 이유로 정지됐다.** 키 재발급은 해법이 아니었다.
- **쓰던 모델이 은퇴한다.** `solar-pro3` 별칭과 모든 버전 2026-10-30(KST) 종료, `embedding-query`/`-passage`(solar-embedding-1-large,
  4096차원) 2026-12-31(UTC) 종료.
- 오너 Max 20x 요금제에 **매달 $200 API 크레딧**이 들어온다(결제 직후 지급, 주기 끝에 소멸, 다 쓰면 요청이 멈추고 요금제로 청구되지 않음 —
  지원 문서 17154008). 2026-10-23 지급분은 11-25 만료.

## 결정

### 챗봇(ssampin-chat)

1. **답변은 Claude Haiku 5.5(`claude-haiku-5-5`), 실패하면 Gemini 로 자동 폴백.** HyDE·재정렬은 생각하기를 끄고(`thinking: disabled`),
   최종 답변은 `effort: low`. Haiku 5.5 는 `temperature` 를 받지 않는다(재정렬의 `temperature: 0` 은 Gemini 폴백에만 쓰인다).
2. **인증은 API 키가 아니라 WIF(Workload Identity Federation).** Supabase 서버 함수에는 플랫폼이 발급하는 신분 토큰이 없어서
   (Vercel·GitHub Actions 와 다름) **쌤핀 자체 발급자**로 한다 — 함수가 ES256 신분 토큰(10분)을 서명해 교환하고 10분짜리 접근 토큰을 받는다.
   - 콘솔 구성: 워크스페이스 `ssampin`(`wrkspc_01M1zJeeWMvQePxq4gVmoysP`, **월 지출 한도 $20**) · 발급자 `ssampin-chatbot`
     (`fdis_01DW5LVZFjyDieD3WViDPZai`, `iss=https://ssampin.com/wif/chatbot`, 인라인 JWK `kid=ssampin-chat-20261023`, 일회용 토큰 강제) ·
     서비스 계정 `ssampin-chatbot`(`svac_011MPjn6PWJXCnmZamRXRLD5`, 개발자) · 규칙 `ssampin-chatbot`(`fdrl_01A5fsPj2Md7qVrjSbMdTHTd`,
     `sub=ssampin-chat`, `aud=https://api.anthropic.com`, 워크스페이스 `ssampin` 만, 10분).
   - 범위는 `workspace:developer`. 콘솔 규칙 화면에 `workspace:inference` 선택지가 없었다(관리 API 로는 가능 — 좁히려면 그쪽으로).
   - **한계**: 서명 키(`ANTHROPIC_WIF_SIGNING_JWK`)는 오래 쓰는 비밀값으로 남는다. 키를 갈 때는 콘솔 발급자의 인라인 JWK 도 함께 바꿔야 한다
     (자동 갱신 없음). 이득은 `sk-ant-api` 키가 아예 없고, 새어도 `ssampin` 워크스페이스·$20 한도·10분 수명 안에 갇힌다는 것.
3. **임베딩은 제미나이 `gemini-embedding-2`, 1536차원.** Claude 에는 임베딩 모델이 없다. 구글 키가 살아 있고 개인정보처리방침에 이미
   구글이 챗봇 수탁자로 적혀 있었다. 질문은 `task: search result | query: …`, 문서는 `title: … | text: …` 형식(비대칭 검색).
   1536 은 pgvector HNSW 상한(2000) 안이라 처음으로 벡터 색인을 건다(080).
4. **임베딩이 실패해도 챗봇은 멈추지 않는다.** 질문 임베딩이 실패하면 `fts`(글자 검색 칸)만으로 찾고(조사를 뗀 형태도 함께, OR),
   HyDE 임베딩만 실패하면 원본 질문 벡터만 쓴다. 두 번의 사고가 모두 "키 하나가 죽자 기능 전체가 멎었다"였다.
5. **DB 는 문서를 지우지 않고 벡터만 갈았다.** 079(벡터 칸 null·1536) → `scripts/reembed-chatbot-docs.mjs`(전량 백업 후 id 로 갱신,
   554건) → 080(not null + HNSW). `supabase db push` 는 쓰지 않았다 — 원격 미적용 070 까지 밀어 넣는다. 관리 API 로 적용하고
   `migration repair --status applied 079 080` 으로 이력을 맞췄다.
6. **개인정보처리방침 제3조·제11조·제13조(국·영문)에 Anthropic, PBC(미국) 추가**, 업스테이지는 쌤핀 AI 전용으로 줄임. FAQ 한 줄도.

### 쌤핀 AI(ssampin-assist) — 결정만, 구현은 계획서로

7. **무료 경로를 없앤다.** 본인 구독(BYOS, [ADR-082](ADR-082.md)) 또는 본인 API 키가 있어야 쓴다. 쌤핀 쪽 비용 0.
8. **본인 API 키(BYOK)를 허용한다 — 2026-09-04 "BYOK 는 여전히 금지"를 뒤집는다.** 대상: 오픈라우터 · 오픈코드 **Zen(쓴 만큼)과 Go(월 구독)
   둘 다** · 제미나이 API 키. 키는 선생님 PC 에만 두고 공급자에 직접 보낸다(쌤핀 서버 경유 없음 — 방침 조건 2 유지).
   - 착수 전 확인: 각 서비스 약관이 다른 앱에서 키 사용을 허용하는지 원문 · 무료 모델(학습 이용 조건)은 목록에서 빼거나 경고 ·
     오픈코드 Go 는 모델마다 호출 형식이 달라 처음엔 OpenAI 형식 모델만.
   - 그때까지 쌤핀 AI 의 Solar 경로는 업스테이지 정지로 사실상 멈춰 있다(ASSIST 키 별도 확인은 못 했다).

## 확인한 것 (2026-10-24)

- 로컬 WIF 교환 성공 · Models API: Haiku 5.5 `thinking.disabled.supported=true`, effort 5단계 지원 · 응답 1.3초 안팎, 지식 없이 물으면
  메뉴를 지어내지 않음(같은 질문에 Solar 는 지어냈다).
- 제미나이 임베딩: 1536차원·정규화, 100건 한 번에 성공, 관련 문서 코사인 0.80 vs 무관 0.63.
- 운영: 시크릿 7개 sha256 대조 일치 · 079/080 적용(554건 유지, 빈 벡터 0, HNSW 생성) · 배포 직후 글자 검색 경로로 정상 답변(200, 근거 3건).
- 27문항 시험 결과는 월별 진행 기록에 적는다.

## 되돌리기

- 답변만 되돌리기: Supabase 시크릿 `ANTHROPIC_WIF_SIGNING_JWK` 를 지우면 Gemini 단독으로 답한다.
- WIF 차단: 콘솔에서 규칙 `ssampin-chatbot` 보관(archive) 또는 워크스페이스 한도 0.
- 임베딩 공급자를 다시 바꾸려면 079 와 같은 순서(벡터 비우기 → 재적재 → not null)로. 차원이 바뀌면 HNSW 색인도 다시 만든다.
