# ADR-113: 지도 장면 차례를 초안에서 검증하고 생성 본문의 가운데점을 쉼표로 정규화

- 날짜: 2026-09-13
- 상태: 로컬 구현, 미배포

## 배경

독서와 작문 기존 예시로 Sol, Terra, Luna를 실행한 결과, 모델이 제안한 지도는 동기로 시작하고 평가로 끝났지만 Sol 초안은 평가 뒤에 발표 결과를 썼다. 요청서에는 실제 장면 차례와 충돌하는 결과 마무리 지시 및 평가 위치 지시가 있었다. 역할 이름만으로는 과정이 여러 번 나오는 장면 차례를 검증할 수 없었다. 사용자는 지도 차례를 초안에도 반영하고 나열의 가운데점 대신 쉼표를 쓰도록 요청했다.

## 결정

1. 지도에서 받은 장면 배열이 작성 순서다. 평가를 첫째, 가운데, 마지막에 둘 수 있고 결과 다음에 과정을 둘 수도 있다. 평가와 결과의 자리를 별도로 강제하지 않는다.
2. 장면 기반 생성은 역할과 함께 장면 번호를 응답에 받는다. 번호는 교사용 본문에서 제거하고 문단 메타데이터로 보존한다. 요청 차례와 다른 번호 또는 역할이면 적용을 막는다. 역할이 같은 장면끼리 임의로 재정렬하지 않는다.
3. 분량 조절에도 사용 가능한 장면 번호를 전달하고 검사한다. 직접 수정한 본문이 저장된 문단과 달라졌다면 예전 번호를 억지로 붙이지 않는다.
4. 생성된 초안과 분량 조절 결과의 가운데점 `·`, `ㆍ`, `・`, `‧`는 쉼표와 공백으로 바꾼다. 별칭 복원 후 처리하고 실제 저장될 본문으로 바이트를 센다. 근거 원문, 기존 초안, 교사가 직접 입력한 본문을 일괄 변경하지 않는다.

## 검증 범위

장면 번호와 역할의 순서 검사는 문장 내용의 의미까지 증명하지 않는다. 실제 독서와 작문 자료의 모델 응답을 각 장면 근거와 별도로 대조한다. 분량 목표 준수도 순서 검사와 별개이며 실제 바이트 결과를 기록한다. 자세한 명령과 결과는 월별 진행 기록에 남긴다.
