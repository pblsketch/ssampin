## Thread 2 (답글 1 / 7장 중 2)
**첨부 이미지**: `cards/02-sticker-autopaste.png`

```
1. 이모티콘 자동 Ctrl+V 붙여넣기 ⭐

이전엔 이모티콘 피커에서 골라도 다시 입력창으로 돌아와 Ctrl+V를 눌러야 했는데, 이번 버전부터는 OS 단에서 Ctrl+V까지 자동으로 입력돼 한 번에 붙습니다.

• 단축키(기본 Ctrl+Shift+E)로 피커 열기 → 이모티콘 클릭 → 끝
• 카톡·디스코드·슬랙·메모·한컴 어디서든 동일하게 동작
• libnut 기반으로 윈도우 표준 키 이벤트 발생, 일부 환경에서 차단되면 폴백 안내가 떠서 수동 Ctrl+V로 마무리

수업 중 학생 채팅·공지방에 반응 한 번 보내려고 손이 마우스로 갔다오던 시간이 사라집니다.
```

2. 이모티콘 다중 업로드·선택·ZIP 내보내기

이모티콘 관리도 일괄 작업 중심으로 바뀌었어요.

• 다중 업로드 — 한 번에 여러 PNG를 끌어 올리면 그대로 등록
• 다중 선택 — Ctrl/Shift로 여러 개 동시에 잡고 일괄 삭제
• ZIP 일괄 내보내기 — 보유한 이모티콘을 한 파일로 묶어 백업 또는 다른 PC로 이전
• 추가 진입점 통합 — 어디서 들어와도 동일한 화면

학기 초에 이모티콘 세트를 한 번에 옮겨두면 PC를 바꿔도 다시 모을 일이 없어요.

## Thread 4 (답글 3 / 7장 중 4)
**첨부 이미지**: `cards/04-sticker-kakao.png`

```
3. 카카오톡 호환 — 흰 배경 채우기 토글

투명 PNG를 카톡에 붙여넣으면 검정 배경으로 보이던 분들 계셨죠. 윈도우 표준 클립보드(CF_BITMAP)가 알파를 다루지 못해 카톡이 투명 영역을 검정으로 그려서 그래요.

• 설정 > 이모티콘 > "흰 배경 채우기 (카카오톡 호환)" 토글 신규
• 켜면 붙여넣기 직전에 알파를 흰 배경으로 합성 → 카톡에서도 정상
• 기본은 꺼짐 (투명 보존). 디스코드·슬랙·메모 등은 투명을 지원하므로 끄고 쓰는 게 더 깔끔
• 함께 정리한 피커 UX — 검정 오버레이 제거·카드 잘림 해소·다른 단축키 팝업과 시각 통일

카톡에서 검정으로 보일 때만 잠깐 켜두면 됩니다.
```

## Thread 5 (답글 4 / 7장 중 5)
**첨부 이미지**: `cards/05-mobile-class.png`

```
4. 모바일 수업 탭 — 출결과 진도 한 화면에서

기존 모바일 [출결 탭]을 [수업 탭]으로 확장했어요. 출결과 진도를 같은 화면에서 처리할 수 있습니다.

• 수업 목록 → 수업 상세에서 출결 체크와 진도 기록 동시 입력
• 모바일 홈의 [오늘 수업 중] 카드를 탭하면 진도 기록 모달이 바로 열림
• PC와 동일한 진도 데이터 — 모바일에서 입력해도 즉시 반영
• 차시 정보·진도 내용·메모를 휴대폰만으로 마무리

수업 중에 PC를 켤 새가 없을 때, 칠판 앞에서 한 손으로 기록을 끝낼 수 있어요.
```

5. "차단된 앱" 경고 우회 가이드

쌤핀을 처음 받으시는 분들 중 윈도우 SmartScreen이 "차단된 앱"으로 막아 실행이 안 되는 경우가 있어요. 인앱 안내와 챗봇 답변을 보강했습니다.

• ssampin-Setup.exe 우클릭 > [속성] > 일반 탭 하단 [차단 해제] 체크
• 다시 실행 → "PC 보호" 화면에서 [추가 정보] > [실행]
• 챗봇에 "차단된 앱"이라고만 물어봐도 동일한 안내 응답
• 출처는 GitHub 공식 릴리즈 페이지이므로 안전

새 학기에 동료 선생님께 추천할 때 같이 보내드리면 설치 첫 단계가 막히지 않습니다.
