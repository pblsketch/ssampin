# 쌤핀 '수업 관리' 인스타 카드뉴스 (2026-08)

2학기를 시작하는 선생님 대상 기능 소개 캐러셀. 릴리즈 카드뉴스가 아니라 **기능 소개용**이라
`CARD-NEWS-STYLE.md`(일러스트 기반 1:1)와는 별개 스타일을 쓴다.

## 스타일

레퍼런스는 인스타 `ai.asap.kr` 계열의 **검은 배경 + 큰 한글 타이포 + 실제 화면** 구성.

- 규격 1080×1350 (4:5)
- 배경 `#05070c` 기반, 위쪽에 파랑/앰버 미세 글로우
- 위 46% = 앱 화면 크롭, 아래 54% = 카피(제목 + 기능 설명 목록)
- 아이브로우: 앰버 `#f5a524` 세로 바 + 라벨
- 헤드라인 Pretendard ExtraBold 68px, 기능 목록 Medium 25px `#96a3b6` (강조어만 Bold `#dde4ee`)
- 기능 목록은 카드당 4줄까지. 앰버 점 마커 + 왼쪽 정렬
- 하단 중앙 서명 `쌤핀 / 선생님의 학급 운영 대시보드`
- **전체 화면을 쓰지 않는다.** 사이드바·창 테두리·작업 표시줄을 빼고 해당 기능 영역만 크롭한다.

## 폴더

```
config.json 크롭 좌표 · 카드 문구 · 클립 구간 (여기만 고치면 전부 다시 나옴)
cards/     최종 카드 6장 (card-01 ~ card-06.png)
clips/     영상 슬라이드 2개 — 3번·4번 카드와 교체 가능
crops/     영상에서 잘라낸 UI 소재 PNG
src/       카드 템플릿(card.html), Pretendard 폰트, 영상 합성용 바탕/마스크
caption.md 게시 순서 · 캡션 · 해시태그
```

## 다시 만드는 법

이 폴더는 **`insta-card` 스킬**로 만들었다. 스타일 스펙과 함정 모음은 스킬 쪽이 정본이다.

- `.claude/skills/insta-card/references/style.md` — 디자인 스펙(잠금) · config 스키마
- `.claude/skills/insta-card/references/pitfalls.md` — 실제로 겪은 함정

`config.json` 하나가 크롭 좌표 · 카드 문구 · 클립 구간을 전부 들고 있다.

```bash
node .claude/skills/insta-card/scripts/crop.mjs  docs/release-notes-assets/class-management-2026-08/config.json
node .claude/skills/insta-card/scripts/build.mjs docs/release-notes-assets/class-management-2026-08/config.json --review --review-clips
```

`src/` 안의 `card.html` · 폰트 · 마스코트는 스킬에서 복사돼 온 것이라
직접 고치지 말고 **스킬 쪽 `assets/card.html`을 고친 뒤 다시 빌드**한다.

### 영상 구간 (녹화본 기준 초)

| 구간       | 내용                                                        |
| ---------- | ----------------------------------------------------------- |
| 12 ~ 24    | 수업 기록 — 출결 찍기, 특기사항, 통계                       |
| 91 ~ 99.5  | 좌석배치 — 행·열 조절, 랜덤 배치, 짝꿍                      |
| 99.5 ~ 102 | 이름 학습 얼굴 카드 그리드                                  |
| 102 ~ 108  | 이름 학습 '매칭하기' — 얼굴 보고 명단에서 고르기, 정답 공개 |
| 108 ~ 118  | 이름 학습 '이름 쓰기' (현재 클립에는 안 넣음)               |
| 163 ~ 168  | 수행평가 · 학교명 노출 — **쓰지 않음**                      |

클립 4번의 `blur` 항목이 **이름 학습 얼굴 카드에 박힌 이름을 가리는 부분**이다.
크롭 좌표계(975×585) 기준 `x=50 y=335 w=250 h=100`, '매칭하기'가 뜨는 10.6초부터 걸린다.

## 지켜야 할 것

- **쌤핀 링크(ssampin.com)를 카드에 노출하지 않는다.** 댓글 '쌤핀'으로 유도하는 게시물이다.
- **내보내기 형식은 한글(.hwpx)·엑셀(.xlsx) 두 가지다. PDF는 없다.**
  자리배치도는 `ClassSeatingTab.tsx`, 생기부 초안은 `RecordDraftExportModal.tsx`
  (초안은 '나이스 붙여넣기' 복사가 하나 더 있다).
- **수행평가·성적 탭은 소개하지 않는다.** 크롭에서 두 탭이 잘려 나가도록 잡았다.
- **개인정보** — 녹화의 명단은 `가가가`·`가나가` 같은 더미다. 다만 `이름 학습` 얼굴 카드의
  일러스트에는 이름이 그림 안에 박혀 있다(옷 부분, 원본 기준 5~6px). 카드/클립 크기에서는
  읽히지 않지만, 크게 확대하는 컷은 쓰지 않는다. 학교명이 보이는 **수행평가 > 평가계획에서
  불러오기** 화면(영상 163~168초)은 쓰지 않는다.
- 사이드바에 담임 교사 이름이 있어 크롭 범위를 `x≥645`로 잡았다.
