## Thread 2 (답글 1 / 8장 중 2)
**첨부 이미지**: `cards/02-native-desktop.png`

```
1. 바탕화면 아이콘 아래 모드 — 위젯이 진짜 작업판이 됩니다 ⭐

위젯이 일반 창이 아니라 '진짜 바탕화면 작업판'처럼 깔립니다. 윈도우키+D로 모든 창을 내려도 위젯은 그대로 보이고, 바탕화면 아이콘 위 클릭은 통과해 폴더가 평소처럼 열려요.

• 위젯 빈 공간 위에서는 클릭·휠·드래그 모두 위젯으로 라우팅
• 가장자리 8방향(상하좌우 + 네 모서리) 자유 리사이즈
• 헤더 잡고 드래그로 위치 이동
• 위젯 위에 마우스를 올린 동안 Ctrl+1~4로 레이아웃 즉석 전환

설정 > 위젯 > [바탕화면 아이콘 아래 모드] 토글로 켜세요. (Windows 11 24H2 검증 완료, macOS·리눅스에서는 비활성)
```

```
2. NEIS → 구글 캘린더 자동 동기화 제안

NEIS 학사일정을 구글 캘린더에도 비추고 싶다는 요청이 많아 자동 동기화 제안 배너가 4곳에서 떠요.

• 옛 NEIS 일정(메타데이터 없음)도 자동 마이그레이션·중복 제거

NEIS와 구글 캘린더 양쪽을 따로 관리하시던 분들께 한 번에 정리할 수 있는 길이 열렸어요.
```

```
5. macOS Tahoe 정식 지원 + Tasks 쿼터 폭주 차단

안정성 두 가지를 같이 정리했어요.

• macOS Tahoe(26.x) 정식 지원 — Electron 32→40.9.3 메이저 업그레이드. 한글 입력 깨짐·창 transparency·Always on Top 모두 정식 지원
• arm64(Apple Silicon)·x64(Intel) DMG 모두 제공

• 429 응답 시 Retry-After + 지수 백오프로 일시적 429 흡수
• 일일 쿼터 한도 감지 시 다음날 새벽 4시까지 silent skip

휴대폰 Google Tasks 앱과 PC 쌤핀을 자주 오가며 쓰는 환경에서 동기화가 안정됩니다.
```

## Thread 7 (답글 6 / 8장 중 7)
**첨부 이미지**: `cards/07-widget-stability.png`

```
6. 위젯 안정화 — 외곽선 토글 + opacity=0 함정 차단

위젯 자체의 가독성·안전성도 같이 손봤어요.

• 위젯 외곽선 표시 토글 — 위젯 경계가 또렷하게 보여 다른 창과 명확히 구분
• 가장자리 호버 시에만 스크롤바 — 평상시 깔끔, 필요할 때 가시성
• 투명도 슬라이더 4곳 min=0% 영구 정합화 — 실수로 0%까지 내려서 위젯이 영구 invisible 되던 회귀 영구 봉쇄
• OS alpha 누수도 함께 차단 — 투명도는 CSS 배경 rgba 단일 경로로만 적용

위젯 모드를 자주 쓰시는 분들이 가장 환영하실 변경입니다.
```
