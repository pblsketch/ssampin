## Thread 2 (답글 1 / 총 8장 중 2)
**첨부 이미지**: `cards/02-학급-명렬-가져오기-학생-id-자동-보존.png`

```
1. 학급 명렬 가져오기 — 학생 ID 자동 보존

학급 명렬을 다시 가져와도 학생기록·좌석·과제 제출 등 외부 참조가 끊기지 않습니다. 이름과 학번 매칭으로 같은 학생을 자동 식별하고, 부분 매칭(이름·학번 중 하나만 일치)이 발견되면 충돌 해결 모달이 떠서 직접 결정할 수 있어요.

· 매칭 우선순위: 이름+학번 일치 → 학번 같음 이름 다름 → 이름 같은 활성 학생 → 이름 같은 비활성 학생
· 충돌 해결 모달: TYPE 배지로 한눈에 분류, 4가지 액션(교체/추가/병합/건너뛰기) + 일괄 적용
· 부분 매칭이 없으면 자동 적용, 1건 이상이면 모달로 결정 위임

[담임 업무 > 명렬관리]에서 엑셀 일괄 가져오기 시 자동 동작합니다.

학기 중간에 전입생을 추가하거나 명렬을 갱신해도 누적된 상담 기록·자리 배치가 그대로 살아 있어요.
```

```
2. 학생 수 줄일 때 안전 확인 모달
```

## Thread 4 (답글 3 / 총 8장 중 4)
**첨부 이미지**: `cards/04-수업반-학생-동기화-모드-그룹-분리-옵션.png`

```
3. 수업반 학생 동기화 모드 — 그룹 분리 옵션

같은 그룹의 수업반들이 자동으로 학생 명단을 공유하는 동작은 그대로 유지하면서, 특정 수업반만 다른 명단을 쓸 수 있는 옵션이 추가됐어요. 영어 수준별 분반·음악 선택반처럼 한 학급에서 다른 명단을 쓰는 수업에 어울려요.

· 그룹 안내 배너에 [다른 명단 사용] 토글
· 토글 ON: 그룹 자동 동기화에서 해당 수업반만 제외
· 토글 OFF (기본): 같은 그룹의 다른 수업반과 명단 자동 공유 (이전과 동일)

[수업 관리 > 명렬 관리] 그룹 안내 배너에서 토글하세요.

수준별·선택반 운영하시는 분들께 단일 학급 안에서도 유연하게 명단을 관리할 길이 열렸어요.
```

```
4. 담임반 → 수업반 학생 명단 복사 액션

담임반 학생을 새로 만든 수업반으로 한 번에 복사할 수 있는 액션이 신설됐어요. 기존에는 담임반과 수업반 명렬이 분리되어 있어서 일일이 다시 입력해야 했는데, 이제 활성 학생만 골라서 일괄 복사할 수 있습니다.

· 활성 학생 카운트 + 대상 수업반 선택
· 2단계 confirm — 현재 명단을 교체한다는 경고 명시
· 학생기록·좌석은 기존 수업반 ID 보존 → 복사 후에도 유지

[설정 > 학교/학급 정보 > 명렬 데이터 도구]에서 사용하세요.

학기 초 수업반 만들 때 담임반 명렬을 다시 입력하던 시간을 크게 줄여드려요.
```
