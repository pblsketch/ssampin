```
2. 어디든 잡고 드래그 — 마우스가 밖으로 나가도 끊기지 않아요

핀 캐릭터를 마우스로 잡고 어디든 옮길 수 있는데, 빠르게 움직여 윈도우 밖으로 나가도 드래그가 끊기지 않습니다.

• main 프로세스가 OS 레벨에서 마우스 위치를 직접 추적해 pointer capture에 의존하지 않음
• 위치는 자동 저장되어 다음 실행 때도 유지
• 모니터 분리·해제 시 화면 밖으로 사라지면 자동 보정
• 트레이 우클릭 또는 핀 우클릭 > [아이콘 위치 초기화]로 우하단 기본 위치 복귀

듀얼 모니터를 자주 바꿔 쓰는 환경에서도 핀이 미아가 되지 않습니다.
```

```
판서 화면 위에 시간표·할일 카드를 띄워두고 수업하시는 분들께 유용해요.
```

## Thread 5 (답글 4 / 8장 중 5)
**첨부 이미지**: `cards/05-google-tasks.png`

```
4. Google Tasks 동기화 — 신규 할일 사라짐 + 좀비 부활 해결

Google Tasks 양방향 연동에서 두 가지 골치 아픈 버그가 있었는데, 이번에 근본부터 다시 짰어요.

• 사라짐 — 새로 추가한 할일이 동기화 직후 갑자기 사라지던 race
• 좀비 부활 — 아카이브한 할일이 다음 동기화 때 살아 돌아오던 문제
• Push-Before-Pull 5단계 파이프라인(PRE-FLIGHT → PUSH-DELETE → PUSH-CREATE → PUSH-UPDATE → PULL → RECONCILE)
• Tombstone + Read-After-Write Reconciliation으로 양방향 정합성 보장

휴대폰 Google Tasks 앱과 PC 쌤핀을 오가며 쓰셔도 이젠 데이터가 어긋나지 않습니다.
```

## Thread 6 (답글 5 / 8장 중 6)
**첨부 이미지**: `cards/06-oauth-fix.png`

```
5. Google 인증 흐름 안정화

Google 캘린더·드라이브·Tasks 인증을 시작하면 가끔 무한로딩에 빠지던 문제가 있었어요. IPC 응답 구조를 단일 응답으로 다시 설계해서 해소했습니다.

• 메인 인증 플로우 무한로딩 해소
• completeAuth가 hang하던 문제 차단
• PKCE OOB → loopback 교체로 안정성 개선
• 연속 클릭 race 차단 + 인증 진행 중 [취소] 버튼 추가
• 자동 인증이 안 되는 환경 대비 PKCE 수동 인증 전환 버튼

새 PC에서 첫 로그인할 때 막혔던 분들도 이젠 한 번에 통과하실 수 있어요.
```
