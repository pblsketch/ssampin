## Thread 2 (답글 1 / 총 5장 중 2)

**첨부 이미지**: `cards/02-여러-날짜-출결-한-번에-입력.png`

```
1. 여러 날짜 출결 한 번에 입력

출장·체험학습·연속 결석처럼 며칠치 출결을 한 번에 처리해야 할 때, 이제 여러 날짜를 골라 한 번에 같은 상태를 적용할 수 있어요.

· 날짜 다중 선택 → 학생 선택 → 출결 상태 한 번에 적용
· 같은 학생이 여러 날짜에 다른 상태를 가져도 안전하게 처리
· 기존 기록을 덮어쓸지 명확히 확인

[담임 업무 > 출결]에서 [여러 날짜 입력] 모드로 진입해 보세요.

수련회 끝나고 3일치 출결을 하루씩 들어가서 같은 클릭 반복하던 시간이 사라져요.
```

## Thread 3 (답글 2 / 총 5장 중 3)

**첨부 이미지**: `cards/03-상담-예약-수정취소-자동동기화.png`

```
2. 상담 예약 수정·취소 + 일정 자동 동기화

한 번 잡힌 상담 예약을 담임과 학부모 양쪽에서 수정·취소할 수 있게 됐어요.

· 담임 — 일정 상세에서 직접 수정/취소
· 학부모 — 예약 확정 후 받은 셀프 링크로 본인이 변경·취소
· 변경 시 양쪽에 안내 메시지 자동 전송
· 학부모용 토큰은 예약별 발급 — 다른 학부모 일정은 접근 불가

⭐ 상담 가능 시간을 일정표에서 바꾸기만 해도 학부모 예약 페이지의 빈 슬롯이 즉시 따라옵니다. 이미 예약된 슬롯은 보호되고, 중복 예약도 차단돼요.

학부모가 "시간 바꿔주세요" 문자를 보낼 때마다 일일이 처리하던 부담이 사라져요.
```

3. 업데이트 알림 통제권 + amber 가독성 회복

"매일 떠서 번거롭다"는 피드백을 받아 업데이트 안내 모달의 표시 정책을 통째로 다시 설계했어요.

앞으로는 정말 새 기능이 도착했을 때 한 번만 알려드려요.
