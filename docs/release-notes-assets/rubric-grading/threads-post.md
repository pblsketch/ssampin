# 쌤핀 '수행평가 채점' 기능 소개 Threads 타래

> **사용법**: 각 타래(Thread 1~6)를 순서대로 Threads에 게시하고, **각 타래에 대응하는 카드 이미지를 첨부**하세요. Thread 2~6은 Thread 1의 답글(reply)로 연결해 타래로 만듭니다.
> **첨부 이미지**: `cards/01-intro.png` ~ `cards/06-outro.png`
> **글자 수**: 각 포스트 500자 이내 (Threads 제한)
> **스타일**: `docs/release-notes-assets/THREADS-POST-STYLE.md` 준수 (v1.10.2 고정 어투)
> **버전 메모**: 기능은 main에 구현 완료(다음 릴리즈 **v2.1.2** 묶음 예정), 정식 릴리즈 전 — CTA는 "곧 만나보세요" 톤. 출시 후 게시하려면 마지막 타래를 "지금 바로 업데이트해 보세요"로 교체.

## Thread 2 (답글 1 / 6장 중 2)

**첨부 이미지**: `cards/02-builder.png`

```
1. 루브릭 빌더 — 나만의 채점 기준표를 그대로

평가 요소마다 자기만의 수준을 따로 둘 수 있어요. '주장의 명확성'은 4단계, '근거의 타당성'은 2단계처럼, 요소마다 수준 개수·이름·배점을 다르게 설정합니다.

• 수준마다 배점과 성취 설명 (예: "근거 3개 이상 제시")
• 새 요소를 추가하면 직전 요소의 수준 구성을 그대로 복제
• 수업반당 루브릭 최대 10개

쓰던 종이 채점표를 화면에 그대로 옮겨 담는 느낌이에요.
```

## Thread 3 (답글 2 / 6장 중 3)

**첨부 이미지**: `cards/03-grading.png`

```
2. 채점 화면 — 모든 평가 요소가 한 화면에 ⭐

왼쪽엔 학생 명단(완료·부분·결시 표시와 합계 미리보기), 오른쪽엔 선택한 학생의 루브릭이 한눈에 들어와요. 수준을 클릭하면 바로 저장되고 합계도 자동으로 갱신됩니다.

• 요소별 특이사항 메모 + 학생별 총평
• '결시' 표시 — 채점에서 빠지고 합계에서도 제외
• ↑↓ 키로 학생 빠르게 이동

발표를 들으면서 클릭만 하면 채점이 끝나요.
```

## Thread 4 (답글 3 / 6장 중 4)

**첨부 이미지**: `cards/04-export.png`

```
3. 결과를 그대로 내보내기 — 엑셀과 학생 평가지

채점이 끝나면 두 가지로 내보낼 수 있어요.

• 엑셀: 번호·이름·요소별 점수·합계 — 나이스 일괄 입력용. 미채점·결시는 0점이 아니라 빈칸으로 둡니다.
• 평가지(PDF·한글): 현장 채점기준표 양식 그대로. '점수 포함'을 끄면 점수 없이 피드백만 담은 형성평가용 평가지가 됩니다.

내보내기 전에 미리보기로 결과물을 바로 확인할 수 있어요.
```

## Thread 5 (답글 4 / 6장 중 5)

**첨부 이미지**: `cards/05-copy.png`

```
4. 다른 반에 복사 — 같은 평가를 여러 반에

한 반에서 만든 루브릭을 다른 수업반에 그대로 복사할 수 있어요. 여러 반을 한 번에 선택하면 각 반에 독립된 사본이 만들어집니다.

• 평가 요소·수준·배점만 복제 (채점 기록은 따라가지 않아요)
• 복사한 뒤 한쪽을 고쳐도 다른 반엔 영향 없음

여러 반에서 같은 수행평가를 하는 중등 선생님께 특히 도움이 됩니다.
```
