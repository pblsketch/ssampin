# v2.2.14 릴리즈 노트 초안 (오너 GO 대기)

> 범위: v2.2.13 이후 ~ `4024b138` (수업반 보관 기능 제외 — 그건 v2.3.0)
> 성격: **데이터 보호·안정화 패치** (전부 수정, 신기능 없음)

## 헤드라인 (사용자 언어)

**"기기 여러 대를 오가며 써도 기록이 사라지거나 되살아나지 않도록, 동기화와 저장의 구멍을 대대적으로 막았습니다."**

## 고치거나 막은 것

### 동기화·데이터 보호

- **모바일 다운로드가 영영 안 되던 문제** — 업로드할 게 없어도 장부를 다시 쓰면서 "받은 적 없는 항목을 받았다"고 기록하던 결함을 수정. 재로그인으로도 안 풀리던 증상이 해소됩니다. (ADR-024)
- **지운 학생 기록이 다른 기기에서 되살아나던 문제** — 삭제 표식(툼스톤)을 도입해 삭제가 모든 기기로 전파됩니다. (ADR-028)
- **출결 기록을 지웠는데 다른 화면·기기에 남아 있던 문제** — 삭제가 원본 출결부까지 반영되고, 실패하면 어느 쪽도 지우지 않습니다. (ADR-027)
- **동기화 2차 하드닝** — 같은 파일을 동시에 저장할 때의 충돌 보호(파일 락·변경 의도 저장·항목 단위 병합). 두 기기에서 같은 시간대에 입력해도 기록 단위로 안전하게 합쳐집니다. (ADR-023)
- **저장이 조용히 실패하던 3경로 표면화** — 저장이 차단됐는데 "저장됨 ✓"으로 보이던 거짓 표시를 제거하고 실패를 알립니다.
- **폰(PWA)에서 앱을 백그라운드로 보낼 때 마지막 입력이 유실되던 문제** — 저장이 끝나기 전 업로드가 시작되지 않도록 보호 장치를 추가했습니다.

### 모바일 담임 출결

- **"우리 반 체크하기"에 학생 명단이 안 뜨던 문제** — 명단 원천을 담임 명렬표로 바로잡았습니다. 빈 명단이 실수로 저장되어 PC 출결을 지우는 경로도 함께 차단. (ADR-026)

### 아이콘 모드

- 안내 말풍선이 계속 떠서 화면을 가리던 고착 해소 + 위젯 설정이 기본값으로 덮이던 문제 차단. (ADR-025)
- 커서를 올리면 아이콘 잔상이 깜빡이던 문제, 드래그가 때때로 안 되던 문제, "345분 후" 같은 시간 표기를 "5시간 45분 후"로 수정.

### 화면·기타

- 일정 카테고리 색을 수정할 수 없던 문제 + 설정에서도 색 변경 지원 + 라이트 모드에서 옅은 색 글씨가 안 보이던 가독성 근본 개선.
- CI 46일 연속 실패 해소, 보안 의존성 업데이트.
