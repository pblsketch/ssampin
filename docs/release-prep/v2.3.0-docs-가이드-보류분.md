## 출시 때 추가로 넣으면 좋을 내용 (아직 안 쓴 것 — 학년도 마무리·보관함)

P2·P3 기능(학년도 마무리 마법사·보관함 뷰어)은 아직 /docs에 없다. 출시 범위에 포함된다면 신규 챕터를 하나 만드는 것을 권한다:

- **"학년도 마무리와 보관함"**(features 카테고리) — 4단계 안내, 무엇이 보관되고 무엇이 유지되는지, **학년도 중간에도 실행 가능하지만 통계가 나뉜다는 점**, 전환 취소·회차 재보관, **보관함은 이 PC 기준이며 백업 파일로 옮길 수 있다는 제약**.
- `sync/data-location`·`sync/google-drive`·`troubleshooting/google-sync`에 각각 한 줄: 보관함 폴더(`archives/`)·전환 후 다른 기기에서 할 일·"전환했는데 다른 기기에 옛 데이터가 보여요" 복구 절차.
- FAQ 1건: "보관한 학년도를 지울 수 있나요?" → 2단계 확인 + **이 PC 기준 삭제**(클라우드 사본은 다음 동기화에 되돌아올 수 있음).
