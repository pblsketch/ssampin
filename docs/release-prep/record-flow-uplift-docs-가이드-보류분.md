## 문구 금지 사항 (릴리즈 노트·가이드 공통)

점검 경고는 **막지 않는다.** 그래서 아래 표현은 사실이 아니므로 쓰지 않는다.

| ❌ 쓰지 말 것                      | ✅ 사실                                    |
| ---------------------------------- | ------------------------------------------ |
| "금지 항목을 걸러 준다"            | "눈에 띄게 알려 준다"                      |
| "규정 위반을 막아 준다"            | "저장은 그대로 되고, 판단은 선생님 몫이다" |
| "AI가 규정을 지켜서 써 준다"       | "경고를 달아 줄 뿐이다"                    |
| "잘못된 문장을 자동으로 고쳐 준다" | "어떤 문장이 걸렸는지 갈래로 적어 준다"    |

이유: 6종 전부 **경고(flag)** 이고 저장을 막지 않는다. "체육대회 참여"처럼 정상 서술도 걸린다.
막는다고 적으면 선생님이 경고가 없는 것을 "통과"로 오해한다 — 그것이 가장 위험하다.
