## 새 기능 — 수업반 보관

- **보관하기**: 수업반 카드 메뉴(⋮)의 "보관" 또는 체크박스로 여러 반을 골라 **한 번에 보관**. 목록 하단 "보관된 수업반" 칸으로 이동하며 학기·교실별로 정리되어 보입니다.
- **그대로 열람**: 보관된 반을 누르면 출결·진도·기록이 전부 그대로 보입니다(읽기 전용). 새로 입력만 막습니다.
- **언제든 복원**: "보관 해제" 한 번이면 활성 목록 맨 아래로 돌아옵니다.
- **새 기록이 옛 반으로 새지 않게**: 같은 이름으로 새 학기 반을 만들어도, 진도 위젯·알림·도구 명렬·AI 브릿지가 **활성 반에만** 기록하도록 전면 정비했습니다.
- **개별 보관이 기본**: 같은 반의 다른 과목은 함께 보관되지 않습니다. 필요한 과목만 골라 정리하세요.

## 알아두세요 (릴리즈 노트 필수 고지)

- **구버전 앱에서는 보관된 반이 그대로 활성으로 보입니다.** 여러 기기를 쓰신다면 모두 v2.3.0으로 업데이트해 주세요. (구버전이 저장해도 보관 정보는 사라지지 않습니다)
- 보관하기 전에 폰·다른 PC를 먼저 동기화해 두시는 걸 권장합니다.
- 시간표는 자동으로 바뀌지 않습니다 — 새 학기 시간표는 시간표 불러오기로 따로 갱신해 주세요.
