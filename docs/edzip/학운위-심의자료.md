쌤핀 본체는 교사만 사용합니다. 다만 아래 기능을 교사가 켰을 때만 학생·보호자가
웹 주소로 접속합니다. 켜지 않으면 어떤 데이터도 외부로 나가지 않습니다.

| 기능            | 접속 주소           | 학생·보호자가 입력하는 정보             |

> 위 4개 화면 모두 하단에 개인정보처리방침·이용약관 링크가 노출됩니다.

## 2. 필수기준 대응 (5개 항목)

### ① 최소처리 원칙 — 수집 항목·목적·보유기간 명시

**대응: 개인정보처리방침 제1조·제2조·제4조**

- 제1조 가목에 교사가 입력하는 학생 정보를 항목별로 모두 적었습니다.
  - 학생 기본 정보: 이름, 학번, 생년월일, 학생 연락처, 보호자 연락처(최대 2인)와 관계, 재적 상태
  - 출결 기록: 날짜, 교시, 출결 구분, 사유, 증빙 서류 여부, NEIS 반영 여부
  - 관찰·상담 기록: 분류, 내용, 날짜, 상담 방법, 후속 조치
  - 학급 운영 자료: 시간표, 자리 배치, 진도, 과제 제출 현황, 설문 응답, 평가 기록
- **모든 항목이 선택 입력**입니다. 입력하지 않아도 프로그램이 동작하므로,
  학교 방침에 따라 필요한 항목만 쓰실 수 있습니다.
- 보유기간: 교사가 삭제하거나 프로그램을 제거할 때까지. 학년도 마무리 기능을
  실행하면 보관함으로 옮겨집니다.

### ② 안전조치 의무

**대응: 개인정보처리방침 제14조** (개인정보 보호법 제29조)

- **기술적** — 전 구간 HTTPS(TLS) 암호화 및 HTTP 강제 전환(HSTS), 인증 토큰
  OS 키체인 암호화 저장, 클라우드 토큰 AES-256-GCM 암호화, 상담 예약 연락처·메모는
  교사 단말에서 암호화 후 전송, 클라우드 자료 행 수준 접근 제어(RLS),
  전자 서명의 접속 IP·기기정보는 해시로만 저장,
  웹 보안 헤더 5종(CSP·X-Frame-Options·X-Content-Type-Options·Referrer-Policy·Permissions-Policy) 적용
- **관리적** — 개인정보 취급 인원 1인으로 한정, 서버 전용 비밀키는 이용자
  브라우저로 내려가는 코드에 미포함, 외부 보안 점검 도구로 정기 점검
- **물리적** — 자체 서버 미운영. 학생 정보 원본은 교사 PC에 있으며,
  클라우드 설비 물리보안은 해당 사업자 기준을 따름

### ③ 열람·정정·삭제·처리정지 절차

**대응: 개인정보처리방침 제7조** (개인정보 보호법 제35~37조)

- 네 가지 권리(**열람·정정·삭제·처리정지**)를 모두 안내합니다.
- **처리 기한: 요구를 받은 날부터 10일 이내** 조치 후 결과 통지.
  기한 내 어려우면 사유와 예상 기간을 먼저 통지합니다.
- 학생·보호자 요구는 **담당 교사 또는 학교**가 1차 창구이며,
  온라인 협업 기능에 남은 정보는 pblsketch@gmail.com 으로도 요구 가능합니다.
