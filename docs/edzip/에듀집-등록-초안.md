## 필수기준 준수 여부

### 1-1. 최소한의 개인정보만 수집 — **준수**

쌤핀은 교사용 업무 도구로, 학생 계정을 만들지 않으며 학생으로부터 직접 정보를
수집하지 않습니다. 교사가 학급 운영에 필요한 정보를 직접 입력하며,
**모든 항목이 선택 입력**이라 입력하지 않아도 프로그램이 동작합니다.
프로그램 본체의 데이터는 교사 PC에만 저장됩니다. 외부로 나가는 경로는 세 갈래이며
모두 교사가 그 기능을 쓸 때만 동작합니다(제11조 처리위탁).

- 과제 수합·설문·상담 예약·전자 서명 등 협업 기능 → 필요한 범위의 자료가 Supabase로 전송
- AI 도우미(앱 내 도움말 챗봇) → 교사가 입력한 질문 문장과 직전 대화가 답변 생성을 위해
  주식회사 업스테이지·Google LLC로 전송(앱에 저장된 학생 자료는 전송되지 않음)
- 건의사항 보내기 → 작성 내용·회신 이메일(선택)·직전 대화·첨부 스크린샷이 저장되고
  개발자에게 이메일로 전달

- 증빙: 개인정보처리방침 제1조 가목, 제3조

### 1-2. 수집·이용 목적 명시 — **준수**

처리 목적을 항목별로 방침에 기재했습니다(학급 운영, 출결·상담 기록 관리,
교사가 선택한 Google 연동 동기화). 마케팅·광고·제3자 분석·기계학습 학습에는
일절 사용하지 않음을 명시했습니다.

- 증빙: 개인정보처리방침 제2조

### 1-3. 수집 항목·보유기간 고지 — **준수**

수집 항목을 4개 묶음으로 모두 나열했습니다(학생 기본 정보 / 출결 기록 /
관찰·상담 기록 / 학급 운영 자료). 보유기간은 "교사가 삭제하거나 프로그램을
제거할 때까지, 학년도 마무리 시 보관함 이동"으로 기재했습니다.

- 증빙: 개인정보처리방침 제1조, 제4조

### 2-1. 개인정보 안전조치 — **준수**

기술적·관리적·물리적 조치를 방침에 독립 조항으로 기재했습니다.

- 전송 구간 HTTPS(TLS) 암호화 및 HTTP 강제 전환(HSTS)
- 인증 토큰 OS 키체인 암호화, 클라우드 토큰 AES-256-GCM
- 상담 예약 연락처·메모는 교사 단말에서 암호화 후 전송
- 클라우드 자료 행 수준 접근 제어(RLS)
- 전자 서명 접속 IP·기기정보는 해시로만 저장
- 웹 보안 헤더 5종 적용(CSP, X-Frame-Options, X-Content-Type-Options,
  Referrer-Policy, Permissions-Policy)
- 증빙: 개인정보처리방침 제14조 (개인정보 보호법 제29조)

### 3-1. 열람·정정·삭제·처리정지 절차 — **준수**

네 가지 권리를 모두 안내하고, **10일 이내 처리** 기한과 접수 창구를
방침에 기재했습니다. 학생·보호자는 담당 교사 또는 학교를 통해서도,
개발자 연락처로도 요구할 수 있습니다.

- 증빙: 개인정보처리방침 제7조 (개인정보 보호법 제35~37조)

### 4-1. 만 14세 미만 아동 보호 — **준수**

이용자를 교사로 한정해 아동으로부터 직접 개인정보를 수집하지 않습니다.
프로그램 본체의 학생 정보는 교사 PC에 로컬 저장되며, 상담 예약·설문·체크리스트에서는
학생을 실명이 아닌 **학생 번호로만** 식별합니다. 과제 수합·전자 서명은 기능 특성상
학생 이름이 포함되므로 필요한 범위에서만 쓰고 목적 달성 후 삭제하도록 안내합니다.

- 증빙: 개인정보처리방침 제12조 (개인정보 보호법 제22조의2)

### 5-1. 개인정보 보호책임자 지정 — **준수**

보호책임자와 연락처, 침해신고센터·분쟁조정위원회 안내를 기재했습니다.

- 증빙: 개인정보처리방침 제15조 (개인정보 보호법 제31조)

### 5-2. 제3자 제공 — **준수 (해당 없음)**

개인정보를 제3자에게 제공·판매하지 않으며, 방침에 그 사실을 명시했습니다.

- 증빙: 개인정보처리방침 제5조 (개인정보 보호법 제17조)

### 5-3. 처리 위탁 및 국외 이전 — **준수**

교사가 온라인 협업 기능을 사용할 때에 한해 아래 사업자에 처리를 위탁하며,
위탁 업무와 국외이전 사실을 방침에 공개했습니다.

| 수탁자        | 위탁 업무                                                      | 소재 |
| ------------- | -------------------------------------------------------------- | ---- |
| Supabase Inc. | 협업 기능(상담 예약·과제 수합·전자 서명·설문) 데이터 저장·처리 | 미국 |
| Vercel Inc.   | 협업 기능 웹페이지 호스팅                                      | 미국 |
| Google LLC    | 교사가 연동을 켠 경우 캘린더·Drive 백업·Tasks 처리             | 미국 |

- 증빙: 개인정보처리방침 제11조, 제13조 (개인정보 보호법 제26조, 제28조의8)
