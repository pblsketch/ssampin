## 2. 자료를 읽고 수정한 판단

### 대학의 평가요소와 한 문단의 구성 요소는 다르다

연세대는 학업·진로·공동체를 학교생활 전체에서 평가하며, 세특의 분량만으로 판단하지 않는다고 설명한다(S3). 세특 문단마다 세 역량을 모두 넣거나 동일 비율로 배분할 이유는 없다. 특정 대학의 배점을 생기부 작성 분량으로 환산하지 않는다.

중앙대는 진로가 바뀌는 것을 자연스러운 과정으로 설명하고, AI 문장의 완성도보다 실제 경험·학습 및 교사의 관찰·평가를 강조한다(S5, 28쪽). 모든 과목을 하나의 희망 직업에 억지로 연결하는 기능은 제안하지 않는다.

### '교사 평가 먼저'는 시작 방식으로 분리한다

이전 후보 목록에는 평가 위치, 학습 과정, 기록 영역이 같은 수준에서 섞여 있었다. v2에서는 기존 평가 선두 방침을 선택 가능한 시작 방식으로 보존한다. 성취형도 성장형도 평가로 시작할 수 있다. 다른 시작 방식 허용은 후속 ADR 결정 사항이다.

### 하나의 탐구 줄거리로 모두 연결하지 않는다

S6의 143~144쪽은 서로 다른 평가 과제의 수행을 한 기록에 담는다. '관련 활동을 단순 나열하지 말라'는 원칙이 모든 활동 사이에 인과관계를 만들라는 뜻은 아니다. 독립된 과제는 각각 관찰된 성취를 중심으로 묶는다.

### 동국대 자료로 보완한 수업 맥락과 근거 출처

S8 32~33쪽은 평가 정보가 학생의 성취를 이해하는 맥락을 제공하며, 교과의 핵심 개념과 일상 수업의 관찰도 중요하다고 설명한다. S9 2~5쪽은 수행평가 영역명을 주제·내용과 방법으로 구성하도록 안내한다. 이를 제품 설계에 적용하여 **수업 맥락과 학생 개인의 수행을 분리**한다.

- 수업 맥락: 무엇을 배우는 수업인지, 어떤 과제·방법으로 확인했는지, 제공된 평가 기준은 무엇인지. 같은 수업의 학생에게 재사용할 수 있는 선택 정보다.
- 개인 근거: 학생이 실제로 선택·설명·수정·기여한 내용. 수업 목표나 과제 안내만으로 달성했다고 추정하지 않는다.
- 서술 초점: 개인 근거를 T1~T8 중 어떤 관점으로 정리할지. 동일한 주제와 수행 방법에서도 초점이 달라질 수 있다.

맥락은 기존 자료에서 먼저 가져오고 새 필수 입력을 늘리지 않는다. 주제나 평가명이 없다고 관찰 본문 입력을 막지 않는다. 맥락은 AI의 이해를 돕되 모든 기록에 같은 수업 소개 문장을 자동 삽입하지 않는다.

S8 69쪽은 진로 변경 뒤의 탐색 노력을 긍정적으로 평가한 사례를 보여 준다. T8에서 진로 일관성을 강제하지 않을 근거로 참고하되, 이 한 사례를 대학 전체의 합격 공식으로 일반화하지 않는다. 또한 평가표가 근거의 기록 영역을 구별하므로, 쌤핀도 학생 진술·교사 관찰·산출물·교사 판단의 출처를 보존하도록 제안한다. 대학별 평가요소 이름과 배점은 공통 작성 틀로 고정하지 않는다.

## 4. v2 템플릿 카드 — 공통 초점 8종

이하 이름·순서·AI 지시는 쌤핀을 위한 설계 제안이다. 대학이나 교육부가 지정한 공식 템플릿이 아니다. 순서는 기본값이고, 근거가 있는 요소만 쓴다. 도입·마무리는 별도 설정으로 조정할 수 있다.

### T1. 성취·수행 중심

- 사용: 일상 수업, 수행평가, 단원별 학습. 탐구 프로젝트가 없어도 선택 가능.
- 기본 구성: 확인된 성취 → 대표 과제에서의 수행 → 수행의 특성·교사 판단.
- 필요 근거: 학생의 실제 응답·작품·수행 및 판단 기준. 성취기준이 제공되지 않았다면 코드나 등급을 추정하지 않는다.
- AI 지시: 무엇을 어느 정도 할 수 있었는지 구체적 수행과 연결한다. 성취기준 문구를 학생의 성취 사실로 그대로 바꾸지 않는다. 참여 사실만으로 이해나 숙달을 단정하지 않는다.
- 생략: 성취 판단 근거가 부족하면 확인된 행동만 정리하고 추가 확인점을 본문 밖에 제시.
- 연결 자료: S3, S6, S8 32~33쪽, S9 2~5쪽.

### T2. 개념 적용·전이 중심

- 사용: 배운 개념으로 자료·현상·새로운 상황을 설명한 수업.
- 기본 구성: 적용 대상 → 사용한 개념 → 적용 절차 → 설명·해결한 내용 → 적용 범위 또는 한계(선택).
- 필요 근거: 개념과 학생이 실제로 수행한 연결·계산·표현·해석.
- AI 지시: 개념 이름이나 전문용어의 수보다 실제 사용 방법을 중심으로 쓴다. 서로 다른 교과가 등장했다는 이유만으로 융합 역량을 선언하지 않는다.
- 생략: 새 맥락에 적용한 근거가 없으면 T1로 안내. 제안한 적용과 실행한 적용을 구별한다.
- 연결 자료: S1, S4. 고교 외에는 해당 학교급의 학습 맥락으로 조정.

### T3. 근거 비교·판단 중심

- 사용: 독서·문학·토론·자료 분석·역사 해석·매체 비평.
- 기본 구성: 쟁점·해석 문제 → 비교 기준 → 자료·작품 속 근거 → 관점의 차이·타당성 판단 → 자신의 결론.
- 필요 근거: 비교 대상 또는 검토 대상 주장, 학생이 실제 사용한 근거와 판단.
- AI 지시: 무엇을 기준으로 어떤 근거를 평가했는지 드러낸다. 토론 참여를 비판적 사고로 자동 해석하지 않는다. 학생의 생각과 교사의 판단을 구별한다.
- 선택 요소: 반론 검토·관점 변화는 실제로 확인될 때만 추가. 자료가 하나라면 복수 자료를 창작하지 않는다.
- 연결 자료: S1, S6 144·146쪽.

### T4. 질문·검증 중심

- 사용: 실제 질문·가설·대안 풀이를 탐색하거나 타당성을 점검한 활동.
- 기본 구성: 실제 질문 → 방법·자료 선택 → 검토·분석 → 도달한 설명 → 한계·추가 검토(선택).
- 필요 근거: 질문 또는 과제, 학생의 탐색·검증 행동, 결과. 교사가 제시한 질문은 학생이 스스로 만든 질문으로 바꾸지 않는다.
- AI 지시: 활동의 의문을 해결하는 데 어떤 자료·방법이 쓰였는지 연결한다. 조사·실험·증명을 혼동하지 않는다. 결론의 강도를 실제 자료 수준에 맞춘다.
- 생략: 미완성 탐구도 확인된 지점까지 기록. 후속 계획을 이미 수행한 것으로 쓰지 않는다.
- 연결 자료: S2, S5 40쪽.

### T5. 피드백·수정 중심

- 사용: 글쓰기·발표·실기·풀이·제작에서 수정 전후가 확인되는 경우.
- 기본 구성: 첫 수행의 특징 → 받은 의견·자기 점검 → 학생이 선택한 수정 → 수정 후 달라진 수행 → 교사 판단.
- 필요 근거: 시점이 구별되는 전후 수행과 수정 행동. 외부 피드백이 없어도 실제 자기 점검 기록이 있으면 사용 가능.
- AI 지시: 막연히 '성장함'이라고 끝내지 말고 무엇을 어떻게 바꿨는지 쓴다. 교사가 고친 것을 학생이 독립적으로 해결했다고 바꾸지 않는다.
- 생략: 전후 근거가 없으면 변화·향상 주장을 작성하지 않으며, 현재 수행 중심으로 전환하도록 안내.
- 연결 자료: S6 137쪽. S7은 이 템플릿의 효과 검증이 아니라 사례 실습·토의 방식의 보조 근거.

### T6. 설계·창작·문제 해결 중심

- 사용: 작품·제품·프로그램·정책 대안·캠페인 등의 설계 및 제작.
- 기본 구성: 목적·조건 → 선택한 전략·표현 방식 → 제작·실행 → 산출물의 특징 → 검토·개선(선택).
- 필요 근거: 학생이 선택한 설계·표현과 실제 산출물 또는 실행.
- AI 지시: 완성 여부뿐 아니라 학생 고유의 선택을 드러낸다. 계획·제작·실행·효과 검증 단계를 구별한다. 작품 재구성은 조사·실험의 순서에 맞추지 않는다.
- 생략: 제안서만 있으면 실행 성과를 쓰지 않는다. 기능·수혜·만족도 수치를 만들어 넣지 않는다.
- 연결 자료: S6 143~144쪽. 실행 효과 검증 조건은 쌤핀 제안.

### T7. 협업·기여 중심

- 사용: 모둠 수업, 동아리, 공동 제작, 자율·자치활동.
- 기본 구성: 공동 과제 → 개인의 행동 → 의견 교환·조정·지원 → 공동 작업에 대한 기여 → 교사 판단.
- 필요 근거: 학생 개인에게 귀속되는 행동과 상호작용. 직책만으로 충분하지 않음.
- AI 지시: 누가 누구에게 어떤 도움을 주거나 어떻게 조율했는지 기록한다. 팀의 성과와 개인의 기여를 구별한다. 조용한 지원과 꾸준한 역할 수행도 근거가 있으면 담는다.
- 생략: 갈등이 없었다면 갈등 해결 이야기를 넣지 않는다. 결과 영향이 확인되지 않으면 행동까지만 기록.
- 연결 자료: S3, S4 공동체 사례, S5 39쪽.

### T8. 관심 탐색·선택 중심

- 사용: 진로활동 및 실제로 관심 분야를 탐색·비교한 수업.
- 기본 구성: 확인된 관심·질문 → 탐색 경험 → 알게 된 조건·특성 → 선택 또는 재고한 판단 → 다음 탐색(선택).
- 필요 근거: 학교 교육활동에서 확인된 탐색과 학생의 실제 판단. 미래 직업 확정 불필요.
- AI 지시: 진로역량을 희망 직업의 반복으로 표현하지 않는다. 관심 변경은 실제 경위를 확인한 경우만 연결한다. 특정 직업명을 모든 교과의 결론에 넣지 않는다.
- 생략: 관심 동기가 없으면 활동부터 시작. 상담·자기평가의 학생 진술을 교사가 직접 관찰한 사실처럼 바꾸지 않는다.
- 연결 자료: S3, S5 28쪽, S8 69쪽.

## 5. 행동특성 및 종합의견은 별도 기본 구성을 둔다

- 표시 이름: '생활·관계 종합'. 위 8종의 수업 초점과 달리 적용 영역에 따른 기본 구성이다.
- 구성: 반복 관찰된 특성 → 대표 생활 장면 2~3개(근거가 충분할 때) → 자기관리·관계·책임의 특징 → 종합 판단.
- 교사에게 장면 개수를 채우도록 강요하지 않는다. 단일 사건은 단일 사건으로 기록하며 성격 전체로 일반화하지 않는다.
- T7의 개인 기여 요소나 T5의 실제 변화 요소를 필요할 때 결합한다. 학교생활 전체를 단일 탐구 프로젝트로 연결하지 않는다.
- 연결 자료: S3 20쪽, S4 24~26쪽, S5 27쪽. 구성과 장면 개수는 제품 제안.

## 7. 모듈 공통 계약과 조합 원칙

각 모듈은 이름, 기록 목적, 허용 영역, 필요한 근거, 강조점, 생략 조건, 함께 쓰기 좋은 모듈, 금지 추론을 가진다. 실제 문장이나 학생 사실을 템플릿에 저장하지 않는다.

1. 요청 시작 때 학생·영역·대상 근거·현재 편집 글·작성 설정을 고정한다.
2. 선택한 모듈에 근거를 연결한다. 관련 없는 근거를 억지로 포함하지 않는다.
3. 근거가 없는 선택 요소는 생략한다. 핵심 근거가 부족하면 더 적합한 방식을 안내하고 자동 변경 여부를 명확히 한다.
4. 문단별로 사실과 교사의 해석을 확인할 수 있게 구성한다. 모듈 하나를 반드시 한 문단으로 출력하지 않는다.
5. 사용자 추가 지시와 선택 설정이 충돌하면 숨은 우선순위로 처리하지 말고 적용될 설정을 보여 준다.
6. 공통 규정·사실 근거·영역 조건을 유지한다. 프롬프트만으로 완전한 준수를 보장한다고 표현하지 않는다.
7. 본문과 본문 밖의 확인 메모를 분리한다. 확인 메모·내부 표식이 학생부 본문에 섞이지 않게 한다.
8. 실제 본문 바이트는 앱이 계산하고, 교사가 비교·수정한 뒤 반영한다. 기존 초안을 자동 덮어쓰지 않는다.

## 9. 후속 검증 계획 — 이번에 실행한 결과가 아님

- 동일 가상 근거를 최소 3가지 초점으로 생성해 사실 보존과 실질적 구성 차이를 비교한다.
- 모든 템플릿에 성장·진로·협업을 억지로 넣지 않는지 확인한다.
- 질문 없음, 전후 자료 없음, 팀 결과만 있음, 자기평가만 있음, 서로 무관한 과제, 미완성 탐구를 포함한다.

- 교사가 이름을 가리고도 수행의 차이로 학생을 구별할 수 있는지, 수정량이 줄어드는지 본다.
