# AI 연결(브릿지) 새 규격 전환 — 실기기 확인 시나리오

> **무엇이 바뀌었나**
> 쌤핀이 외부 AI와 이야기하는 **말투(규격)를 새 버전으로 올렸습니다.** 새 규격(2026-07-28)과
> 지금까지 쓰던 옛 규격을 **동시에** 말하므로, 선생님들이 이미 해 둔 Claude Desktop·Codex·
> Antigravity 설정은 **그대로 두어도 됩니다.** 이 문서는 "정말 그런지"를 실제 앱으로 확인합니다.
>
> **이 문서는 무엇인가**
> 자동 검사로 이미 확인한 것은 **뺐습니다.** 아래는 실제 GUI 앱이 붙고, 실제 설치본이 돌고,
> 실제 선생님 설정이 걸릴 때만 드러나는 것들입니다.
>
> **어떻게 쓰나**
> 위에서부터 순서대로 합니다. `기대`와 다르면 "결과 기록"에 적고 계속 진행합니다.
>
> **🔴 표시는 하나라도 실패하면 출시하지 않습니다.** 기존 선생님의 연결이 끊기거나,
> 학생 개인정보가 새거나, 꺼 둔 쓰기가 열리는 항목입니다.

| 확인한 것                                          | 방법                                               |
| -------------------------------------------------- | -------------------------------------------------- |
| 신·구 규격 각각 도구 54개 조회·호출·거부·정상 종료 | `npm run check:ai-bridge-protocol` (빌드에 연결됨) |

## 1. 🔴 기존 설정이 그대로 살아 있는가 (가장 중요)

**이번 전환에서 깨질 수 있는 1순위입니다.** 선생님이 예전에 등록해 둔 설정을 **손대지 않은 채로**
새 브릿지가 붙어야 합니다.

| #   | 무엇을 하나                                              | 기대                                                             |
| --- | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 1.1 | 새 쌤핀을 설치·실행하되 **[연결]을 누르지 않는다**       | 기존 설정이 그대로 남아 있다                                     |
| 1.2 | Claude Desktop 을 **완전히 껐다가** 다시 켠다            | 대화창 도구 목록에 쌤핀 도구가 나온다. "연결 실패"가 **없다** 🔴 |
| 1.3 | Claude Desktop 에 "우리 반 학생 명단 보여줘" 라고 시킨다 | 번호 + `stu_…` 토큰으로 나온다. **실명·전화번호가 없다** 🔴      |
| 1.4 | Antigravity 도 같은 방식으로 껐다 켜고 명단을 시킨다     | 위와 같다 🔴                                                     |
| 1.5 | Codex 를 껐다 켜고 명단을 시킨다                         | 위와 같다 🔴                                                     |

> **왜 이걸 먼저 보나:** 새 브릿지는 "연결을 여는 첫 요청"을 보고 옛 규격/새 규격을 고릅니다.
> 이 판단이 틀리면 **아무 설정도 안 바꿨는데 갑자기 안 붙습니다.** 기존 사용자에게 가장 아픈 실패입니다.

**1.2~1.5 중 하나라도 실패하면 여기서 멈추고 알려 주세요.** 아래는 볼 필요 없습니다.

## 3. 🔴 쓰기 게이트가 그대로인가

규격이 바뀌어도 **꺼 둔 쓰기는 여전히 막혀야** 합니다.

| #   | 무엇을 하나                                              | 기대                                         |
| --- | -------------------------------------------------------- | -------------------------------------------- |
| 3.1 | **쓰기 허용을 끈 채로** "○○에게 관찰 기록 하나 추가해줘" | 저장되지 않고 쓰기가 꺼져 있다고 안내 🔴     |
| 3.2 | 쓰기 허용을 켜고 같은 요청                               | 저장되고, 쌤핀 화면에도 그 기록이 보인다     |
| 3.3 | 같은 요청을 **한 번 더** 시킨다                          | 같은 기록이 **두 개로 늘지 않는다** 🔴       |
| 3.4 | 쌤핀을 **켜 둔 채로** 쓰기를 시킨다                      | 앱 화면에 즉시 반영되고 내용이 깨지지 않는다 |

## 4. 설치본에서만 드러나는 것

> 개발 모드(`npm run electron:dev`)로는 **이 장을 확인할 수 없습니다.** 반드시 설치파일로 하세요.
> 과거에 여기서만 터진 사고가 있습니다 — 개발 PC에서는 우연히 되고 설치본에서만 즉시 죽었습니다.

| #   | 무엇을 하나                                             | 기대                                                           |
| --- | ------------------------------------------------------- | -------------------------------------------------------------- |
| 4.1 | 설치파일로 설치한 뒤 [연결] → 클라이언트 재시작         | 도구가 나온다. "Could not attach to MCP server" 가 **없다** 🔴 |
| 4.2 | **Node.js 가 설치되지 않은 PC** 에서 4.1 을 반복        | 똑같이 된다 🔴                                                 |
| 4.3 | 설치 폴더의 `resources/ai-bridge/index.mjs` 크기를 본다 | 약 1.6MB (1.1MB 면 옛 번들 — 재생성 누락)                      |
