# "내 AI로 실행" — 실기기 확인 시나리오

> **이 문서는 무엇인가**
> 코드 검사(자동 테스트 9,050건)로는 확인할 수 없는 것만 모았습니다. **실제로 CLI를 띄우고,
> 실제 모델이 답하고, 실제 화면이 그려질 때만** 드러나는 것들입니다.
>
> **어떻게 쓰나**
> 위에서부터 순서대로 합니다. 각 항목의 `기대`와 다르면 **아래 "결과 기록"에 적고 계속** 진행합니다
> (한 항목이 실패해도 나머지는 대부분 독립적입니다).
>
> **🔴 표시가 붙은 항목은 하나라도 실패하면 출시하지 않습니다.** 개인정보가 새거나, 기능이
> 통째로 잠기거나, 선생님께 없던 비용이 생기는 항목입니다.

## 0. 준비

### 0.1 무엇이 필요한가

| 항목 | 내용                                                                                        |
| ---- | ------------------------------------------------------------------------------------------- |
| 구독 | Claude 유료(Pro·Max 등) **그리고/또는** ChatGPT 유료 중 최소 하나. 둘 다 있으면 더 좋습니다 |
| 기기 | 윈도우 PC. 되도록 **평소 쓰지 않던 PC**(설치부터 확인하려면)                                |
| 빌드 | `npm run electron:dev` 또는 설치파일 빌드                                                   |
| 시간 | 전체 약 60~90분                                                                             |

### 0.2 테스트용 데이터 심기

실제 학생 자료로 시험하지 않습니다. 가짜 수업반을 하나 심습니다.

```bash
# ★쌤핀을 완전히 종료한 뒤에 실행하세요 (앱이 켜져 있으면 스스로 중단합니다)
npm run seed:record-flow
```

심어지는 것 — **수업반 `흐름테스트 3-8`**, 학생 4명:

| 번호 | 이름     | 상태                     |
| ---- | -------- | ------------------------ |
| 1    | 흐름가온 | 근거가 많음(주제로 묶임) |
| 2    | 흐름나래 | 근거 보통                |
| 3    | 흐름다솜 | 근거 보통                |
| 4    | 흐름라온 | 근거가 적음              |

기존 학급·학생·기록은 **건드리지 않습니다.** 끝나면 `npm run seed:record-flow:clean` 으로 지웁니다.

### 0.3 확인 창구 열어 두기

- **작업 관리자**(Ctrl+Shift+Esc) → "세부 정보" 탭 — 프로세스가 남는지 볼 때 씁니다.
- 터미널 하나(Git Bash 또는 PowerShell) — 아래 §2에서 명령 한 줄을 붙여 넣습니다.

## 2. 🔴 개인정보 — 실명이 나가지 않는가

**이 절이 가장 중요합니다.** 2026-09-05 검증에서 실제로 새고 있던 부분입니다.

### 2.1 근거에 다른 학생 이름을 심는다

1. 수업반 `흐름테스트 3-8` → **기록** 탭 → **근거 자료**
2. **흐름가온**(1번) 학생 선택
3. 근거를 하나 직접 추가하고, 본문에 **다른 학생 이름을 일부러 넣습니다**:

   ```
   흐름나래와 함께 모둠 발표를 준비했고, 흐름다솜의 자료를 정리해 주었다.
   ```

4. 영역은 **교과 세부능력 및 특기사항**으로 지정

### 2.2 Codex로 초안을 만든다 (Codex가 보낸 것을 파일로 남기기 때문)

1. 설정 → AI 연결에서 **Codex를 연결**해 둔다
2. AI 패널을 열고 헤더에서 답할 AI를 **Codex**로 고른다
   > ★이 단계를 빠뜨리면 안 됩니다. 아무것도 고르지 않으면 **Claude가 기본**이라
   > 확인용 파일이 안 생깁니다. 확실히 하려면 Claude를 [연결 해제]해 두셔도 됩니다.
3. 기록 탭 → **초안** → 흐름가온 행의 **[AI로 초안 쓰기]** → **[이 학생만]**
4. 초안이 나올 때까지 기다린다

### 2.3 🔴 실제로 나간 글을 확인한다

터미널에 **그대로 붙여 넣으세요** (PowerShell):

```powershell
Select-String -Path "$env:USERPROFILE\.codex\sessions\*\*\*\*.jsonl" -Pattern "흐름가온|흐름나래|흐름다솜" | Select-Object -Last 10
```

| 결과                   | 판정                                                         |
| ---------------------- | ------------------------------------------------------------ |
| **아무것도 안 나온다** | ✅ **통과** — 실명이 한 글자도 나가지 않았습니다             |
| 한 줄이라도 나온다     | ❌ **실패(P0)** — 그 줄을 복사해 기록에 남기고 **출시 중단** |

> **왜 Codex인가**: Codex는 보낸 글을 `~/.codex/sessions` 에 파일로 남깁니다. Claude Code는
> 쌤핀이 `--no-session-persistence` 로 띄우기 때문에 파일을 남기지 않습니다 — 확인할 방법이
> 없어서가 아니라, **일부러 안 남기게 해 둔 것**입니다.

### 2.4 되돌아온 이름이 맞는가

| #     | 확인                   | 기대                                                  |
| ----- | ---------------------- | ----------------------------------------------------- |
| 2.4.1 | 미리보기 글을 읽는다   | `［이름1］` 같은 **꺾인 괄호가 남아 있지 않다**       |
| 2.4.2 | 초안에 이름이 나온다면 | **흐름가온**이지, 다른 학생 이름으로 바뀌어 있지 않다 |
| 2.4.3 | [반영] 후 입력창       | 미리보기에서 본 글과 **똑같다**                       |

### 2.5 알려진 한계 — 이건 정상입니다

**다른 반 학생 이름은 가리지 못합니다.** 근거에 "2반 김OO도 같이 했다"라고 적으면 그 이름은
명단에 없어서 그대로 나갑니다. 버그가 아니라 현재 설계의 한계이고 `/docs` 에도 적혀 있습니다.
근거를 적으실 때 유의하시면 됩니다.

## 3. 생기부 초안

### 3.1 구독 없이는 만들지 않는다 (Solar로 대신 만들지 않는다)

| #     | 단계                                          | 기대                                                                                 |

| 3.1.3 | 🔴 그 상태로 기다린다                         | **초안이 만들어지지 않는다.** 쌤핀 AI가 대신 쓰지 **않는다**                         |

> **먼저 앱을 껐다 켜세요.** 규정은 한 번 받아오면 1시간 동안 기억하므로, 앞에서 성공한 적이
> 있으면 이 시험이 통과처럼 보입니다.

| #     | 단계                                 | 기대                                                                                 |
| ----- | ------------------------------------ | ------------------------------------------------------------------------------------ |
| 3.2.1 | 앱 재시작 → **와이파이/인터넷 끄기** |                                                                                      |
| 3.2.2 | 🔴 [AI로 초안 쓰기] → [이 학생만]    | **"생기부 작성 규정을 서버에서 받아오지 못해 초안을 만들지 않았어요…"** 가 뜬다      |
| 3.2.3 |                                      | CLI가 **아예 실행되지 않는다**(작업 관리자에 claude/codex 프로세스가 새로 안 생긴다) |
| 3.2.4 | 인터넷 다시 켜고 [이어 하기]         | 정상 진행된다                                                                        |

### 3.3 생성 단위

| #     | 단계                            | 기대                                                                                  |
| ----- | ------------------------------- | ------------------------------------------------------------------------------------- |
| 3.3.1 | [AI로 초안 쓰기]                | "이 학생만" / "남은 학생 모두 (N명)" / "그만두기" 가 보인다                           |

| 3.3.3 | [반영]                          | 그 학생 입력창에 들어간다. 초안이 없던 학생이면 "반영", 있으면 "바꾸기 / 뒤에 붙이기" |
| 3.3.4 | "버리기"                        | 아무것도 저장되지 않는다                                                              |
| 3.3.5 | 🔴 [남은 학생 모두]             | 한 명씩 차례로. **[반영]을 누를 때만** 다음으로 넘어간다                              |
| 3.3.6 | 🔴 두 번째 학생 차례의 미리보기 | **"○○ 학생 칸에 저장됩니다."** 한 줄이 보인다(내가 누른 행과 다른 학생이므로)         |

| 3.3.8 | 이미 초안이 있는 학생           | "남은 학생 모두" 대상에서 **빠진다**(손으로 쓴 글을 덮지 않는다)                      |

## 4. AI 패널

### 4.1 🔴 "내 AI"만 켠 선생님도 패널이 열린다

> 2026-09-05 검증에서 **기능이 통째로 잠겨 있던** 부분입니다. 반드시 확인하세요.

| #     | 단계                                                          | 기대                                                   |
| ----- | ------------------------------------------------------------- | ------------------------------------------------------ |
| 4.1.1 | 설정 → 실험실에서 **"쌤핀 AI"는 끄고**, "내 AI로 실행"만 켠다 |                                                        |
| 4.1.2 | 🔴 사이드바를 본다                                            | **"쌤핀 AI" 항목이 보인다**                            |
| 4.1.3 | 🔴 그 항목을 누른다                                           | **오른쪽 패널이 실제로 열린다**(아무 반응 없으면 실패) |
| 4.1.4 | 질문을 하나 보낸다                                            | 구독 모델이 답한다                                     |

### 4.2 공급자 고르기

| #     | 단계                         | 기대                                                  |
| ----- | ---------------------------- | ----------------------------------------------------- |
| 4.2.1 | 패널 헤더                    | 연결된 것이 있으면 "누가 답할지" 고르는 상자가 보인다 |
| 4.2.2 | 연결이 하나도 없을 때        | 그 상자가 **안 보인다**(예전 화면 그대로)             |
| 4.2.3 | 답 아래                      | 어느 AI가 답했는지 작게 표시된다                      |
| 4.2.4 | 답을 기다리는 중             | 고르기 상자가 잠긴다                                  |
| 4.2.5 | 한도 80% 이상일 때           | "한도 NN% 사용" 뱃지가 보인다. 평소엔 안 보인다       |
| 4.2.6 | 창 폭을 1280px 아래로 줄인다 | 헤더 요소가 **넘치지 않고 다음 줄로 내려간다**        |

### 4.3 🔴 저장 제안 카드 — [실행] 없이는 저장되지 않는다

| #     | 단계                                                  | 기대                                                                                                                |
| ----- | ----------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| 4.3.1 | 설정 → AI 연결에서 **쓰기 허용**을 켠다               |                                                                                                                     |
| 4.3.2 | 패널에서 "내일 3교시에 수행평가 채점 할 일 추가해 줘" |                                                                                                                     |
| 4.3.3 | 🔴                                                    | 입력칸 위에 **카드**가 뜬다: **[외부 요청]** 배지 + "할 일 추가" + 내용 + **"다른 AI 앱에서 온 요청일 수 있어요."** |
| 4.3.4 | 🔴 카드를 그대로 둔다                                 | **아무것도 저장되지 않는다.** 할 일 목록에 안 생긴다                                                                |
| 4.3.5 | [취소]                                                | 카드가 사라지고 여전히 저장 안 됨                                                                                   |
| 4.3.6 | 다시 요청 → **[실행]**                                | 그제야 실제로 저장된다. 할 일 목록에서 확인                                                                         |
| 4.3.7 | [실행]을 **빠르게 두 번** 누른다                      | **한 번만 저장된다**(두 개 안 생긴다)                                                                               |
| 4.3.8 | 카드를 2분 넘게 방치                                  | 사라진다. 저장은 안 된 상태                                                                                         |

### 4.4 조회 범위

## 5. 안전 장치

### 5.1 🔴 API 키가 있어도 구독으로 붙는다 (없던 비용 방지)

> 선생님 PC에 API 키가 설정돼 있으면, CLI가 구독 대신 그 키로 붙어 **구독과 별도로 요금이
> 청구**됩니다. 쌤핀은 키를 가리고 실행합니다.

1. 터미널에서 **가짜 키**를 넣고 쌤핀을 띄웁니다:

   ```powershell
   $env:ANTHROPIC_API_KEY = "sk-ant-이건가짜입니다"
   npm run electron:dev
   ```

2. 패널에서 Claude로 질문 하나

| 결과                | 판정                                             |
| ------------------- | ------------------------------------------------ |
| **평소처럼 답한다** | ✅ 통과 — 가짜 키를 무시하고 구독으로 붙었습니다 |
| 인증 오류가 난다    | ❌ **실패(P0)** — 가짜 키가 새어 들어갔습니다    |

> 끝나면 터미널을 닫아 환경변수를 없애세요.

### 5.2 프로세스가 남지 않는다

| 5.2.2 | 🔴 [중단] 직후                | 쌤핀 AI로 **자동으로 넘어가지 않는다**(멈추라고 했으므로)    |
| 5.2.3 | 답을 받는 중에 **앱을 종료**  | 잠시 뒤 자식 프로세스도 **전부 사라진다**                    |

## 6. 화면과 반응

| #   | 단계                                | 기대                                                          |
| --- | ----------------------------------- | ------------------------------------------------------------- |
| 6.1 | 🔴 앱을 켠 직후                     | 화면이 **멈추지 않는다**. 사이드바 클릭·스크롤이 즉시 반응    |
| 6.2 | 설정 → AI 연결 탭을 연다            | 카드가 "확인 중이에요…"를 보이며 **화면은 계속 움직인다**     |
| 6.3 | 다른 창 갔다가 쌤핀으로 복귀        | 상태를 다시 확인하지만 멈춤 없음                              |
| 6.4 | 초안 [AI로 초안 쓰기]를 누르는 순간 | **멈칫하지 않는다**                                           |
| 6.5 | 초안 화면에서 학생 30명 목록        | 버튼 30개가 **거슬리는지 판단**. 옆 [복사] 버튼과 어울리는지  |
| 6.6 | 실험실 스위치를 **끈다**            | 초안 화면에 [AI로 초안 쓰기]가 **사라진다**(예전 화면 그대로) |
| 6.7 | 유리 모드에서 저장 제안 카드        | 배경이 제대로 보인다. 파란 테두리 같은 엉뚱한 색이 없다       |
| 6.8 | 다크/라이트 모드 전환               | 글자가 안 사라진다                                            |

> **6.5 는 판단을 여쭙는 항목입니다.** 개발 판단으로는 "이 화면이 이미 행마다 [복사] 버튼이
> 30개 있는 행 단위 조작 화면이라 그대로 두는 게 맞다"로 봤습니다. 실제로 보시고 다르게
> 느끼시면 알려 주세요.
