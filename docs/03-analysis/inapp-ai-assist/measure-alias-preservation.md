**측정일** 2026-08-21 · **모델** `solar-pro3` · **호출** 30회(6가지 상황 × 5회) · **오류** 0건
**원자료** `measure-alias-preservation.json`

> 실제 학생 정보는 쓰지 않았다. 입력은 전부 지어낸 숫자와 별칭이다.
> 측정에 쓴 임시 스크립트와 임시 API 키는 측정 후 삭제했다.

---

## 왜 쟀나

이름을 `［이름1］` 로 가려 보내고, **답변을 화면에 띄우기 직전 실제 이름으로 되돌리는** 설계를 했다.
이 설계는 **모델이 별칭을 원형 그대로 돌려준다**는 가정 위에 서 있는데, 그 가정은 검증된 적이 없었다.

## 결과 — 가정이 틀렸다

| 지표                                      | 값                       |
| ----------------------------------------- | ------------------------ |
| 별칭 **원형**(`［이름1］`) 보존           | **5 / 30 = 16.7%**       |
| 별칭이 어떤 형태로든 등장                 | 16 / 30                  |
| 별칭을 아예 언급하지 않음(문장을 풀어 씀) | 14 / 30                  |
| 거부(개별 학생 질문에 대해)               | 3 / 30 — **의도된 동작** |
| 중앙값 응답 시간                          | 682ms                    |

**정확 일치로 되돌리면 16건 중 6건만 잡힌다.** 나머지는 `〈이름1〉` 같은 찌꺼기가 화면에 그대로 남는다.

### 모델이 실제로 만든 별칭 형태

| 형태                                                                                                                             | 횟수 |
| -------------------------------------------------------------------------------------------------------------------------------- | ---- |
| `〈이름1〉`                                                                                                                      | 4    |
| `［이름1］`(원형)                                                                                                                | 4    |
| `〈이름2〉` · `[이름1]` · `[학번1]` · `［학번1］` · `(이름1)` · `(이름 1)` · `[이름1`(닫힘 누락) · `학번1`(괄호 없음) · `학번1 ` | 각 1 |

전각 대괄호 → 홑화살괄호·반각 대괄호·소괄호로 **자유롭게 갈아치우고**, 마크다운 escape(`\[이름1\]`)를
붙이거나 괄호를 아예 빼기도 한다.

## 대응

`restoreModelText()` 를 새로 만들어 괄호 모양·유무·공백에 상관없이 되돌린다.
저장해 둔 실제 응답 30건으로 재검증: **되돌리기가 필요했던 16건 전부 성공.**

### 규칙은 둘뿐 — **우리 괄호만 떼고, 모델이 쓴 괄호는 그대로 둔다**

| 입력             | 결과                                   |
| ---------------- | -------------------------------------- |
| `［이름1］ 면담` | `김지훈 면담` (우리 표기이므로 괄호째) |
| `〈이름1〉 상담` | `〈김지훈〉 상담` (모델 표기는 보존)   |
| `면담(이름1)이`  | `면담(김지훈)이`                       |
| `학번1 상담`     | `15번 상담`                            |

**모델 괄호까지 떼려다 두 번 실패했다** — 둘 다 테스트가 잡았다.

1. 뒤 공백을 같이 먹어 `학번1 상담` → `15번상담`
2. 괄호를 떼니 `면담(이름1)이` → `면담김지훈이` 로 **한글이 붙어 버림**

모델이 괄호를 **구분자로 썼는지 삽입구로 썼는지 알 수 없으므로** 건드리지 않는 쪽이 안전하다.

## 부수적으로 확인된 것

- **답변 품질은 쓸 만하다.** 별칭이 있어도 문장이 자연스럽다.
  예: `"오늘 마감인 〈이름1〉 상담 기록이 가장 급한 일입니다. 그 다음으로는 …"`
- **47%는 별칭을 아예 안 쓴다.** `"결석 사유 확인을 내일까지 진행해 주세요"` 처럼 풀어 쓴다.
  되돌릴 것이 없고 읽기에도 자연스러워 **문제가 아니다.**
- **`"［이름1］이 누구야?"` 에는 5회 중 3회 거부했다** — 시스템 프롬프트가 의도한 동작이다.
  나머지 2회도 "개별 정보는 앱에서 확인하세요"로 안내했고, **실제 이름을 지어내지 않았다.**
- **숫자를 지어내지 않았다.** 출결 집계(26/2/1/0)를 30회 내내 정확히 옮겼다.

## 남은 한계

- 별칭 형태는 **모델 버전이 바뀌면 또 달라질 수 있다.** 지금 규칙은 `접두사+번호` 만 보므로
  괄호가 어떻게 바뀌어도 견디지만, 모델이 `"첫 번째 학생"` 처럼 **완전히 풀어 쓰면** 되돌릴 수 없다.
  그 경우 이름이 안 보일 뿐 **잘못된 이름이 끼어들지는 않는다**(테스트로 고정).
- 이 측정은 `get_my_todos` 중심이다. 자유 입력이 있는 도구가 이것뿐이라 그렇다.
