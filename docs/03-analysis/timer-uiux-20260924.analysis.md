> 충돌할 수 있어 그만뒀다. 아래 수치는 코드에 적힌 크기로 계산한 값이며 오너 스크린샷과 맞는다.

## 1. 원이 숫자에 붙어 보이는 이유

간격이 좁은 수준이 아니라 **숫자가 원 안쪽보다 넓었다.**

- 원 크기는 300px 고정, 테두리 안쪽 지름 274px (`Timer/CircleProgress.tsx:2`)
- 숫자는 96px 글꼴, "05:00" 다섯 글자 폭 약 288px (`Timer/TimerMode.tsx:490`)
- 숫자 폭이 원 안지름의 **105%** — 양쪽이 원 테두리를 넘는다.

숫자 폭은 원 안지름의 60~65%일 때 편안하다. 제안한 B안: 원과 숫자를 함께 조정(원 360px·숫자 72px 수준)하고, 비율을 고정한 채
**창 크기에 맞춰 함께 커지게** 한다. A안(원만 480px)은 노트북 화면에서 너무 크다.

더 큰 문제: 원 크기가 **어떤 창에서도 300px 고정**이라 교실 TV 전체화면에서도 원이 작게 남는다.

## 3. 분석 중 발견한 결함

1. **발표 타이머 예고 알림이 설정을 따르지 않는다.** 단추에는 "1분 전"인데 실제로는 늘 10초 전에 울린다 (`PresentationMode.tsx:316`).
2. **발표 타이머에서 '내 파일' 알람음을 골라도 기본 "삐삐삐"가 울린다.** 등록한 파일을 넘기지 않는다 (`PresentationMode.tsx:326`·455·475).
3. **🔊 단추(M 키)를 눌러도 타이머 알람은 꺼지지 않는다.** 타이머 알람이 다른 음량 설정을 쓴다.
4. **타이머를 켜 둔 채 다른 화면으로 가면 안내 없이 꺼진다** (`TimerMode.tsx:347`). 팝업으로 옮기는 기능이 있어도 모르면 못 쓴다.
5. **모바일은 옛 타이머 사본을 쓴다.** 1,551줄짜리 별도 파일(`src/adapters/components/Tools/ToolTimer.tsx`, `mobile/App.tsx:43`)이라 고쳐도 모바일에 반영되지 않는다.
6. 작은 것: '직접 입력' 창에서 Enter 확인·Esc 닫기가 안 된다. 발표 타이머 알람 파일 선택에 5MB 검사가 빠져 있다.

## 4. 교사 입장에서 추가하면 좋을 기능

**수업 중 바로 체감되는 것**

- 교실 화면 모드 — 조작 단추를 숨기고 원과 숫자가 화면을 채운다.
- 초과 시간 "+00:32", 확인할 때까지 알람 반복 선택지(시끄러운 교실에서 한 번 울리면 놓친다)
- 끝나는 시각 "10:42에 끝나요"
- 화면을 떠날 때 안내 — "타이머가 돌고 있어요. 팝업으로 옮길까요?"
- 마지막에 쓴 시간 기억, 내 프리셋

**활동 운영**

- 활동 이름("모둠 토의 중")을 숫자 위에 크게
- 단계 타이머 — 생각 2분 → 짝 3분 → 발표 1분이 자동으로 이어짐, 모둠 순환처럼 N번 반복
- 남은 시간을 부채꼴로 — 저학년·특수학급에서 숫자보다 잘 읽힌다

**발표 타이머**

- 명단을 불러오면 번호순 자동 지정(지금은 "순서를 지정하세요 (0/25)"로 시작 단추가 잠김)
- 발표 시간 직접 입력(지금은 1·2·3·5분만), 발표 뒤 질의응답 시간
- 결석·준비 안 된 학생 "맨 뒤로 미루기"
- 발표자별 쓴 시간 요약 — 순위는 매기지 않는다(보상형 게임 요소 금지 원칙, ADR-134)

## 5. 오너 결정 (2026-09-24)

- "모두 진행" — 세 차례로 나눈 제안을 한 번에 진행한다. 원 크기는 B안 + 창 맞춤.
- 모바일도 새 모듈로 — 단, **타이머·스톱워치만**(발표·단계 타이머·프리셋 편집·부채꼴은 PC만).
