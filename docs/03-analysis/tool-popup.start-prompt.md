```text
/oh-my-claudecode:ralph

쌤핀의 쌤도구 팝업 기능을 계획·설계부터 구현·검증·사용자 가이드 갱신까지 진행해 줘. 이 세션은 Claude Opus 5로 작업하며, 오마이클로드 코드의 Ralph 스킬을 사용해. 실제 선택 모델을 확인하고 다른 모델을 Opus 5라고 보고하지 마.

먼저 아래 핸드오프 전체를 읽어:
E:/github/ssampin/docs/03-analysis/tool-popup.handoff.md

그다음 원 검토서를 읽어:
E:/github/ssampin/docs/03-analysis/tool-popup-feasibility-20260908.analysis.md

현재는 검토 문서만 있고 기능은 아직 구현되지 않았어. 다른 쌤핀 페이지를 사용하면서 도구를 별도 창에 띄우는 게 목적이야.

핸드오프의 S0~S5를 Ralph PRD의 검증 가능한 이야기로 나누고 순차 진행해. 타이머(일반·스톱워치·발표)와 랜덤 뽑기부터 실제 Electron 창에서 검증한 뒤, 신호등·점수판·룰렛·주사위·동전·QR코드·활동 기호까지 총 9종을 완성해. 두 도구만 끝내고 전체 완료로 처리하지 마.

본문과 팝업 사이를 옮길 때 입력·진행 시간·제외 목록·결과를 보존하고, 알람이나 추첨이 중복 실행되지 않게 해. 같은 도구는 하나의 실행만 허용하고 재열기는 기존 창을 보여줘. 기존 본문 열기와 병렬 보기도 유지해.

main의 현재 작업 폴더에서만 작업해. 시작 시 CLAUDE.md·AGENTS.md·PROGRESS.md·DECISIONS.md와 git status/diff를 확인하고 다른 세션의 미커밋 변경을 보존해. 구현을 여러 에이전트에 병렬로 맡기지 마. 독립 분석·리뷰는 가능해. 새 브랜치·worktree·PR·push·배포는 하지 마.

계획을 작성했다는 이유만으로 멈추지 말고, 핸드오프 기본안 안의 구현 선택은 근거를 기록하며 계속 진행해. 실제로 중요한 범위 변경만 확인해. 현재 활성 Ralph 지침의 reviewer 검증·코드 정리·후속 재검증도 수행하되 정리는 이번 작업 변경에 한정해.

검증 게이트, 실제 Electron 동작, 사용자 가이드 검증을 증거와 함께 기록해. 실행하지 못한 항목을 통과로 표시하지 말고, 환경상 검증 불가라면 가능한 나머지 작업을 마친 뒤 정확한 잔여 항목을 보고해. 최종 답변은 무엇이 구현됐는지, 어떤 검증이 통과했는지, 남은 사항을 한국어로 짧게 알려줘.
```
