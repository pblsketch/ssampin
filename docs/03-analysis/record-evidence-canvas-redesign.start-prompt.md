앞선 세션은 조사·설계만 했고, 이번 세션은 그 계획을 바탕으로 실제 구현하는 세션이야. 계획서의 '구현하지 않음'은 이전 세션 기록이지 이번 구현을 막는 지시가 아니야. 특히 계획서 §11의 교사 사용 난이도·기존 화면 연동 보완까지 적용해줘.

원하는 결과:

- 기존 '근거 정리 ↔ 초안' 안에서 근거 카드를 직접 연결하고 분기·합류를 볼 수 있게 해줘. 새 사이드바 메뉴나 주제 칩만 보강하는 것으로 끝내지 마.
- 연결·분류를 하지 않아도 초안을 만들 수 있어야 해. 별도 '작성 구성에 담기' 단계는 없애고, 글 순서 조정은 초안 준비에서 필요할 때만 펼쳐줘.
- 상단 작업 버튼은 '근거 추가 / AI로 정리 제안 / 이 근거로 초안 쓰기' 최대 3개, 강조 버튼은 하나로 해줘. 같은 기능은 모든 페이지에서 같은 이름을 써줘.
- AI는 선택 범위에 대해 제안하고 적용 전에 저장하지 않아야 해. 실제 AI에 보낸 근거와 화면의 선택·제외 이유가 일치해야 해.
- 담임·수업 관리·과제 수합에서 학생과 과목을 다시 선택하지 않고 이어지게 하고, 돌아가면 원래 화면 상태를 복원해줘. 수합 상세 직접 연동은 추가 구현이 필요한 부분이야.
- 원본·기존 초안·미저장 글, 다중 학생/날짜 입력, 일괄 생성, 분량 조절, 비교·반영, 복사·내보내기를 보존해줘.

main의 기존 미커밋 작업을 먼저 확인하고 인수해줘. 새 브랜치/worktree를 만들거나 다른 세션의 변경을 되돌리지 마. 구현은 병렬로 나누지 말고 순차 진행해줘. 커밋·push·PR·배포·운영 DB 변경은 하지 마.

핸드오프의 S0부터 시작해서 P0~P5를 작은 작업 단위로 진행해줘. 옛 ADR과 달라지는 결정은 최신 번호를 확인해 후속 ADR로 남겨줘. 이미 합의한 방향을 다시 승인받느라 멈추지 말고, 일반적인 구현 선택은 근거를 남기고 진행해줘.
