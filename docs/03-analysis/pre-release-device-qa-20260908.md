# 다음 릴리즈 전 실기기 확인 — 한 장 통합표 (2026-09-08)

> **왜 이 문서인가**
> v2.4.9(9/4) 이후 커밋 70여 개, 바뀐 파일 439개. 전부 자동 검사(tsc·lint·vitest·회귀)를 통과했고
> 전부 커밋돼 있습니다. 그런데 **실기기에서 눈으로 확인된 것은 0건**입니다. 이 저장소에는 검사가
> 전부 초록인 채로 살아 있던 결함이 여러 번 있었습니다(출석번호 밀림, 유리 모드 창 갇힘, 드라이브
> 100개 잘림, 담임 본문 소실). 그래서 출시 전에 아래를 손으로 봅니다.
>
> **어떻게 쓰나**
> 🔴 절부터 합니다(약 1시간). 🔴 이 전부 통과해야 출시를 시작합니다. 나머지는 시간 되는 만큼 하되,
> 실패한 것은 릴리즈 노트 "알려진 문제"로 적을지 고칠지 정합니다.
> 세부 항목은 기존 점검표 3건을 그대로 씁니다 — 이 문서는 **어디부터 볼지와 빠진 조각**만 모았습니다.

## 0. 준비 (10분)

| 항목      | 내용                                                                                                                                 |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 구독      | Claude 유료 **또는** ChatGPT 유료 중 하나 이상. Codex 는 사용량 한도가 자주 걸리니 Claude 를 기본으로, Codex 는 §2 개인정보 확인에만 |
| 학교 자료 | 컴시간 **보강·교체가 있는 주**(없으면 A-③·④ 는 건너뜀) · 교무실 부서 1개(멤버 2명 이상이면 좋음)                                     |
| 기기      | 윈도우 PC. 브릿지(§I)는 **설치파일**로만 확인 가능 — `npm run electron:build` 또는 GHA 산출물                                        |
| 휴대폰    | 말로 남기기(§D-⑪)용. 아이폰이면 홈 화면 추가 후 실행도 한 번                                                                         |
| 시간      | 🔴 만 약 1시간 · 전부 약 4~5시간 (하루에 다 안 해도 됨)                                                                              |

**순서대로:**

1. 쌤핀을 **완전히** 닫습니다. 트레이(시계 옆) 아이콘까지 오른쪽 클릭 → 종료.
2. 터미널에서 테스트 자료를 심습니다. 실제 학생 자료는 건드리지 않고 수업반 **흐름테스트 3-8**(학생 4명: 흐름가온·나래·다솜·라온)만 더합니다.

   ```bash
   npm run seed:record-flow
   ```

3. 앱을 켭니다. **브라우저 모드(`npm run dev`)는 안 됩니다** — 말로 쓰기 단추가 안 보이고, 이번 변경에 앱의 속(메인 프로세스) 수정이 많아 반드시 껐다 켠 상태여야 합니다.

   ```bash
   npm run electron:dev
   ```

4. 설정 → 실험실에서 **"내 AI로 실행 (구독)"** 켜기 → 설정 → 연동·백업 → AI 연결에서 Claude Code 연결.
5. 끝나면 `npm run seed:record-flow:clean` (앱 닫고 실행).

> ⚠️ **실제 학생 이름·기록으로 시험하지 마세요.** §2 는 일부러 다른 학생 이름을 근거에 넣어 봅니다.
