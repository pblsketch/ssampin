## 확인하지 못한 것

- **선생님 화면의 예약 상세 칩** — 확인용 창은 구글 미연결이라 명단을 열 수 없다.
  갈라 보이는 규칙 자체는 위 "저장된 값"과 단위 테스트로 확인했다.
- **엑셀 내보내기·캘린더 추가 실물** — 같은 이유(명단을 못 연다).
- **다크 테마 실렌더** — 확인용 창에서 테마 클래스를 바꿔도 앱이 되돌려 놓는다.
  쓰는 클래스 9종이 hover 변형까지 실제로 생성되는 것은 `npx tailwindcss` 로 확인했다.
