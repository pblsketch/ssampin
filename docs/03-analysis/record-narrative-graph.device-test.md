# v2.5.2 실기기 테스트 항목 — 생기부 흐름 보기 (2026-09-11)

> 자동 게이트(타입·린트·검사 10,400여 건·회귀 109)와 브라우저 확인은 끝났다. 아래는 **오너가 설치본에서 직접 볼 것**만 남긴 목록이다.
> 게이트가 초록인 채 존재한 결함이 이 기능에서만 16건 나왔으므로([[docs/progress/2026-09.md]]), 자동 검증을 실기기 대신으로 쓰지 않는다.
> 릴리즈(커밋·빌드·GitHub·챗봇 지식 갱신)는 이 테스트를 통과한 뒤 지시하시면 진행한다.

## 1. 저장이 실제로 되는가 (가장 중요)

파일 위치: `%APPDATA%\쌤핀\data\` — 근거는 `recordEvidence*`, 주제·장면은 `inquiryThread*`.

| 할 일                                      | 봐야 할 것                                                           |
| ------------------------------------------ | -------------------------------------------------------------------- |
| 관찰 기록만 있고 아직 손 안 댄 학생을 연다 | 카드는 보이는데 **파일은 안 커진다**(거울 카드는 저장 0회)           |
| 「자리 미정」 카드를 장면으로 끌어 놓는다  | 근거 파일과 주제 파일 **둘 다** 바뀐다(근거 먼저, 장면 나중)         |
| 다른 주제로 카드를 끌어 놓는다             | 옛 주제의 장면에서 빠지고 새 주제로 간다. 옛 자리에 유령이 안 남는다 |
| 장면 메모를 쓰고 [저장]                    | 주제 파일이 커진다. 앱을 껐다 켜도 글이 그대로                       |
| [흐름] ↔ [보드] 전환                       | 같은 자료가 양쪽에 그대로. 한쪽에만 있는 근거가 없다                 |

## 2. 새로 들어간 것

- **[넓게 보기]** — 메모를 쓰는 도중에 눌렀다가 [원래 크기로]/Esc 로 돌아와도 **쓰던 글이 남아 있는가.**
  설정에서 **유리 모드를 켠 채로도** 창 전체로 펼쳐지는가(가로 1,400px 넘게).
- **[되돌리기]** — 장면 옮기기 · 근거 놓기 · 뼈대 깔기 각각 뒤에 아래 안내의 [되돌리기]를 눌러 **제자리로 오는가.**
  특히 뼈대 깔기 되돌리기에서 **장면 메모와 근거 자리가 그대로** 살아나는지.
- **장면 사이 [+]** — 칸과 칸 사이에 마우스를 올리면 나타나고, 누르면 **그 사이에** 장면이 끼는가(맨 뒤가 아니라).
- **AI 흐름 제안** — 구독 AI 를 연결한 상태에서 [AI 흐름 제안] → 칩/추가 요청 → [제안 받기].
  점선이 뜨는 동안 **파일이 안 바뀌는가**(적용 전 저장 0회). [이 흐름 적용] 뒤에야 바뀌는가.
- **학생 넘기기** — Alt+←/→ 로 넘어가는가. 장면 메모를 **쓰다 만 상태**로 넘기려 하면 먼저 묻는가.
- **개요 지도** — 주제를 셋 이상 만든 학생에서 맨 위 한 줄 지도가 뜨고, 칩을 누르면 그 주제로 가는가. [모두 접기]도.

## 3. 화면이 답답하지 않은가 (단순화 확인)

- 1440×900 기본 창에서 **장면 칸이 첫 화면에 보이는가**(스크롤 없이). 노트북 등 다른 해상도에서도.
- 도구 줄이 **한 줄**인가. [+ 근거 ▾] 안에 직접 입력·엑셀 양식·엑셀 업로드 셋이 다 있는가.
- 다크 모드에서 장면 색·글자 대비가 괜찮은가.

## 4. 옛 자료 호환

- v2.5.1 에서 **작성 방식을 저장해 둔** 학생을 연다 → 「뼈대로 옮겼습니다」 안내가 **한 번만** 뜨는가.
  그 뒤 초안을 뽑았을 때 예전과 크게 다르지 않은가.
- 장면을 **하나도 안 놓은** 주제로 초안을 뽑으면 예전과 같은 글이 나오는가(관문이 꺼져 있어야 한다).

## 5. 알고 넘어갈 것

- 장면을 놓고 뽑은 초안은 **평균 18% 짧다**(하네스 20건 실측, [비교표](record-narrative-graph.harness-compare.md)).
  근거가 없는 자리를 억지로 채우지 않기 때문이다. 자리를 다 채우려면 근거를 더 놓으면 되고, 화면이 빠진 자리를 이름으로 알려 준다.
- 「문단 수 = 장면 수」는 보장하지 않는다(계획서 §11). 근거가 없는 자리는 모델이 건너뛴다.
