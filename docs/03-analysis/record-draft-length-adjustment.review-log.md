# 개정 이력

## 1차 개정 (2026-09-07) — Architect `SOUND WITH CONCERNS` · Critic `ITERATE` 반영

**전제 변경**

- 다른 세션이 워킹트리를 전부 커밋(`ed760331`, `880a82c4`). "미커밋 변경 위에서 작업"이라는 옛 §A-2 동인 3 · §C S0 선행 조건 · §H 충돌 위험 행을 **폐기**하고, 새 동인 3("기존 결함 위에 새 기능을 얹지 않는다")과 **경로 지정 커밋 규칙**으로 대체했다.
- 이 계획서 파일 자체가 남의 커밋에 딸려 들어간 사고를 §전제·§C·§J·§H에 교훈으로 남겼다.
- **모든 코드 앵커를 HEAD `880a82c4`에서 다시 열어 확인**하고, 옛 개정본의 틀린 번호 4건을 고쳤다. 확인하지 못한 것은 줄 번호를 빼고 함수 이름만 적었다.

**설계가 바뀐 것 (Architect 종합 제안 2건 채택)**

- 한도를 넘긴 결과를 죽은 채로 두지 않는다 → **[편집칸에 넣기(저장 안 함)]** 신설. 등록부의 "절대 안 쓴다"를 "쓰는 자리가 딱 한 곳이고 그 자리에 게이트가 있다"로 바꿨다.
- 자동 재조정 1차 결과를 **디스크에 안 남기고 화면에 두 탭**으로 두어, 판 상한을 안 갉아먹으면서 ADR-085 취지를 지킨다.

**새로 찾은 결함 3건 → C0 신설**

- 반영 실패 무반응 / **초점을 잃으면 저장 거부된 글이 화면에서 되돌아감(이번에 새로 발견, 기능의 전제를 무너뜨림)** / `useState` 기반 중복 실행 잠금. 새 기능보다 **먼저** 고친다.

**개인정보·규정 게이트 보강**

- 분량 조절도 **L1 규정 지시문**을 받고, 못 받으면 실행하지 않는다.
- 기재 금지 필터의 **비대칭**(근거는 빠지고 본문은 안 빠짐)을 새로 밝히고, **확인 후 그대로 전송**(자동 삭제 금지)으로 결정했다.
- 실명 0건 확인을 조각 단위 테스트에서 **이음매 게이트(`ownAiEgress.test.ts`) 5번 항목**으로 끌어올리고, **재조정 2차 요청까지** 본다.

**정확성 보강**

- 지시문 전문 2종(줄이기 / 보충하기)과 `[근거 부족]` 표식 처리 순서를 실었다.
- `aliasByteDelta` 부호를 `김지훈`(9B) → `［이름1］`(13B) = `-4`로 못 박고, "정확한 계산식"이 아니라 **어림 보정**임을 명시했다.
- `judgeLength`를 `(area, level)`로 받고 **`over-limit`을 가장 먼저** 판정하게 했으며, 목표 입력에 상한(`clampTargetBytes`)을 뒀다.
- `appendedBytes`를 코드와 글자 단위로 일치시켰다(`trim` · 빈 앞글).
- 조절안 판의 버튼 규칙(뒤에 붙이기 숨김, 원문과 비교로 대체)을 명시했다.
- `mode:'expand'`의 근거 범위를 **조절 대상 판의 `threadId`**로 고정했다.
- 회귀 #68·#69를 grep이 아니라 **테스트 생존 검사** 형태로 바꾸고 패턴 예시를 실었다.

**가독성**

- `## 오너가 결정해 주실 것` 9건을 맨 앞으로 올렸다.
- `useRef`(기억 상자) · `enforceAiDraftCap`(상한을 넘으면 오래된 판을 지우는 함수) 등 기술 용어에 처음 나올 때 쉬운 한국어를 붙였다.
- 단계를 S3a/S3b, S5a/S5b로 쪼개 한 세션 단위에 맞췄다.
- 연결부를 7건에서 **8건**으로 바로잡았다(분석 §5의 실제 항목 수).
