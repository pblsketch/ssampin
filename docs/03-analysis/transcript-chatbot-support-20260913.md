# 성적 파일 인식 실패 지원 안내 검증

- 수신 주소는 오너가 확인한 공개 문의 주소 `pblsketch@gmail.com`이다.
- 원본을 보관하고 복사본의 개인정보와 실제 성적을 모두 삭제한 빈 양식만 요청한다. 머리글·행열·병합은 유지하며 숨김 영역·메모·속성도 확인한다. 만들기 어려우면 전송하지 않아도 된다.
- 운영 지식 문답은 전용 출처 1건만 저장하고 직접 재조회했다. 전체 문답 일괄 갱신은 실행하지 않았다.
- 실제 답변 검사에서 지식 문답만으로는 빈 양식을 앱에 다시 올리라는 잘못된 설명이 발생했다. 따라서 성적 파일 인식 실패와 직전 사용자 질문을 잇는 재시도는 검증한 요청문을 직접 반환한다. 다른 주제의 질문은 기존 답변 경로를 유지한다.
- 챗봇 함수만 운영 적용했다. 요청 제한과 대화 저장은 유지한다. 시스템 비밀값·다른 함수·앱 버전은 변경하지 않았다.
- 함수 검사에서 기존 DB 클라이언트 반환형의 추론 오류 8건을 확인했고, 해당 두 매개변수를 SDK의 명시적 클라이언트 타입으로 변경했다. `deno check supabase/functions/ssampin-chat/index.ts`: 오류 0.
- `node --test scripts/chatbot-support.test.mjs`: 3개 통과. 실패 표현·후속 질문·다른 주제 제외·요청문 내용 확인.
- 운영 API에 테스트 표시를 붙인 가상 질문 3건(원문 오류, xlsx 재시도 실패, 후속 메일 문의)을 보냈다. 모두 HTTP 200이며 같은 검증 요청문을 반환했다. 개인정보 원본 전송이나 빈 양식 재업로드를 권하지 않는다.
- 실제 학생 파일·개인정보를 사용하거나 이메일을 발송하지 않았다. 로그는 `_workspace/transcript-qa/chatbot-live.json`에 있다.
- 원격 main에 없던 기존 8개 커밋은 오너 지시에 따라 푸시에서 제외한다. 원격 main 기준 별도 검증 폴더에 이번 성적·챗봇 변경만 적용한다. 기존 작업 폴더의 미커밋 변경은 보존한다.
