# Phase 0 실측 ② — 무료 티어 사용 제한

> **[2026-08-18 갱신] 이 문서는 키 없이 익명으로 측정한 결과다.**
> $20 충전 후 키로 재측정하니 **REST는 열렸다**(이 문서의 "서버에서 부를 수 없다"는 결론은 뒤집혔다).
> 다만 **무료 모델이 잔액으로 풀리지 않는다**는 점은 그대로다. 최신 결론은 `measure-4-with-key.md` 를 볼 것.

측정일: 2026-08-18
대상: OpenCode Zen (`https://opencode.ai/zen/v1`), 모델 `deepseek-v4-flash-free`
계획서: `docs/01-plan/features/in-app-chatbot-zen.plan.md` §7 Phase 0 실측 ②

## 답해야 했던 질문

계획서의 설계는 **"키는 앱에 없고 Supabase 중계 함수에만 둔다"** 였다. 즉 서버 한 곳이
전 사용자를 대신해 Zen REST를 부른다. 실측 ②는 그 구조가 무료 티어에서 버티는지를 묻는다.

## 관측 사실

### 1. 서버가 부를 REST 경로는 익명으로는 즉시 막힌다

`POST https://opencode.ai/zen/v1/chat/completions` (인증 헤더 없음):

```
HTTP/1.1 429 Too Many Requests
{"type":"error","error":{"type":"FreeUsageLimitError",
 "message":"Error from provider (Console): Rate limit exceeded. Please try again later."}}
```

20초 간격으로 4회 재시도 — **4회 모두 동일한 429**. 순간 폭주 제한이 아니라 고착 상태다.
인증 실패(401)가 아니라 **무료 사용 한도(FreeUsageLimitError)** 라는 점이 중요하다.
"키가 없어서 거절"이 아니라 "무료 몫을 다 썼다"는 뜻이다.

참고로 `GET /zen/v1/models` 는 인증 없이 200으로 목록을 준다. 조회는 열려 있고 생성이 막힌다.
`/zen/go/v1` 은 별도 경로이며 이 모델을 지원하지 않는다(`401 ModelError: Model ... is not supported`).

### 2. 같은 순간 CLI는 정상 동작한다 — 통로가 다르다

REST가 429를 뱉는 그 시점에 같은 PC에서:

```
opencode run -m opencode/deepseek-v4-flash-free "숫자 7만 답하세요."
→ 7   (종료코드 0)
```

즉 **실측 ①에서 잰 20건은 REST 무료 몫과 다른 통로**를 탄 것이다.
그런데 자격증명은 없다 — `opencode auth list` 결과 **0 credentials**, `auth.json` 파일 자체가 없다.
무료 접근이 공식 클라이언트에 묶여 있고, 서버가 흉내 낼 대상이 아니다.

### 3. 공식 문서가 말하는 것

`https://opencode.ai/docs/zen` 에서 확인:

- 정상 이용 절차는 **"sign in → add your billing details → copy your API key"**.
  즉 REST를 쓰려면 결제 정보를 등록한 키가 필요하다.
- 무료 모델은 **한시적**이다("available for a limited time").
- 무료 기간 데이터 취급: **"During its free period, collected data may be used to improve the model."**
- 문서에 명시된 것은 호출 빈도 제한이 아니라 **월 지출 한도**(workspace·멤버별)다.
- **재판매·키 공유·다수 최종 사용자를 대신한 서버 호출에 대한 조항은 문서에 없다.**

## 판정

**계획서의 중계 구조는 무료 티어 위에 세울 수 없다.**

| 계획서 전제                        | 실측 결과                                          |
| ---------------------------------- | -------------------------------------------------- |
| 서버가 무료 모델을 중계            | 익명 REST는 429 고착 — 성립 불가                   |
| 키 하나로 전 사용자 중계           | 키를 쓰려면 결제 정보 등록 필요 = 쌤핀이 비용 부담 |
| 무료 모델 `deepseek-v4-flash-free` | 한시적 제공 — 언제 사라져도 이상하지 않음          |

실측 ①(도구 호출 94% PASS)은 **모델의 능력**을 증명했지만, 그 측정은 opencode CLI 경로에서
이뤄졌다. **제품이 쓸 경로(서버 REST)에서는 애초에 무료로 호출이 되지 않는다.**

## 오너가 판단할 지점

1. **비용을 쌤핀이 부담할 것인가.** 방침(`선생님이 AI 비용을 내지 않을 것`)은 지켜지지만,
   "무료라서 한다"는 전제는 깨진다. 유료 키 기준으로 단가·월 상한을 다시 계산해야 한다.
2. **한시적 무료 모델에 제품을 얹을 것인가.** 모델이 사라지면 기능도 사라진다.
3. **무료 기간 데이터가 모델 학습에 쓰인다는 문구.** 계획서는 집계 수치만 내보내지만,
   개인정보 방침의 재위탁 대상·국외 이전 표에 반영해야 하는 사안이다.
   (판단 기준은 법인 소재지가 아니라 실제 재위탁 대상 — 과거 오판 사례 있음)

## 하지 않은 것

- CLI 경로를 반복 호출해 한계치를 찾는 시험은 하지 않았다. 제품이 쓸 경로가 아니라 답이 되지
  않고, 무료 서비스를 무의미하게 소모하는 일이기 때문이다.
- 공식 클라이언트를 흉내 내 무료 몫을 얻는 시도는 하지 않았다. 사전 부검(§11)이 최대 위험으로
  꼽은 "재판매로 간주되어 차단"에 정확히 해당한다.
