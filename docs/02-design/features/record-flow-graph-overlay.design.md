# 생기부 흐름 보기 — 그래프 조망 덧입히기 설계 (2026-09-10)

> 오너 요청: "Manyfast 유저 플로우(docs.manyfast.io/plan/user-flow)처럼 노드·엣지·섹션으로 그래프를 그리는 모습".
> 권고안(편집은 레인 유지 + 읽기 전용 그래프 조망)을 오너가 승인했고, 낱말 두 가지를 확정했다 —
> **"서사"는 화면에서 뺀다**(이면의 설계 철학), 주제/장면/뼈대/이음말/흐름만 쓴다.
> 결정: [ADR-104](../../03-decisions/ADR-104.md). 상위 결정: [ADR-103](../../03-decisions/ADR-103.md)(레인 구조 유지, 자유 캔버스 기각).

## 1. Manyfast 와의 대응

| Manyfast                | 쌤핀 흐름 보기(이번)                                                   | 비고                                                                       |
| ----------------------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| 자유 캔버스             | 주제 세로 × 장면 가로 레인(편집) + **개요 지도**(읽기 전용)            | ADR-103 유지. 좌표 저장·자동 배치·동기화 충돌 없음                         |
| 노드 유형 + 범례        | 주제 노드(이름·장면 수·근거 수·자리 색점) + 장면 4자리 색 + **[범례]** | 색만으로 뜻을 전하지 않는다                                                |
| 라벨 있는 방향 엣지     | 앞 주제 → 이 주제 화살표 + **이음말 라벨**                             | 앞 주제는 하나뿐(선이 갈리지 않는다). 분기는 생기부(순차 서술)에 뜻이 없다 |
| 섹션                    | **이어진 흐름**(사슬) 묶음 — 머리글 + 왼쪽 띠                          | 주제에 영역이 저장돼 있지 않아 영역별 묶음은 만들지 않는다                 |
| 노드 앞뒤 삽입          | 장면 **사이 [+]** (hover/focus 에만 보임, 탭 순서엔 늘 있음)           | 스토어 `addScene(at)` 을 그대로 쓴다                                       |
| Undo/Redo               | 장면 이동·근거 놓기·뼈대 깔기 뒤 토스트 **[되돌리기]**(5초)            | 스택 없음, 최신 하나만                                                     |
| AI 생성 + 추천 프롬프트 | [AI 흐름 제안] → **추가 요청 칸 + 칩 4종** → [제안 받기]               | 칩은 값이 아니라 입력 도우미(이음말 칩과 같은 원리)                        |
| 편집 계획 확인          | 점선 미리보기에 "장면 N개 · 근거 N건 옮김 · 이음말 1"                  | 적용 전 저장 0회 유지                                                      |
| 버전 패널               | 없음(뼈대 깔기 되돌리기가 직전 판 역할)                                | 흐름 판 저장은 이번 범위 밖                                                |

## 2. 조각별 설계 (디자이너 스펙 반영)

### 2-1. 개요 지도 (`NarrativeFlowView.tsx`, `nav aria-label="주제 개요 지도"`)

- 주제가 둘 이상일 때만. 자리: 영역 필터 줄 아래, 레인 목록 위(옛 "주제 N개" 칩 줄 대체).
- 노드 = 단추 `w-32 rounded-xl bg-sp-card ring-1 ring-sp-border`: 이름(2줄 자름) · `장면 N개 · 근거 N건` · 자리 색점(`ROLE_DOT`).
  접근 이름: `N번째 주제 {이름}, 장면 N개, 근거 N건[, {앞 주제}에서 이어짐[, 이음말 …]]`.
- 엣지 = 이어진 주제 사이에만 `arrow_forward` 아이콘 + 이음말(잘라서). 형제(같은 앞 주제)면 "{앞 주제}에서".
- 묶음(사슬) 사이 세로 구분선. 오른쪽 끝 [모두 접기]/[모두 펼치기].
- 누르면 `[data-lane-id]` 로 그 주제를 찾아 `scrollIntoView` + 접기 토글에 포커스. SVG·캔버스·애니메이션 없음.

### 2-2. 섹션 — 이어진 흐름

- `chainGroups(lanes)`: 화면 순서(앞 주제 바로 다음)를 그대로 타며 앞 주제가 지금 묶음에 있으면 같은 묶음.
- 둘 이상이면 `section aria-labelledby` + `h3` "이어진 흐름 · 주제 N개" + `ol.border-l-2.border-sp-accent.pl-3`. 하나면 껍데기 없음.
- 점선 테두리는 쓰지 않는다(점선 = 범례상 "AI 제안 · 저장 전").

### 2-3. 범례

- `details/summary` 한 줄, 기본 접힘, 개요 지도 바로 아래. 틀에 맞는 자리 이름 4개(`frameRoleLabels`) + 화살표 + 점선.

### 2-4. 장면 사이 삽입 (`NarrativeLane.tsx`)

- 셀 사이 `li.w-3` 안의 둥근 [+] (`opacity-0` → `group-hover/insert`·`focus` 에 보임). 오른쪽 이웃이 **저장된** 장면일 때만.
- `onAddScene(at)` — `at` 은 저장 배열 인덱스. 상한이면 `disabled:hidden`. [초안 순서] 칩의 이동은 인덱스가 아니라 `data-scene-id` 로 찾는다(손잡이가 자식으로 끼어들었으므로).

### 2-5. AI 흐름 제안 요청 칸

- [AI 흐름 제안] 은 바로 보내지 않고 머리 아래에 `role="group"` 칸을 연다: textarea(선택, `NARRATIVE_NOTE_MAX`) + 칩
  `동기부터 강조 · 결과는 짧게 · 성장 중심 · 근거 적은 장면은 비우기` + [그만두기]/[제안 받기]. Esc 닫기, 닫히면 포커스는 단추로.
- 꾸러미: `NarrativeSuggestInput.instruction` → "선생님의 추가 요청(차례를 세울 때 이 말을 우선합니다):" + 가린 글. 비면 줄 없음.
- 점선 상자 머리: `AI 흐름 제안 · 장면 N개 · 근거 N건 옮김[ · 이음말 1]`, 단추 [이 흐름 적용].

### 2-6. 되돌리기 (`RecordEvidenceBoard.tsx`)

- 장면 이동: 반대 방향으로 한 번 더.
- 근거 놓기: 놓기 **직전** 자리(`EvidenceOrigin`: 장면 / 자리 미정 / 주제 미정)를 표로 적어 두고 그 자리로. 같은 자리끼리 묶어 저장.
- 뼈대 깔기: 직전 장면 배열 스냅샷 → 새 스토어 메서드 `restoreScenes` 로 통째 복원(메모 출처·id 보존.
  `applyNarrativeDraft` 로 되돌리면 선생님 메모에 AI 표식이 붙는다).

## 3. 하지 않은 것

자유 캔버스 · 영역별 섹션(추정 금지) · 흐름 판(버전) · Undo 스택 · 토스트 hover 시 타이머 정지 · 「자리 미정」에서 여러 장 한 번에 보내기.

## 4. 검증

`narrativeFlowView.test.tsx` 5건(개요 노드 접근 이름·섹션·범례·사이 삽입 인덱스·AI 요청 칸) · `recordEvidenceFlow` 갱신(제안 받기 2단계) ·
실기기(브라우저): 노드 2개·화살표 1·섹션 1·범례·노드 이동·사이 끼우기(4→5)·장면 이동 되돌리기. AI 요청 칸은 브라우저에 AI 연결이 없어 단위 검사만.

## 5. 단순화 감사 반영 (같은 날, 오너 "복잡해 보인다")

디자이너 감사 결론: 본문(장면 칸) 앞에 가로줄 다섯 겹이 문제. 적용 — 범례 줄 제거 · [+ 근거 ▾] 병합(직접 입력·엑셀 양식·엑셀 업로드) ·
힌트를 전구 아이콘+숫자 단추로 · 섹션 머리글 제거(띠 1px) · 개요 지도 **3개↑ 한 줄 칩** · 장면 머리 ← → hover/focus 노출 · 자리 미정 0건 숨김 ·
영역 칩 짧은 이름(접근 이름·title 은 전체). 결과: 1440×900 일반 모드에서 첫 장면 칸 y≈525~738. 보류: [넓게 보기] 제거 여부.
