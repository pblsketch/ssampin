## 0. 한 줄

초안 화면의 기본은 **학생 한 명을 넓게** 보는 집중 보기다. 30명을 한 번에 훑는 예전 목록은 **전체 훑어보기**로 남긴다.
오른쪽에는 **보조 공간 하나**만 있다(근거 / AI 초안 / 쌤핀 AI 가 탭으로 바뀌고, 닫으면 폭도 없다). 실행 상태는 화면이 아니라 **스토어**가 든다.

- 학생 목록(왼쪽, 224px): 번호·이름·상태 점(○ 초안 없음 / ● 작성 중·검토 중 / ✓ 검토 완료 / ⚠ 검토 필요) + **체크 상자**(초안 생성 대상 고르기, P9). 검색(이름·번호), 상태 필터는 정보 바의 기존 필터를 그대로 쓴다. 목록 머리에 [미작성 전체 선택]·[선택 해제].
- 본문(가운데): 기존 `RecordDraftRow` 의 편집 로직(자동 저장 700ms·blur flush·한도 오류·검토 플래그·형광펜 거울 레이어·`deliver` 배달·`onLiveText` 등록)을 **그대로** 쓰고 배치만 `variant="focus"` 로 넓게 그린다. 머리에 [근거 N건](미분류 M건은 배지) · [AI 도움] · [복사] · [이전]/[다음]. **Ctrl+Enter = 다음 학생**(현재 칸 blur → 저장 → 다음 학생 선택 → 새 칸 포커스).
- 보조 공간(오른쪽): §3.
- 보기 선택은 `Settings.recordDraftViewMode?: 'focus' | 'overview'` 에 기억한다(기본 `focus`).

### 2-2. 전체 훑어보기 (기존 목록 유지)

지금 화면 그대로: 30명 행이 세로로, 행마다 편집 칸. 행의 [AI ▸]·[미분류 N건]·[복사]·상태 버튼 유지. 행 왼쪽에 **체크 상자**만 추가(P9).
오른쪽 보조 공간은 §3 규칙을 똑같이 따른다(눌렀을 때만 열림 — 지금처럼 항상 붙어 있지 않다).

### 2-3. 넓은 창 / 좁은 창 배치 규칙 (`RecordDraftView` 루트 폭 W 를 ResizeObserver 로 잰다)

| 조건(패널 열림 기준)            | 배치                                                                        |
| ------------------------------- | --------------------------------------------------------------------------- |
| W − 224(목록) − 380(패널) ≥ 560 | 목록 + 본문 + 패널 (나란히)                                                 |
| 560 ≤ W − 380 < 784             | 목록을 **선택기**(머리의 `학생 ▾` + 이전/다음)로 접고 본문 + 패널           |
| W − 380 < 560                   | 패널을 **별도 보기(sheet)** 로: 본문 자리에 패널이 들어오고 머리에 [← 본문] |
| 패널 닫힘                       | 목록 + 본문(W < 784 면 선택기)                                              |

- ★구현에서는 본문 칸의 좌우 안쪽 여백 32px 을 빼고 잰다(`BODY_PADDING`) — 편집 칸이 **실제로** 560px 을 갖게. 즉 목록 유지 = W − 224 − 패널 − 32 ≥ 560, 나란히 = W − 패널 − 32 ≥ 560. 패널 폭은 W ≥ 1200 이면 380, 아니면 320.
- 수업 관리에서는 생기부 초안 탭에 **들어올 때 학급 목록을 접고**, 나갈 때 **들어오기 전 상태로 복원**한다(사용자가 그 사이 직접 펼쳤다면 건드리지 않는다). 선택된 학급은 그대로다.
- 페이지 가로 스크롤은 만들지 않는다. 보드(근거 정리)는 열이 많으면 가로 이동을 허용한다(기존).
- jsdom 에는 ResizeObserver 가 없다 → 폭을 모르면 "넓다"로 본다(테스트 안정).

## 3. 보조 공간 하나 (도크와 배타)

> ★2026-09-08 오너 피드백으로 바뀜: 처음 구현은 쌤핀 AI 도크를 이 패널의 세 번째 탭(포털 슬롯)으로 넣었다. 오너: "이 화면의 AI 는 어차피 생기부 초안을 쓰는 데 쓰는데, 범용 쌤핀 AI 가 같은 자리에 있으면 헷갈린다." →
> 탭·슬롯(`useAssistDockHostStore`, `createPortal`)을 **제거**하고 **배타 규칙**으로 바꿨다: 이 화면에서 쌤핀 AI 도크(형제 aside)가 열리면 초안 패널이 닫히고, [AI ▸]·[AI 도움]·[근거 N건]을 누르면 도크가 닫힌다. 오른쪽에는 여전히 하나만 있다. 아래 원 설계는 기록으로 남긴다.

- `RecordDraftSidePanel` 이 **오른쪽 보조 공간**이다. 탭: [AI 초안] [근거] [쌤핀 AI](쌤핀 AI 탭은 `enabled || ownAiEnabled` 일 때만).
- **열림 규칙**: [AI 도움]·[근거 N건]·행의 [AI ▸]·[미분류 N건]을 눌렀을 때 연다. ✕ 로 닫으면 폭 0. 사이드바의 쌤핀 AI 단추(`setOpen(true)`)를 누르면 이 화면에 있는 동안은 **같은 공간의 [쌤핀 AI] 탭**으로 열린다.
- **쌤핀 AI 는 어디에 그려지나**: `AssistDockContainer` 는 그대로 App 에 있고, `AssistDock` 만 자리를 바꾼다. 새 스토어 `useAssistDockHostStore { claimed: boolean; host: HTMLElement | null }`:
  - `RecordDraftView`(초안 모드일 때만)가 마운트 중 `claimed=true`. 근거 정리 보드 모드·다른 화면에서는 `false` → 예전처럼 App 오른쪽 형제 `<aside>`.
  - `RecordDraftSidePanel` 의 [쌤핀 AI] 탭 본문이 `host` 요소를 등록한다(콜백 ref).
  - `AssistDock`: `open && claimed` 이면 `host` 가 있을 때 `createPortal(내용, host)`(embedded: `<aside>` 대신 `flex h-full flex-col`, 창 드래그 띠·폭 CSS 변수 없음), `host` 가 아직 없으면 `null`(한 프레임 깜빡임 방지). `open && !claimed` 면 기존 `<aside>`.
  - 활성 탭 = `assist.open ? 'assist' : sideTab`. [쌤핀 AI] 탭 클릭 = `setOpen(true)`, [AI 초안]/[근거] 클릭 = `setOpen(false)` + 탭 변경. 임베디드 ✕ = `setOpen(false)`. 화면을 떠나면 `claimed=false` → 도크는 App 형제로 돌아간다(대화는 스토어에 있어 그대로).
- **권한 혼동 금지**: [쌤핀 AI] 탭은 일반 대화(Solar 또는 구독)이고, 초안 생성·분량 조절·분류 제안은 [AI 초안] 탭에서 **구독 AI 로만** 한다(기존 `runProvider` 규칙 그대로). 탭 머리에 "쌤핀 AI: 일반 질문" / "AI 초안: 구독 AI 전용"을 한 줄로 쓴다.

## 4. 실행 상태 소유 계약 (가장 중요한 부분)

새 스토어 `useRecordAiRunStore`(zustand, **저장 안 함**):

```ts
interface RecordAiRunState {
  /** 초안 생성 큐. scope = `${classId ?? 'homeroom'}:${area}:${subject ?? ''}` */
  drafts: Record<scope, Phase>; // scope 별. Phase = idle | running | preview | stopped (학생은 항목 안에)
  draftAbort: Record<scope, AbortController>;
  /** 분량 조절. runKey = 행의 3축 키 `${studentRef}:${area}:${subject ?? ''}` */
  length: Record<string, LengthStage>; // idle | confirm-prohibited | running | result | failed
}
```

| 상태                             | 주인                                                          | 근거                                                                                                       |
| -------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 미저장 본문                      | `RecordDraftView.liveDraftTextRef`(기존, 항목 = 글+고친 시각) | 저장본 `updatedAt` 보다 **새로울 때만** `initialLiveText` 로 되살린다(P8, 리뷰 지적 1). 행은 여기에 쓰기만 |
| 고른 학생·영역·보기·패널 열림·탭 | `RecordDraftView` 상태                                        | 패널·보드·목록은 props 로만 받는다(ADR-085 P1 그대로)                                                      |
| 초안 생성 큐(phase)              | `useRecordAiRunStore.draft`                                   | 패널이 학생마다 새로 만들어져도 큐가 산다(P6). 늦게 온 결과는 큐 항목의 `studentRef` 칸으로 저장(기존)     |
| 초안 생성 [중단]                 | `useRecordAiRunStore.draftAbort`                              | 새 인스턴스에서도 멈출 수 있다                                                                             |
| 분량 조절 단계·결과              | `useRecordAiRunStore.length[runKey]`                          | 학생을 바꿨다 돌아와도 결과가 있다(P7). 다른 학생에게는 보이지 않는다(키가 다르다)                         |
| AI 잠금·실행 번호                | `RecordDraftView.aiBusyRef/aiRunTokenRef`(기존)               | ADR-088 결정 11                                                                                            |
| 판(버전)·반영 표시               | `useRecordAiDraftStore`(기존, 디스크)                         | 그대로                                                                                                     |
| 30초 되돌리기·비교 켜짐·안내문   | 패널 인스턴스                                                 | 학생을 바꾸면 사라진다 — 되돌리기는 "바꾼 그 자리"에서만 뜻이 있다(문서화)                                 |
| 쌤핀 AI 대화·입력·첨부           | `useAssistStore`(기존)                                        | 도크가 옮겨 그려져도 잃지 않는다                                                                           |

지키는 선:

1. **결과는 요청한 학생 칸에만** 간다. 초안: 큐 항목의 `studentRef`. 조절: `runKey` 의 학생. 화면의 현재 선택은 저장 대상이 아니다.
2. **적용 직전 재확인**은 그대로: 분량 조절의 `getSourceText().trim() !== result.sourceText.trim()` 되묻기, 초안 [반영]의 한도 오류 표시.
3. 패널을 닫거나 탭을 바꾸는 것은 **화면 표시만** 바꾼다. 실행은 스토어에 남고, [AI 도움] 단추에 진행 중·결과 있음 배지가 뜬다("결과 돌아가기").
4. `aiActiveRefs`(미작성 필터에서 실행 중 행 붙들기)는 패널 콜백 대신 **스토어의 phase 에서** 계산한다. 패널이 닫혀도 붙들림이 풀리지 않는다.

## 5. 근거 카드 (S4)

- **겉면(항상)**: 본문 · 날짜 · 출처 칩 · **상태 배지**(`AI 제외됨`(호박), `원본과 내용이 달라요`(호박, [비교하기] 포함), 자동 제외 이유 한 줄) · "이것도 이 주제?" 칩(있을 때만, 1~2개).
- **선택했을 때(카드 클릭·Enter/Space)**: 조작 줄이 열린다 — 영역 칩(2개 이상일 때) · [AI 제외]/[AI 제외 해제] 토글 · [수정] · [원본 보기·수정] · [삭제 | 정리한 근거 삭제]. 마우스 올리기만으로 나타나는 것은 없다. Tab 으로 조작 줄에 들어갈 수 있다.
- 일괄: 하단 바의 [AI 제외]/[AI 제외 해제]/주제 보내기/[+ 새 주제로]/[미분류로] 그대로.
- ★**ADR-085 보강 2 §4-5 를 일부 바꾼다**: "토글은 겉에, 배지는 없앤다" → "**상태 배지는 겉에**, 토글은 선택했을 때". 이유는 §1 P4 — 카드마다 5~7개 단추가 반복되어 근거 본문이 묻혔다. 겉에서 상태를 잃지 않으므로 "숨긴 조작은 없는 조작"의 우려(상태를 모르게 됨)는 배지가 막는다. 새 ADR-093 에 기록.

## 6. AI 도구 단계별 표시 (S4)

`RecordDraftAiPanel` 본문 순서를 **단계**로 나눈다.

1. **설정(생성 전)** — 주제 칩(있을 때) · "Claude Code · Sonnet 5 [바꾸기]" 한 줄(누르면 공급자 토글·모델 선택이 그 자리에 펼쳐짐) · 실행 단추: [이 학생 초안 쓰기] · 체크한 학생이 있으면 [고른 N명] · [남은 학생 모두 (M명)]. 고른 학생 중 초안이 있는 학생이 있으면 "N명은 이미 초안이 있어요. 미리보기에서 [바꾸기]/[뒤에 붙이기]를 고릅니다" 한 줄(덮어쓰기 정책 확인).
2. **생성 중** — 진행 줄 + [중단](기존). 설정 줄은 숨긴다.
3. **결과** — 판 탭·바이트·미리보기·[반영|바꾸기]·[뒤에 붙이기]·[버리기]·[내 글과 비교](기존). **비교는 위아래**(내 글 → 고른 판)로 바꾼다. 좁은 패널에서 두 열 금지.
4. **분량 조절** — 접이식 그대로(ADR-088·092). 스토어 기반으로 결과가 학생 전환에도 남는다.
5. **형광펜 다시 표시** — 그대로.

## 8. 단계별 완료 조건

- **S2**: 초안 모드에서 쌤핀 AI 를 열어도 오른쪽 패널이 하나다(호스트 슬롯). 패널 닫힘 = 폭 0. 수업 관리 진입 시 학급 목록 접힘·복원. 다른 페이지의 도크는 예전과 같다(테스트).
- **S3**: 집중/전체 보기 전환 + 기억. 집중 보기 Ctrl+Enter. 체크 선택 → [고른 N명]. 큐가 학생 전환에도 산다(스토어). 미저장 글이 학생·영역·보기 전환에 남는다(테스트).
- **S4**: 카드 겉면 = 본문·출처·상태, 선택 시 조작. AI 패널 단계 표시·위아래 비교. 분량 결과가 학생 전환에 남는다(테스트).
- **S5**: 게이트 4종 + landing 2종 통과. 1280/1440/1920 × 담임/교과 × (패널 닫힘/AI 열림/쌤핀 AI 열림/보드) 스크린샷을 직접 보고 합격 기준(가로 스크롤 없음·본문 ≥560px·세로 글자 없음) 판정. 가이드·진행 기록·ADR 갱신.
