## 출시 범위

1. **내 API 키로 연결(BYOK)** (ADR-143, `78eaa478`) — 제미나이·오픈라우터·오픈코드 Zen/Go 키로 쌤핀 AI 패널·생기부 초안·근거 정리·분량 조절.
   키는 main 금고(OS 암호화)에만, 화면으로 돌려주는 통로 없음, 고정 3호스트·리디렉트 금지, 요금 상한, 다른 서비스 키는 보내지 않음.
2. **무료 쌤핀 AI 종료** (ADR-142 결정 7) — 실험실 스위치를 안내로 바꾸고, 저장된 `enabled` 는 불러올 때 끈다. 폴백도 함께 멎는다.
   관찰 기록 [학생별로 나누기]는 구독·내 API 키로도 열린다.
3. **보안 수정** — `secure:*`·`data:*` IPC 의 `../` 경로(데이터 폴더 밖 읽기·쓰기·지우기) 차단.
4. **개인정보처리방침** 제10·13조(국·영) 내 API 키 문단 (`8c6ff081`) — 랜딩 푸시와 함께 공개.
5. 공개 가이드: 새 문서 `features/own-api-key`, `features/ssampin-ai`·`features/own-ai`·관찰 나누기·업데이트 내역 갱신. 챗봇 문답 새 5건 + 옛 문답 경계 9곳.

서버 쪽 선행 조건: **없음.** 내 API 키는 쌤핀 서버를 쓰지 않는다. 생기부 초안의 1층 규정 배급(`record-prompt`)은 기존 그대로.

## 알려진 제한과 미검증

- **오너 실기기 확인 없이 출시**(오너 결정). 대신 에이전트가 설치형 빌드(dist, file://, 임시 데이터 폴더)로 실제 제미나이 키를 넣어
  연결·패널 답변·쓰기 제안 [실행]·키 삭제를 확인했다(ADR-143 「확인한 것」). 설치 파일로 깐 앱에서는 아직 확인하지 않았다.
- 오픈라우터·오픈코드는 **유효 키로 확인하지 못했다**(가짜 키 거절만 확인).
- 생기부 초안은 실제 키로 IPC 수준(규정 + 근거 → 초안 한 문단)만 확인, 초안 화면 단추로는 확인하지 않았다.
- 무료 쌤핀 AI 를 켜 두었던 선생님 중 구독·키가 없는 분은 업데이트 뒤 사이드바의 「쌤핀 AI」가 사라진다. 실험실 안내·릴리즈 노트·가이드·챗봇으로 다음 길을 알린다.
- 이미지 첨부는 내 API 키 경로에서 받지 않는다(첫 판).
- 오픈코드 Go 는 문서상 "코딩 에이전트용·남용 감시"다. 오너 결정으로 유지하고 카드 주의 문구로 알린다.
- 전체 테스트는 시간 제한 60초로 실행한다(기본 5초에서 느린 메타 테스트가 넘는다, 이전 출시와 같은 조건).
