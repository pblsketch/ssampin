## 9. 부가 관찰

- **데이터 정합성 자가 보존**: 마이그레이션이 dirty 변화 없을 때 같은 참조를 반환해 불필요한 디스크 쓰기 회피. localStorage의 정상 데이터(st-001 등)는 마이그레이션 후에도 빈 필드(예: `status` 미설정)를 그대로 둔다 — 이는 의도된 동작이며 `isStudentActive`가 `undefined → active`로 처리.
- **Cancel 안전성**: ConflictResolveModal과 StudentCountReduceConfirmModal 모두 취소 시 원본 데이터를 한 글자도 변경하지 않음을 확인.
- **콘솔 에러**: 6개 시나리오 전 과정에서 콘솔 에러 0건. 페이지 전환·모달 전환·저장소 mutation 모두 정상.
