# 생기부 흐름 — 실기기 확인 시나리오 (준일님용)

- 작성일: 2026-09-05
- 짝 문서: [체크리스트·한계 정리](record-flow-uplift-device-qa.report.md) — 결과만 적으실 때 그쪽을 쓰세요.
- 걸리는 시간: **처음부터 끝까지 약 40분.** 1부만 하셔도 큰 위험은 걸러집니다.

---

## 0. 이 확인이 왜 필요한가

코드 검사는 전부 통과했습니다(테스트 9,028건). 그런데 이 저장소에는 **검사가 전부
초록인 채로 살아 있던 결함**이 여러 번 있었습니다 — 출석번호가 한 칸씩 밀린 일,
유리 모드에서 창이 부모 상자에 갇힌 일, 드라이브 목록이 100개에서 잘린 일.

이번에도 실제로 그랬습니다. 실기기 확인 전에 Codex로 한 번 훑었더니 **검사가 못 잡은
결함 8건**이 나왔고, 그중 하나는 `.txt` 파일을 열면 화면이 죽는 것이었습니다.
지금은 고쳤지만, **눈으로만 보이는 것들이 아직 남아 있습니다.** 그게 아래 항목들입니다.

특히 **1부 ③(유리 모드)** 은 디자인 승인을 받지 못한 자리라, 준일님이 보시는 게
유일한 확인 방법입니다.

---

## 1. 준비 (5분)

### ① 쌤핀을 완전히 닫습니다

작업 표시줄 아이콘까지 확인해 주세요. 트레이(시계 옆 숨은 아이콘)에 남아 있으면
오른쪽 클릭 → 종료. **켜 둔 채로 다음 단계를 하면 앱이 파일을 도로 덮어씁니다.**

### ② 테스트용 자료를 심습니다

터미널에서 쌤핀 폴더로 간 뒤:

```bash
npm run seed:record-flow
```

이렇게 나오면 성공입니다:

```
[recseed] 심기 완료 — 건드린 파일 9개
  수업반 "흐름테스트 3-8" 에서 확인하세요:
```

> **선생님 실제 자료는 건드리지 않습니다.** 겹치지 않는 테스트 수업반 하나만 더하고,
> 바꾸는 파일마다 백업(`.pre-recseed-...`)을 남깁니다. 실제로 시험해 확인했습니다.
>
> "쌤핀이 실행 중입니다"가 뜨면 ①로 돌아가 주세요. 정말 닫으셨는데도 뜬다면
> 다른 프로그램을 잘못 본 것일 수 있습니다 — `npm run seed:record-flow -- --force`

### ③ 앱을 새로 켭니다

```bash
npm run electron:dev
```

> ⚠️ **이번 작업에는 앱의 속(메인 프로세스) 변경이 들어 있습니다.** 켜 두신 채로
> 코드만 바뀐 상태면 반영되지 않습니다. 반드시 **완전히 껐다가** 다시 켜 주세요.
>
> ⚠️ 브라우저(`npm run dev`)로 여시면 **말로 쓰기 단추가 아예 안 보입니다.** 고장이
> 아니라 "데스크톱 앱이 아니면 숨긴다"는 설계입니다. 1부는 꼭 `electron:dev`로 해 주세요.

### ④ 어디로 가면 되나

- **수업(교과) 쪽**: 왼쪽 메뉴 `수업 관리` → 위쪽 반 목록에서 **흐름테스트 3-8** 선택
  → `수업 기록` 탭 → 그 안의 **`📑 생기부 초안`**
- 그 화면 위쪽에 **[초안 | 근거 자료]** 토글이 있습니다. 둘을 오가며 확인합니다.

## 2. 1부 — 안 되면 기능이 없는 것과 같은 것 (20분)

### ① 말로 쓰기가 실제로 켜지는가

말로 쓰기는 **쌤핀이 음성을 듣는 게 아니라, 윈도우 받아쓰기를 대신 눌러 주는 것**입니다.
그래서 코드로는 "정말 떴는지"를 확인할 수 없습니다.

| 어디서                                     | 무엇을                  |
| ------------------------------------------ | ----------------------- |
| 담임 → `누가기록` 입력 화면, 메모 칸 아래  | **[🎤 말로 쓰기]** 클릭 |
| 수업 기록 → 관찰 입력 칸                   | 같은 단추               |
| 수업이 끝난 뒤 뜨는 알림 팝업의 한 줄 메모 | 같은 단추               |
| 옆핀 메모                                  | 머리 줄의 마이크 아이콘 |

**정상이면**: 커서가 그 글자 칸으로 옮겨지고, 화면 위쪽에 **윈도우 받아쓰기 막대**가
뜹니다. 말하면 글자가 그 칸에 들어갑니다.

**이러면 알려 주세요**:

- 단추가 아예 안 보인다 → 브라우저로 여신 건 아닌지 먼저 확인
- 단추는 눌리는데 받아쓰기 막대가 안 뜬다 → **학교 보안 프로그램이 막는 경우가 있습니다**
- 처음 한 번 윈도우가 동의를 묻는 화면 → 쌤핀이 아니라 윈도우 것입니다. 정상입니다

> ★ **담임 누가기록은 원래 빠져 있던 자리**입니다. 준일님이 "안 보인다"고 하셔서
> 어제 붙였습니다. 여기가 제일 중요합니다.

> 🎤 "듣는 중" 표시는 **일부러 안 만들었습니다.** 받아쓰기 창은 윈도우 것이라 앱이
> 언제 듣기 시작했는지 알 수 없고, 표시하면 거짓말이 되기 때문입니다. 휴대폰은
> 앱이 직접 듣기 때문에 그쪽에만 진짜 표시가 있습니다.

### ② 성취기준 고르기 창이 세 곳에서 다 뜨는가

같은 창이 세 군데에서 뜹니다. **셋 다** 봐 주세요 — 창이 부모 화면에 갇히는 사고가
이 저장소에 있었습니다.

1. `진도 관리` → 차시 입력 → **[성취기준 고르기]**
2. `과제 수합` → 과제 만들기 → **[성취기준 고르기]**
3. `수행평가` → 루브릭 편집 → **[성취기준 고르기]**

**정상이면**: 창이 화면 한가운데에 온전히 뜨고, 과목·영역으로 접힌 목록이 보입니다.

> ⚠️ **테스트 반(흐름테스트 3-8)에서는 목록이 비어서 뜹니다.** 3학년이라 2022 개정 자료가
> 없기 때문입니다(아래 ⑨ 참고). 목록을 보시려면 **1·2학년 반**에서 열어 주세요.
> 창이 갇히는지만 보실 거면 아무 반에서나 해도 됩니다.

**이러면 문제**: 창이 뒤쪽 상자 안에 **잘려서** 뜨거나, 스크롤이 안 되거나,
바깥을 눌러도 안 닫힘.

### ③ 유리 모드에서 배경이 제대로 나오는가 ★가장 중요

> **이 항목만 디자인 승인을 받지 못했습니다.** 디자인 에이전트가 두 번 다 빈 응답으로
> 끝나서, UI는 준일님이 직접 고르신 안으로 만들었습니다. 코드 검사로는 절대 안 잡히는
> 종류입니다(테스트 환경에는 화면 레이아웃이 없습니다).

1. 설정 → 화면에서 **유리(글래스) 모드**로 바꿉니다
2. `근거 자료` 화면을 엽니다 → **흐름가온** 선택
3. 아래 세 곳의 **배경이 제대로 깔려 있는지** 봅니다:
   - 위쪽 **주제** 칩 줄 (`전체` / `미분류` / 주제 이름들)
   - 주제를 눌렀을 때 나오는 **흐름 패널**
   - **[새 주제 만들기]** 상자

**정상이면**: 글자 뒤에 은은한 판이 깔려 글씨가 또렷합니다.

**이러면 문제**: 뒤 화면이 그대로 비쳐 **글씨가 겹쳐 보이거나**, 상자 테두리만 있고
속이 비어 보임. (이건 "반투명해 보이는" 것과 다릅니다 — **배경이 아예 없는** 상태입니다.)

라이트 모드·다크 모드에서도 한 번씩 봐 주시면 좋습니다.

### ④ 근거를 끌어다 놓아 주제에 넣기

체크해서 묶는 길은 자동 검사로 덮었지만, **끌어다 놓기는 못 덮었습니다**(마우스 동작이라
테스트로 흉내 내기 어렵습니다).

1. `근거 자료` → **흐름나래** 선택
2. `미분류` 칩을 눌러 아직 안 묶인 근거를 봅니다
3. 근거 카드 하나를 **끌어서** 위쪽 `차별과 구별` 주제 칩에 떨어뜨립니다

**정상이면**: 그 근거가 미분류에서 빠지고 주제 쪽으로 옮겨집니다.
**이러면 문제**: 끌리지 않거나, 놓아도 아무 일이 없거나, 화면이 굳음.

체크박스로 고른 뒤 **[주제로 묶기]** 를 쓰는 길도 함께 눌러 봐 주세요.

### ⑤ 점검 경고가 뜨는가 (막지는 않는가)

`초안` 화면에서 **흐름라온**을 고르면 이미 심어 둔 초안이 있습니다.

**정상이면**: 저장할 때 초안 아래에 경고가 뜹니다. 예를 들어 라온의 초안에는
`장면 없는 일반 평가` 와 `근거 없는 변화 서술` 이 걸려야 합니다.

**그리고 반드시 확인해 주실 것**: **경고가 떠도 저장은 됩니다.**
막히면 그게 오히려 문제입니다 — 이 기능은 "걸러 주는" 게 아니라 "알려 주는" 것입니다.

다른 학생 것도 하나씩 열어 보시면 갈래별로 다르게 뜹니다:

| 학생               | 걸려야 하는 갈래                                               |
| ------------------ | -------------------------------------------------------------- |
| 흐름라온           | 장면 없는 일반 평가 · 근거 없는 변화 서술                      |
| 흐름다솜           | 질문 없는 활동 나열 · 관찰할 수 없는 표현                      |
| 흐름나래           | 생기부에 적으면 안 되는 항목(대회·수상)                        |
| 흐름가온·나래      | 다른 학생과 같은 문장 (둘이 같은 문장이라 뒤에 쓴 쪽에 뜹니다) |
| 흐름가온 (긴 초안) | **아무 경고도 없어야 정상** — 대조군입니다                     |

**마지막 줄이 중요합니다.** 대조군에 경고가 뜬다면 오탐이 늘었다는 뜻입니다.

## 3. 2부 — 값이 맞는지 (15분)

### ⑥ 탐구 흐름이 줄기로 보이는가

`근거 자료` → **흐름가온** → 주제 **`소비 선택과 준거점 — 사회문제 탐구 보고서`** 클릭

**정상이면**: 3월~6월 기록이 **시간순 줄기**로 보이고, 각 마디에 `질문`·`시도`·
`시행착오`·`산출물`·`피드백`·`융합` 같은 갈래 이름이 붙어 있습니다.

### ⑦ "빈 고리"를 짚어 주는가

`근거 자료` → **흐름나래** → 주제 `차별과 구별` 클릭

**정상이면**: **`질문이 하나뿐이에요`** 같은 힌트가 뜹니다. 나래는 일부러 질문 1건만
넣어 두었습니다.

> 이건 **경고가 아니라 다음 수업의 실마리**입니다. 점수나 채움률은 만들지 않습니다.

### ⑧ "이것도 이 주제?" 제안

**흐름가온**의 미분류 근거 중 "…설문으로 물어보고 싶다"는 줄이 있습니다.
`소비 선택과 준거점` 주제에 `설문` 이라는 키워드가 있어서 **[이것도 이 주제?]** 로
제안돼야 합니다.

반대로 **흐름나래의 `차별과 구별` 주제는 제안이 하나도 안 뜨는 게 정상입니다** —
키워드를 비워 두었기 때문입니다. 화면에 그 사실이 한 줄로 적혀 있는지도 봐 주세요.

### ⑨ 2026학년도 중3·고3 — "직접 입력" 흐름

**테스트 반이 마침 3학년이라 여기서 바로 확인됩니다.**

`진도 관리` → **흐름테스트 3-8** → 차시 입력 → [성취기준 고르기]

**정상이면**: 목록 대신 이 안내가 뜹니다 —
**"이 학년은 2022 개정 자료가 없습니다 — 직접 입력해 주세요."**
직접 적어 넣으면 그대로 저장됩니다.

(선생님 실제 1·2학년 반에서도 한 번 열어 목록이 **제대로 나오는지** 비교해 주세요.)

> **고장이 아닙니다.** 그 학년은 2015 개정 교육과정이라 2022 개정 자료에 없습니다.
> 그 학년 선생님이 "왜 내 과목이 없냐"고 물으실 자리라, 안내 문구가 충분한지 봐 주세요.

### ⑩ 과제 파일 본문 — 두 갈래로 나눠서 봅니다

> ⚠️ **시드가 심은 "제출물"은 과제수합 화면에 뜨지 않습니다.** 제출 현황은 로컬 파일이
> 아니라 **서버(Supabase)에서** 가져오기 때문입니다. 시나리오를 쓰다 확인해 알게 되어
> 적어 둡니다 — 과제수합에서 시드 제출물을 찾으시면 헛걸음입니다.

**(가) 실패 표시가 어떻게 보이는지 — `근거 자료`에서 (시드로 확인 가능)**

`근거 자료` → **흐름라온** 선택. 근거 목록에 이 두 줄이 있어야 합니다:

- `제출 파일: 7월_보고서.hwp (본문 추출 안 됨)`
- `제출 파일: 실험사진.jpg (사진 파일 — 본문 추출 불가)`

**보실 것**: 교사가 "왜 본문이 없는지" 이유를 알 수 있는가. 지금은 글로만 적혀 있고
**다시 시도할 단추가 없습니다**(알려진 미완성 — 결함 아닙니다).

그리고 **흐름다솜**의 근거 중 "교내 과학탐구대회에서 최우수상…" 줄은 기재 금지 항목이
섞여 **AI에 보내지 않는 표시**가 붙어 있어야 합니다. 교사가 그 이유를 알 수 있는지도
함께 봐 주세요(이유 표시는 아직 없습니다 — 남겨 둔 항목).

**(나) 글자가 안 깨지는지 — 실제 과제로 (이번 QA의 핵심 수정)**

이건 시드로는 못 봅니다. **실제 과제를 하나 만들어** 확인해 주세요.

1. `과제 수합` → 과제 만들기 (파일 형식 제한은 **"문서"** 로)
2. 메모장에 한글 몇 줄을 적고 **ANSI(CP949)로 저장** → 그 과제에 제출
3. 같은 내용을 **UTF-8로 저장** → 또 제출
4. `근거 자료`에서 그 제출물을 끌어와 본문을 봅니다

**정상이면**: 두 파일 모두 **한글이 안 깨진 채로** 본문이 들어옵니다.

> 여기가 이번 QA에서 가장 크게 고친 부분입니다. 예전에는 `.txt`가 아예 안 받아졌고,
> 받게 만든 첫 판에서는 **깨진 글자가 "성공"으로 저장**돼 생기부 근거로 쌓였습니다.
> 여유가 되시면 메모장의 옛 "유니코드"(UTF-16) 저장도 함께 봐 주세요.

> 💡 `.md`도 이번에 열었습니다. 다만 **서버 쪽 허용 목록을 함께 고쳐야 했는데 빠져 있었고**
> (QA로 발견, 지금은 수정), 그대로였다면 교사는 고를 수 있는데 **학생만 제출이 막히는**
> 상태였습니다. 확인차 `.md` 파일도 한 번 제출해 거부되지 않는지 봐 주시면 좋습니다.

### ⑪ 휴대폰에서 말로 남기기

휴대폰으로 `m.ssampin.com` 접속 → 관찰 기록 입력 시트를 엽니다.

**정상이면**: 시트가 열릴 때 커서가 자동으로 들어가고 마이크 단추가 보입니다.
컴퓨터와 달리 **"듣는 중" 표시가 진짜로 뜹니다**(휴대폰은 앱이 직접 듣습니다).

아이폰은 **홈 화면에 추가한 뒤 그 아이콘으로 실행**해서도 한 번 봐 주세요.

## 5. 결과 적는 자리

각 항목에 ✅ / ❌ / — 만 적어 주시면 됩니다. **❌ 가 하나라도 있으면 출시를 시작하지 않습니다.**

```
1부  ① 말로 쓰기 __   ② 성취기준 창 __   ③ 유리 모드 __   ④ 끌어다 놓기 __   ⑤ 점검 경고 __
2부  ⑥ 흐름 줄기 __   ⑦ 빈 고리 __      ⑧ 주제 제안 __   ⑨ 중3·고3 __     ⑩ 파일 본문 __   ⑪ 휴대폰 __

실제 과제로: ANSI(.txt) __   UTF-8(.txt) __   .md 제출 거부 안 됨 __
```

**❌ 를 적으실 때**: 어느 화면에서 무엇을 눌렀고 무엇이 보였는지 한 줄이면 충분합니다.
화면 사진이 있으면 더 좋습니다.

## 6. 미리 알고 계셔야 할 것 (결함이 아닙니다)

- **주제를 고르고 초안을 써도 "이 주제로 쓴 초안"으로 저장되지는 않습니다.**
  칸은 만들었지만 값을 넣는 배선이 아직 없습니다. 주제를 고르면 그 주제의 근거만
  보여 주고 AI 요청문을 복사해 주는 데까지가 지금 동작입니다.
- **학년도를 넘기면 파일은 비지만 앱 메모리에는 남습니다.** 앱을 껐다 켜면 정리됩니다.
- **명단에 없는 이름은 가려지지 않습니다.** 학생 글에 나오는 다른 반 친구·가족·학원
  이름은 AI로 갈 때 가려지지 않습니다. 관찰 첨부에 이미 있던 한계이고, 과제 본문이
  들어오면서 그 범위가 **넓어집니다.** 실험실 토글을 정하실 때 이 점을 봐 주세요.
- **과제수합을 한 번도 안 들르면** 근거 창고에 제출물 후보가 안 뜹니다(기존 한계).
