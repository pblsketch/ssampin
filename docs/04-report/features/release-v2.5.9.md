## 출시 범위

1. **구글 드라이브 동기화 영구 교착 방지**(ADR-144) — 장부 중간 확정, 버려진 업로드를 덮지 않고 장부에 편입해 받기 판정,
   오래 멈췄던 실행은 확정 안 함.
2. **'동기화 충돌' 창 무반응 수정** — 실패 안내·다시 비교·닫기.
3. **컴시간 2차 대응**(ADR-145) — 두 겹 난독화·base64 검색 주소·enc5·조각난 열쇠·세션 쿠키+요청 토큰. 검색 실패 안내.
4. **구글 캘린더 일정 9시간 어긋남** — 한국 시각으로 맞춤, 캘린더마다 한 번 전체 다시 받기.
5. **직접 입력한 급식이 홈·위젯에 안 보임**.
6. **AI 도구 사용 중 쌤핀 창이 튀어나옴** — AI 연결용 실행이 일반 실행으로 떨어지면 창 없이 종료. 설정 읽기 전 단축키 등록 방지.
7. **할 일** — 홈 입력 저장 실패 안내, 날짜 달력·표 보기 수정 창을 body 포털로(유리 효과).
8. **랜덤뽑기·모둠 나누기 반 목록** — body 포털.
9. **수업 교체 때 반이 안 바뀜**.

v2.5.8 이후 커밋된 것: 서명 이미지 보관기간 자동 삭제 복구(`5bdad875`, 081 — 서버 쪽은 이미 운영 적용·확인됨, 앱 동작 변화 없음).

## 실기기 확인 (에이전트 대행, 2026-11-10)

설치 전에 오너 자료 폴더(181파일·18MB)를 임시 폴더에 그대로 복사해 두었다.

  2.5.9 를 켜자 스스로 진행했다: 정적 파일 대부분 "장부만 편입", `events` 는 "버려진 장부 밖 파일을 원격 장부에 편입 — 받기 판정 후 재업로드",
  사진 123건 등록(이미 올라가 있던 세대 파일은 내용 확인 후 재사용), 로컬 장부가 정적 파일 직후(18:38)에 저장됨(중간 확정).

## 알려진 제한과 미검증

- **표 보기 수정 창**: 이 PC 는 할 일 프로 모드가 꺼져 있어 화면으로 확인하지 못했다(설정을 바꾸지 않음). 단위 테스트로만 확인.
- **급식 직접 입력**: 이 PC 는 학교가 등록돼 있어 재현 조건이 아니다. 단위 테스트로만 확인.
- **구글 일정 시각**: 캘린더 시간대가 한국이 아닌 계정으로는 확인하지 못했다. 단위 테스트로만 확인. 6개월보다 오래된 일정은 바로잡히지 않는다.
- **AI 도구 창 문제**: 원인이 "환경변수 없이 실행"이라는 것은 코드상 유력하지만 신고자 환경에서 확인하지 못했다. 방어 동작만 확인.
- **다른 기기(학교 PC)와의 합류**: 두 번째 기기에서의 동작은 확인하지 못했다. 그 기기도 2.5.9 가 필요하다.
- **동기화 충돌 창의 [이 기기 유지] 단추 배경**: `bg-sp-accent/10` 이 칠해지지 않아 글자만 보인다(기존 문제, 이번에 바꾸지 않음).
- **컴시간**은 의도적으로 바꾸고 있어 다시 깨질 수 있다. 자동 감지는 없다. macOS 실기기는 확인할 수 없다.
- **자동 업데이트 감지·설치**(v2.5.8 이하 → 2.5.9)는 이 PC 가 이미 2.5.9 라 확인하지 못한다.
- **이번에 고치지 않은 제보**: 하위 할 일 수정(기능 없음), AI 브릿지 출결 일부만 표시, 수업 교체 삭제 뒤 교시 선택 불가(재현 못 함), 할 일 저장 실패의 근본 원인.
- **실기기 확인 중 발견(별건)**: 오너 PC 의 `tasks-sync-state.json`·백업이 둘 다 0 으로 채워진 210바이트(2026-11-06 13:37)라
  Google Tasks 동기화 초기화가 매번 실패한다. 이번 변경과 무관하며 손대지 않았다. 원본·백업이 함께 깨진 파일을 앱이 스스로 복구하지 못하는 문제는 별도 판단이 필요하다.
