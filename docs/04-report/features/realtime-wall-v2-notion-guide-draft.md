## 2. "5장. 실시간 도구" 페이지에 추가할 섹션

### 5-5. 실시간 담벼락 v2.0 — 탭·권한·PIN·엑셀 (v2.1.0 신규)

#### 5-5-1. 탭 관리 (최대 8개)

담벼락 하나 안에 게시판처럼 **탭을 8개까지** 만들 수 있어요. 예: "오늘 질문", "복습 메모", "교사 메모"처럼 주제별로 분리.

**탭 추가**: 교사 화면 상단 탭 바 우측의 `+` 버튼 → 탭 이름 입력 → Enter.
**탭 이름 변경**: 탭 옆 `⋮` 메뉴 → "이름 변경".
**탭 삭제**: 탭 옆 `⋮` 메뉴 → "탭 삭제". 단, **기본 탭(default)은 삭제 불가**.
**순서 변경**: (v2.1.x 추후 지원 예정)

**8개 cap 도달 시**: `+` 버튼이 비활성되고 "탭은 최대 8개까지 만들 수 있어요" 토스트 표시.

> ⚠️ **탭을 삭제하면 카드는?**
> 해당 탭 안에 있던 모든 카드(post)는 자동으로 **기본 탭으로 이동**합니다. 좋아요·댓글·핀 고정 상태도 그대로 보존돼요. 잃어버린 카드는 없습니다.

#### 5-5-2. 탭별 권한 (전체공개 / 교사 전용 / 역할 제한)

탭마다 학생 접근 권한을 다르게 설정할 수 있어요.

| 권한                   | 학생 동작                      | 용도                  |
| ---------------------- | ------------------------------ | --------------------- |
| **전체 공개** (기본값) | 모든 학생이 카드 읽기·쓰기     | 일반 토론             |
| **교사 전용**          | 학생 화면에서 탭 자체가 숨겨짐 | 채점 메모, 운영 노트  |
| **역할 제한**          | v2.1+ 구체화 예정              | (역할 기반 접근 제어) |

**설정 경로**: 탭 옆 `⋮` 메뉴 → "접근 권한" 섹션에서 라디오로 선택.
변경 즉시 모든 학생 화면에 반영(WebSocket broadcast).

**일괄 설정**: 보드 설정(⚙️) 드로어 → "탭별 권한 일괄 설정" 패널에서 한 번에 조정.

#### 5-5-3. PIN 필수 모드 — 학생 본인 확인 강제

닉네임만으로 누구나 들어오는 게 신경 쓰인다면, 학생에게 **숫자 4자리 비밀번호 입력을 강제**할 수 있어요.

**켜는 법**: 실시간 담벼락 도구 우상단 ⚙️ 보드 설정 → "비밀번호 입력 필수" 토글 ON.

**효과**:

- 학생이 담벼락에 들어올 때 닉네임 + PIN(숫자 4자리) **둘 다 필수**
- PIN 미입력 상태로는 카드 제출 불가
- PIN 모달은 ESC/배경 클릭으로 닫을 수 없음 (강제 진입)
- 같은 닉네임으로 재입장 시 동일 PIN으로 본인 확인 → 닉네임 도용 차단

**기본값**:

- v2.0 신규 보드 → **ON** (PIN 필수)
- 기존 v1.x 보드 → **OFF** (원래 동작 유지)

#### 5-5-4. 엑셀(XLSX) 내보내기 — 9칼럼

수업 후 카드를 인쇄·보관하거나 평가 자료로 쓰려면 엑셀로 받으세요.

**경로**: 실시간 담벼락 도구 우상단 📤 내보내기 패널 → **XLSX** 라디오 선택 → 다운로드.

**9칼럼** (한국어 헤더):

1. 작성일시
2. 닉네임
3. 탭ID
4. 탭이름
5. 내용
6. 색상
7. 좋아요수
8. 댓글수
9. 상태

**옵션 2종**:

- **닉네임 표시 ON/OFF** — 평가용은 ON, 익명 분석용은 OFF
- **현재 탭만 vs 전체 탭** — 특정 토론만 vs 전체 보관

**PNG 이미지 내보내기**도 그대로 유지됩니다(라디오에서 선택).

> 💡 **성능 안전 장치**: 학생 화면(SPA)에는 엑셀 라이브러리가 포함되지 않아 학생 페이지 로딩 속도에 영향이 0입니다.

#### 5-5-5. 기존 v1.x 보드 자동 마이그레이션 (무손실)

업데이트 후 예전 담벼락을 열면 **자동으로 v2 구조로 변환**돼요.

- 기존 카드, 좋아요, 댓글, 교사 하트, 색상 → **100% 보존**
- 모든 기존 카드는 "기본 탭(default)"에 자동 배치
- v2 신규 기능(탭 추가·권한·XLSX) 바로 사용 가능
- PIN 필수 모드는 기본 OFF로 유지 (기존 학생 흐름 안 깨짐)
- 학생이 구버전 브라우저 캐시로 접속해도 메시지 파싱 정상 (legacy fallback)
