## 사전 확인한 구글 서버 동작 (2026-10-14, 구글 API 탐색기·임시 목록 1개를 만들고 지움)

- **삭제된 항목에 수정을 보내면 오류 없이 200 으로 받아들여지고 삭제 상태 그대로다**(옛 코드가 쌤핀 할 일을 지울 수 있던 이유 → 이번 수정).

## 알려진 제한과 미검증

- **쌤핀 앱 화면에서의 충돌 알림·기록은 실제 구글 계정으로 확인하지 못했다**(설치본에 이번 변경이 없었고 개발 빌드를 실제 자료로 돌리면 선생님 할 일이 구글에 올라갈 수 있어 시도하지 않음). 체크리스트: [google-tasks-sync.md](../../google-tasks-sync.md) §8.
- **오너 실기기 확인 없이 출시**(위). 특히 쓰기 경로(`data:write`)를 건드렸으므로 설치본에서 할 일 추가·완료·삭제가 정상인지가 첫 확인 대상이다.
- 할 일 입력이 목록에 안 뜬다는 사용자 신고는 정상 조건에서 재현되지 않았다. 이번 변경은 원인을 없애는 것이 아니라 **실패를 화면에 드러내는 것**이다.
  같은 신고가 오면 앱 버전·기존 할 일 표시 여부·구글 연동·자료 폴더 위치·로그를 받는다.
- 충돌 판정의 허용 오차(5분), 쌤핀 영구 삭제는 기록되지 않음, 컴퓨터 두 대 이상 연결 시 각각 기록(ADR-141).
- 설정 카드 「확인되지 않은 앱 경고는 정상이에요(검증 대기 중)」 안내 문구는 심사 승인 뒤에도 경고가 남는지 확인 전이라 그대로 뒀다(오너 확인 대상).
- 자동 업데이트 감지→다운로드→설치→앱 버전 2.5.5 왕복, macOS 실제 설치·[그래도 열기]는 확인하지 못했다(피드와 파일 자체는 검증). 공증하지 않았다.
- 전체 테스트는 소스 전체를 읽는 메타 테스트 몇 개가 이 환경에서 기본 5초 제한을 넘겨 60초로 늘려 실행했다(CI 는 통과).
- Dependabot 경고(79건: critical 4·high 41)는 이번 범위와 분리된 별도 보안 작업이다.
