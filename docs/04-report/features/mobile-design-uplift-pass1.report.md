## 무엇을 했나 (교사 눈높이)

모바일 앱이 "급하게 만든 느낌"을 주던 마감 문제 6가지를 손봤습니다. 기능은 그대로 두고, **보이는 인상**만 전문 디자이너가 만진 수준으로 끌어올렸습니다.

1. **쌤도구 아이콘 통일** — 신호등·주사위·타이머 등 11개 도구가 제각각 이모지(🚦🎲⏱️)였던 걸, 앱 전체와 같은 정식 아이콘 + 은은한 회색 칩으로 통일했습니다. 기기마다 다르게 보이던 문제가 사라지고 한 앱처럼 정돈됩니다.
2. **할 일 우선순위 표시** — 원색 이모지 점(🔴🟡🟢)을 앱 색 체계(빨강=긴급, 주황=보통, 초록=낮음)에 맞춘 깃발 아이콘으로 바꿔 다크모드에서도 색이 어긋나지 않습니다.
3. **빈 화면에 쌤핀이 등장** — 회색 글자 한 줄뿐이던 빈 화면(할 일·자리 배치)에 마스코트 쌤핀이와 "다음에 뭘 하면 되는지" 안내를 넣어 따뜻하고 친절해졌습니다. 일정·보관함 등은 절제된 아이콘으로 정리했습니다.
4. **온보딩 첫인상** — 환영/로그인 화면의 이모지(👋🔄)를 쌤핀이 마스코트로, 정보 화면은 정식 아이콘 메달리온으로 바꿔 첫 실행부터 브랜드가 느껴집니다.
5. **설치 안내 배너 위치** — 배너가 [+] 추가 버튼을 가려 누를 수 없던 문제를 고쳐, 배너를 버튼 위로 올렸습니다. 배너 아이콘도 이모지에서 정식 아이콘으로.
6. **글씨 크기·위계** — 너무 작던 하단 탭 글씨(9px→11px)를 키우고, 홈 상단에서 경쟁하던 두 제목의 위계를 정리(날짜를 확실한 주 제목으로)했습니다. 에러·안내 화면의 이모지도 정식 아이콘으로.

## 핵심 설계 결정

- **통일 중립 칩**: 11개 도구에 11가지 색을 칠하는 대신, 모두 은은한 회색 칩 + 파란 아이콘 하나로 통일. 브랜드 방향(`.impeccable`의 절제된 Notion/Linear 톤, 안티=네온)에 맞춘 선택. 설치 배너·온보딩 메달리온까지 같은 칩 스타일로 앱 전역 일관.
- **토큰 순수성**: 신규 raw 색상 0건. sp 토큰의 Tailwind 투명도 수식(`bg-sp-accent/NN`)은 조용히 투명 렌더되는 함정이라, 칩 배경은 `bg-black/5 dark:bg-white/10`로만 처리.
- **하위호환**: `EmptyState`에 마스코트·힌트·선택적 버튼을 추가하되 기존 4개 prop 소비처(Memo·관찰·진도)와 완전 호환.
