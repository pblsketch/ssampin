# 참여교실 통합·문항 확장 검증 (2026-09-21)

> 이 보고서는 **2026-09-21 1차 확장 시점**의 기록이다. 이후 같은 날
> [ADR-127](../../03-decisions/ADR-127.md)~[ADR-130](../../03-decisions/ADR-130.md)으로
> 시각 언어·도구 이름(`퀴즈·설문·토론`)·유형 묶음이 바뀌었고, **2축 평가는 2×2 매트릭스로 대체**됐다.
> 아래 본문의 유형 이름과 개수는 그 전 기준이다.

## 반영 범위

- 목적 선택 없이 활동을 만들고 문항 유형을 조합한다. 기존 자료 접근을 보존한다.
- 순서 배열·순위·이미지 위치·숫자·점수 배분·2축 평가·아이디어와 투표·여러 항목 척도, 선택지 이미지·질문 공감을 연결했다.
- 유형 선택 시 학생 입력 체험과 결과 미리보기, 명시적 추가, 작성 문항 미리보기를 제공한다.
- 학생 실제 입력·서버 검증·공개·투표·교사/교실/지난 결과를 연결했다. 정답은 공개 입력 설정에서 제외한다.

## 확인한 동작

- 실제 HTTP 200 및 WebSocket: 추가 입력 8종 연속 제출, 범위 밖 응답 거부, 정답 비노출, 공개 후 투표와 중복 공감 방지.
- 브라우저: 추가 입력 8종 체험→제출→결과 표시; 전후 저장 데이터 동일. 편집 저장·취소 원본 보존·작성한 문항 미리보기.
- 모바일 390×844: 가로 넘침 없음, 40+30+30 점수 배분 제출, 아이디어 공감 0→1.
- 저장소: 혼합 문항의 의견은 오답 제외, 결과 저장/재읽기, 원본 편집·삭제 후 이전 결과 보존, 재응답 투표 회차 분리.
- 독립 코드 리뷰: 정답 배열 노출·점수표 누락·투표 초기화·워드클라우드 표시·음수 척도 시각화 수정 후 차단 사항 0건.

## 점수·초대 흐름 추가 검증

- 실제 학생 서버와 교사 React 화면을 로컬 HTTP 기반 IPC 테스트 연결로 묶어 확인했다. 학생 제출 즉시 교사 10점, 마감 전 학생 점수 비노출, 마감 후 10점, 다음 문항에서 누적 점수 유지, 중도 종료 후 2문항 중 1정답·10점이 일치했다. 최종 순위 공개 버튼도 확인했다.
- 19개 유형의 실제 학생 HTML 미리보기를 브라우저에서 열었고 실행 오류 0건이었다. 문항 목록과 미리보기의 스크롤을 분리했다. 모바일 390px에서 가로 넘침 없음.
- 편집 취소 시 원본 제목 유지, 초대 실패 후 편집 내용 유지, 초대 대기실의 링크 복사 버튼을 확인했다. 주요 버튼의 기본 배경색 충돌을 제거했다.
- 독립 재검토: 중도 종료 결과, 풀이 중 점수, 공백 정답 차단, 최종 순위 공개, 불투명 항목 ID, 워드클라우드 집계, 보너스 안내, 교실 이미지 보기의 8건 모두 해결. 관련 도메인·컴포넌트·실제 서버 테스트 17건 통과.
- 증거: `.dryforge/evidence/participation-classroom/{preview-browser,quiz-browser,final-ui-browser,final-focused}.log`, `output/playwright/participation-{type-picker,editor-final,teacher-live,student-final}.png`. 테스트 연결은 실제 Electron 창 간 IPC나 학교망 터널 검증을 대체하지 않는다.

## 확인하지 않은 범위

학교망 터널·공개 접속 주소와 실제 휴대폰 여러 대의 동시 참여는 미검증이다. Windows 설치 패키지에서 Electron UI를 직접 조작하는 확인은 하지 않았다. 서버 로직은 실제 로컬 HTTP/WebSocket으로, 교사·학생 UI는 실제 브라우저로 분리 검증했다.

커밋·푸시·배포·출시는 하지 않았다. 시작 전 다른 세션의 미커밋 변경을 보존했다.
