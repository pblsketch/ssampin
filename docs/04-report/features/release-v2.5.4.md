## 챗봇 KB 상세

- 원고: 출시 대기 3건(퀴즈·설문·토론)을 v2.5.4 로 옮기며 옛 한 단추 `[응답 마감 · 결과 공개]`·`[+ 활동 만들기]`·옛 자료 위치를 바로잡았다. 새 문답 12건(진행 세 단추 · 옛 도구 5종 · 참여 주소 · 응원·잔디 · 오늘 챙길 학생 등 · 알림 기준 · 한 주 정리·학기 돌아보기 · 학교 달력 인사 · 타이머 · 단계 타이머 · 발표 타이머 · 쌤핀 AI 구글 자료 제외). 부딪히는 옛 문답 23건(25곳)에 경계·바로잡기 — "쌤도구 37가지", "타이머 3가지 모드", 옛 참여 링크 절차, 복합 설문 베타 켜는 법, 쌤도구 기능 요약 등. `PENDING_RELEASE_QA` 는 절차 설명과 함께 빈 배열로 남겼다.
- 실제 질문(`isTest: true`)에서 잡아 고친 것:
  - "응답 마감 뒤 결과가 안 보여요" → 없는 **설정 옵션**을 지어냄 → "결과 공개를 끄는 설정은 따로 없습니다" 부정형 사실 추가.
  - "단계 타이머 사용법" → 발표 타이머의 [시간 기록 보기]를 섞음 → 문답을 둘로 나누고 "단계 타이머에는 시간 기록이 없습니다" 추가.
  - "설문 참여 링크는 어디서 만드나요" → 옛 문답이 이겨 옛 절차만 답함 → 옛 문답을 **새 경로 먼저, 옛 도구 절차는 뒤**로 다시 씀.
  - "쌤핀 AI가 구글 캘린더 일정을 몰라요" → 모델이 버그 신고로 분류한 회차에 "업데이트 후 다시 연동하면 전달된다"(정반대)로 답함 → "고장이 아니며 업데이트·재연결해도 가지 않는다" 추가, 이후 3/3 정확.
- 최종 KB 로 12개 질문 모두 핵심 사실을 맞게 답했다. **남은 흔들림**: 단추 위치를 "오른쪽 위"라고 하거나(실제 화면 아래 띠), 옛 도구 5종을 "이름이 바뀌었다"고 말하거나, 짧은 주소 도메인을 `ssampin.com/s/` 로 말하는 등 표현이 회차마다 흔들린다. KB 사실은 맞으므로 여기서 멈췄다.

## 출시 후 확인 잔여

- **타이머(ADR-139) 오너 실기기 확인** — 오너 결정으로 확인 없이 출시했다. Electron 설치본에서 창 X 자동 팝업·[본문으로 가져오기] 왕복·메모리 절약 재생성·전체화면, 실제 팝업 창 420px, 휴대폰판 새 타이머(m.ssampin.com 에 이미 배포), 어두운 테마, 알람 소리 실제 재생.
- 구버전 Windows 설치본의 자동 업데이트 카드 → 다운로드 → 설치 → 앱 버전 2.5.4 전체 왕복. 피드와 파일 자체는 검증 완료.
- macOS arm64/x64 실제 설치·[그래도 열기]. 공증하지 않았으므로 `spctl` 거부 허용은 그대로.
- 관문을 켰으므로 **v2.5.3 이하 사용자의 쌤핀 AI 는 일정·할 일 질문에 업데이트 안내를 받는다**. 업데이트 비율과 문의를 지켜본다.
- 구글 클라우드 콘솔의 `userinfo.email` 범위 등록 확인(ADR-136 T7, 오너 몫).

## 알려진 제한과 경고

- 공개 가이드의 쌤도구 목록 그림(`tools-grid.png`)은 v0.3.7 시절 화면이라 내린 도구(투표·주관식 설문·워드클라우드)가 보인다. 이번 출시 전부터 있던 낡은 그림이며 따로 새로 찍어야 한다.
- 쌤핀 AI 가 구글 항목을 뺀 할 일 결과에 "하나뿐입니다"처럼 단정하는 문제(ADR-136 관찰)는 그대로다 — 챗봇 문답에 "아래 칸의 구글 항목은 빠진 것"이라고 적어 두었다.
- `ssampin-embed` ingest 는 지운 뒤 다시 넣는 방식이라, 배치 하나가 실패하면 그 사이 문서가 빈다. 이번에는 같은 호출 안에서 재시도해 484/484 로 맞췄다.
- Dependabot 경고(45건)·GitHub Actions Node20 deprecation 은 이번 범위와 분리된 별도 보안 작업이다.
