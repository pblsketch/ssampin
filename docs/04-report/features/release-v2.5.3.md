## 출시 범위

1. **컴시간 이번 주 보강·교체를 변동 시간표로 자동 반영** (ADR-123, 커밋 `8ae44e8d` 로 main 에 있음)
   확인하는 즉시 그 주 날짜의 변동으로 등록하고, 기본 편성표는 건드리지 않는다. 직접 만든 변동이 있는 칸은 건너뛰며 `[되돌리기]`·`[다시 반영하기]` 로 그 주만 되돌린다. 주말은 제외.
2. **빠른 학생 기록 허브** (ADR-122, 미커밋)
   대시보드 `오늘 기록` 카드를 담임+수업반 학생 기록 허브로 넓혔다. 학생 검색 → 저장 위치 선택 → 본문 순서의 빠른 기록, 여러 명 동시 기록, 전역 단축키 `Ctrl/Cmd+Alt+R`, 명령 팔레트 `학생 빠른 기록`. 위젯 모드에서는 별도 팝업 창으로 뜬다.
3. **쌤도구 외부 도구 2종 추가 + NEW 배지 정리** (미커밋)
   오너 제작 **성취도 분석기**·**분할점수 산출기** 카드를 추가하고, 기존 도구 8개의 `NEW` 배지를 내렸다. 도구 총수 35 → 37.

범위에서 뺀 것: 관리자 Analytics 롤업 복구(`5a3785ab`, 개발·운영 작업이며 랜딩 배포로 이미 반영), v2.5.2 챗봇 문답 수정(`45de1c45`, 이미 ingest 완료), 모바일 오프라인 캐시(`2f491cc6`, m.ssampin.com 배포 완료), 자기평가 070 등 미적용 마이그레이션.

## 알려진 제한과 미검증

- 컴시간 서버 조회부터 시작하는 전체 경로는 실계정(학교 코드·교사 지문)이 없어 미검증이다. 주말 주차 실측도 하지 않아 주말은 자동 등록에서 제외한 상태다.
- 빠른 학생 기록의 Electron 확인은 별도 `.dev-data` 개발 빌드에서 했다. 오너 실데이터·설치본 확인은 남았다.
- macOS 워크플로우는 서명·아키텍처만 보고 공증하지 않는다(`spctl` 거부 허용은 그대로).
- 자동 업데이트 왕복(구버전 → 카드 → 설치 → 버전 표시)은 출시 후에만 확인할 수 있다.
- 의존성 취약점(Dependabot·npm audit)과 GitHub Actions Node20 deprecation 경고는 이번 범위와 분리된 별도 보안 작업이다.
- 관리자 Analytics 갱신 소요가 325초까지 늘어 컴퓨트 승격/증분 롤업 재검토 조건에 닿았다(2026-09-18 기록 참조). 이번 출시와 무관하지만 열려 있는 판단이다.
