## 출시 범위

1. **컴시간 이번 주 보강·교체를 변동 시간표로 자동 반영** (ADR-123, 코드 커밋 `8ae44e8d`)
   확인하는 즉시 그 주 날짜의 변동으로 등록하고 기본 편성표는 건드리지 않는다. 직접 만든 변동이 있는 칸은 건너뛰며 `[되돌리기]`·`[다시 반영하기]`로 그 주만 되돌린다. 주말 제외.
2. **빠른 학생 기록 허브** (ADR-122, 이번 커밋 `8d51f06b`)
   대시보드 `오늘 기록` 카드를 담임+수업반 학생 기록 허브로 넓혔다. 학생 검색 → **저장 위치 직접 선택** → 본문 순서, 여러 명 동시 기록, 전역 단축키 `Ctrl/Cmd+Alt+R`, 명령 팔레트, 위젯 모드 별도 팝업. 출결은 저장하지 않고 기존 출결 화면으로 보낸다.
3. **쌤도구 외부 도구 2종 추가 + NEW 배지 정리** (이번 커밋)
   성취도 분석기·분할점수 산출기 추가, 기존 8개 `NEW` 배지 제거. 도구 총수 35 → 37.

범위에서 뺀 것: 관리자 Analytics 롤업 복구(`5a3785ab`, 이미 운영·랜딩 반영), v2.5.2 챗봇 문답 수정(`45de1c45`, ingest 완료), 모바일 오프라인 캐시(`2f491cc6`, 배포 완료), 다른 세션의 미커밋 MultiSurvey v2 작업, Dryforge 하네스(ADR-120/121), 자기평가 070 등 미적용 마이그레이션.

## 챗봇 KB 상세

- v2.5.0 컴시간 문답이 **"자동 반영하지 않습니다"** 로 새 동작과 정면 충돌했다. 새 문답을 덧붙이지 않고 그 문답을 v2.5.3 동작으로 다시 썼다(진실의 출처를 하나로 유지).
- 실제 질문 확인(`isTest: true` 로 통계 오염 방지): 수업 중 빠른 기록 / `Ctrl+Alt+R` / 컴시간 자동 반영 여부 / 이번 주 변동 되돌리기 / 분할점수 산출기 / 성취도 분석기 — 6/6 정확. 컴시간 질문에 "네, v2.5.3부터 이번 주 보강·교체가 바뀌면 자동으로 반영됩니다"로 답한다.
- 임시 `ADMIN_API_KEY` 는 작업 직후 다른 값으로 교체하고 함수를 재배포했다. 키 값은 어떤 로그·문서·커밋에도 남기지 않았다.
