## 출시 범위

1. **쌤핀 AI 출결**(`e429882e`, ADR-147 추가): 교시를 밝혀 적으면 같은 날 다른 교시·같은 번호 다른 학생 기록이 지워지던 결함 → 교시 단위 병합. 미리보기도 같은 학생 판정. 실패 안내를 교사용 문장으로.
2. **AI 연결 담임 출결**(ADR-147 추가): `periods`(특정 교시만)가 그 학생의 하루 전체를 바꾸던 결함 → 넣은 교시만. 교시 없이 번호만·`allDay`+`periods` 동시·같은 학생 중복은 입력 오류로.
3. **옛 출결 사본 편집**(ADR-147 추가): 교시 목록이 없는 사본(휴대폰이 만듦)을 PC 기록 탭에서 고치면 조회·다른 교시가 사라지고 없던 1교시가 생기던 결함 → 출결부의 실제 교시로 채움, 출결부를 다 읽기 전 저장은 기다림. [되돌리기]가 조용히 실패하던 결함도 수정.
4. **자동 복원**(새, ADR-148): 원본·백업이 모두 깨진 사용자 자료를 그날 첫 실행 때의 사본으로 되돌리고 한 번 알림. 깨진 파일은 복사로 보관, 복원 기록을 먼저 쓴 뒤 교체, 구글 드라이브 동기화는 덮지 않고 '동기화 충돌' 창으로 묻기(창에 "이 기기 자료는 옛 상태로 되돌린 것" 안내), 복원 기록이 깨지면 보관본으로 다시 만들어 이어감.
5. **시작 사본 확대·보관**: 9종 추가(창을 띄운 뒤 10초 뒤부터), 파일마다 최근 7개 보존, 미래 날짜 사본 제외.
6. 자료 이름 표 하나로 통일(복원 알림·'동기화 충돌' 창).

서버 쪽 선행 조건: **없음.**

## 실기기 확인 (에이전트 대행, 2026-11-11)

로컬 `npm run build`(postbuild 3종 통과) + `electron-builder --win --publish never` 로 만든 2.5.11 설치본.

- **격리 연습 자료**(`--user-data-dir`, 개발용 연습 자료 사본·통계 끔): `todos.json`·`todos.backup.json` 을 0x00 4096바이트로 깨뜨리고 어제 날짜 사본을 두고 실행 → 깨진 두 파일이 `*.json.corrupt-<시각>` 으로 **복사 보관**, `todos.json` 이 사본 내용(658바이트)으로 교체, 할 일 화면에 사본의 할 일이 보임, `backups/restore-log` 에 항목(`written:true`) 기록. 다시 깨뜨려 켜자 토스트 「할 일 자료를 읽을 수 없어 11월 11일 오후 1시 59분 상태로 되돌렸어요. 그 뒤에 바꾼 내용은 빠졌을 수 있으니 확인해 주세요.」를 확인.
- **오너 PC**: 쌤핀을 트레이 메뉴 [완전히 종료]로 정상 종료(디버그 포트 없이 떠 있었다) → 자료 폴더 313파일 백업 → v2.5.10 위에 `/S` 설치(종료 코드 0, ProductVersion 2.5.11.0). 복원은 일어나지 않음(`restore-log` 없음 — 오너 자료는 정상), 콘솔 오류 0, 자료 11종(새 사본 대상 `students`·`assignments` 포함) 읽힘, 드라이브 동기화 받기·올리기 변동 0, 시작 사본 폴더에 새 대상 9종의 오늘 사본 생성.

## 알려진 제한과 미검증

- 자동 복원: 사본 이후 바꾼 내용은 되돌아오지 않는다. 구글 캘린더·구글 할 일의 증분 동기화가 그 사이 항목을 다시 내려받지 않을 수 있다(미확인). 학년도를 넘긴 직후 설정까지 깨지면 지난 학년도 사본으로 갈 수 있다. 구글 드라이브가 켜진 상태에서의 '동기화 충돌' 창 흐름은 자동 테스트로만 확인했다.
- AI 연결 출결은 실제 AI 도구 화면에서 확인하지 않았다(자동 테스트, 그리고 v2.5.10 때 동봉 브릿지 실경로 확인).
- 수업반 명단 자체에 학년·반이 비어 있는 학생끼리 번호가 겹치면 구별할 수 없어 한 칸으로 저장된다.
- 교시 없이 적는 "하루 전체" 출결은 그날 기록을 통째로 바꾼다(의도, 바꾸지 않음).
- macOS 실기기, 자동 업데이트 감지·설치, 두 번째 기기는 확인하지 못했다.
