## A. 신규 보드 (PIN 필수 모드 기본 ON)

- [ ] **A-1**: 도구 선택 → 실시간 담벼락 → "새 보드 만들기" 클릭
  - 보드가 정상 생성되고 기본 탭(default) 1개가 표시됨
  - 보드 설정(⚙️) → "비밀번호 입력 필수" 토글이 **ON** 상태

- [ ] **A-2**: 라이브 시작 → 공유 링크/QR 확인 → 학생 PC(또는 본인 휴대폰)에서 접속
  - 닉네임 입력란 + **PIN 입력란(숫자 4자리) 둘 다 표시**
  - PIN 미입력 상태에서 "참여하기" 버튼 클릭 → "비밀번호(숫자 4자리)를 입력해 주세요" 안내
  - PIN 입력 후 진입 → 정상 동작

- [ ] **A-3**: 같은 닉네임으로 다른 브라우저/시크릿 창에서 재접속 시도
  - 같은 PIN으로만 본인 카드 관리 가능 (다른 PIN으로는 차단되어야 함)

## B. 탭 관리 (최대 8개)

- [ ] **B-1**: 교사 화면 상단 탭 바 우측 [+] 클릭 → 탭 이름 입력 → Enter
  - 신규 탭이 추가되고 학생 화면에도 즉시 반영
  - 탭 카운터 표시(N/8) 갱신

- [ ] **B-2**: 탭을 8개까지 추가 → 9번째 시도
  - [+] 버튼이 **비활성**되고 "탭은 최대 8개까지 만들 수 있어요" 토스트 표시

- [ ] **B-3**: 탭 옆 [⋮] 메뉴 → "이름 변경" 클릭 → 새 이름 입력
  - 탭 이름이 즉시 변경되고 학생 화면도 갱신

- [ ] **B-4**: 신규 탭에 카드 작성 → 그 탭을 [⋮] → "탭 삭제"
  - **카드가 사라지지 않고 기본 탭(default)으로 자동 이동** 확인
  - 좋아요·댓글·핀 고정 상태도 보존

- [ ] **B-5**: 기본 탭(default)의 [⋮] 메뉴
  - "탭 삭제" 항목이 **없음** (보호 가드)

## C. 탭별 권한 토글

- [ ] **C-1**: 탭 [⋮] → "접근 권한" → "교사 전용" 선택
  - 교사 화면에서는 탭이 계속 보임
  - 학생 화면에서는 해당 탭이 **숨김 처리**됨

- [ ] **C-2**: 같은 탭을 다시 "전체 공개"로 토글
  - 학생 화면에서 탭이 즉시 다시 보임

- [ ] **C-3**: 보드 설정 드로어 → "탭별 권한 일괄 설정" 패널에서 한 번에 변경
  - 모든 탭에 일괄 적용 + 학생 화면 즉시 반영

## D. 엑셀(XLSX) 내보내기

- [ ] **D-1**: 카드 5개 이상 작성 → 우상단 📤 내보내기 → "XLSX" 라디오 선택
  - 닉네임 표시 ON / 현재 탭만 옵션 체크 → 다운로드
  - 다운받은 .xlsx 파일 열기 → **9칼럼 한국어 헤더** 확인:
    작성일시 · 닉네임 · 탭ID · 탭이름 · 내용 · 색상 · 좋아요수 · 댓글수 · 상태

- [ ] **D-2**: 같은 패널에서 "닉네임 표시 OFF" 토글
  - 다운받은 .xlsx의 닉네임 칼럼이 비어있거나 익명 표시

- [ ] **D-3**: "전체 탭" 옵션 선택 → 다운로드
  - 모든 탭의 카드가 하나의 .xlsx에 포함, 탭ID·탭이름 칼럼으로 구분

- [ ] **D-4**: PNG 라디오 선택 → 다운로드 → PNG 정상 출력 (회귀 X)

## E. 기존 v1.x 보드 마이그레이션

- [ ] **E-1**: 업데이트 전(v2.0.7)에 만들었던 담벼락 보드를 열기
  - 자동으로 v2 구조로 변환됨 (로딩 시 깜빡임 없음)
  - **기존 카드·좋아요·댓글·교사 하트·색상이 그대로** 보존됨

- [ ] **E-2**: 마이그레이션된 보드의 보드 설정 확인
  - "비밀번호 입력 필수" 토글이 **OFF** 상태 (기존 동작 유지)
  - 탭이 1개("default")만 존재 + 모든 기존 카드가 그 안에 배치

- [ ] **E-3**: v1.x 보드에서 신규 v2 기능 사용 시도
  - 탭 추가 / 권한 토글 / XLSX 내보내기 모두 정상 작동

## F. WebSocket 동기화 (학생 ↔ 교사)

- [ ] **F-1**: 교사가 탭 추가 → 학생 화면 1초 이내 반영
- [ ] **F-2**: 교사가 탭 삭제 → 학생 화면 카드가 기본 탭으로 자동 이동
- [ ] **F-3**: 교사가 탭 권한 변경(전체공개 ↔ 교사전용) → 학생 화면 즉시 탭 숨김/노출
- [ ] **F-4**: 학생이 카드 작성 → 교사 화면 1초 이내 반영
- [ ] **F-5**: 학생 PC를 새로고침 → 연결 정상 복구 + 카드 목록 그대로

## G. 회귀 차단 (5건 가드, 자동 + 수동)

- [ ] **G-1**: 학생 화면에 **pending 카드 누설 X** (Guard #1)
  - 보드 설정 → moderation = 'manual' → 학생 카드 작성 → 교사 승인 전까지 다른 학생 화면에 안 보임
- [ ] **G-2**: 학생 화면에 **교사 액션 버튼 누설 X** (Guard #3)
  - 카드의 편집/삭제/핀 버튼이 학생 화면에서 보이지 않음
- [ ] **G-3**: 학생이 카드 작성 버튼 더블 클릭 → **중복 카드 X** (Guard #4)
- [ ] **G-4**: 교사가 라이브 종료 → 새 라이브 시작 → **rate-limit 카운터 reset** (Guard #5)
  - 이전 세션에서 다수 카드 작성한 학생이 새 세션에서 정당하게 작성 가능

## H. 챗봇 KB 동기화 (묶음 릴리즈 4단계 KB ingest 후)

- [ ] **H-3**: "담벼락을 엑셀로 받을 수 있어?" 질문 → 9칼럼 XLSX 안내 답변
