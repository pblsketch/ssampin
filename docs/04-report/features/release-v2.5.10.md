## 출시 범위

v2.5.9 보고서 「알려진 제한과 미검증」에 남겼던 미해결 제보·별건을 해결한다(작업 문서 `.dryforge/007`).

1. **하위 할 일 글 수정·순서 바꾸기**(새 기능) — 일반 모드 목록에서 더블클릭·연필로 제자리 수정, ↑↓ 로 이동. 화면 문구 "서브태스크" → "하위 할 일".
2. **홈에서 넣은 할 일이 안 보이던 문제** — 원인은 저장 실패가 아니라 잘림(카드 20개·확장 창 50개). 방금 넣은 항목은 항상 보이고 「외 N개 · 할 일에서 모두 보기」를 표시. 아이콘 창 빠른 추가 실패 안내.
3. **구글 할 일 연동** — 바뀐 것 없이 동기화가 끝없이 반복되던 문제, 다른 목록을 고르면 옛 목록에 묶인 쌤핀 할 일이 지워지던 문제, 연동 상태 파일이 깨지면 알림 없이 꺼지던 문제(격리 후 한 번 알림).
4. **자료 파일 저장 안전장치**(ADR-146) — fsync 뒤 교체, 깨진 원본으로 백업을 덮지 않음, 잠금 오류 재시도, 읽기가 막힌 원본을 옛 백업으로 대체하지 않음, 다시 만들 수 있는 상태 파일 2종만 격리 후 초기화.
5. **AI 연결로 넣은 수업반 출결이 일부만 보이던 문제**(ADR-147) — 학년·반 보존, 교시 안에서 든 학생만 갱신, 번호만 저장된 옛 항목은 전체 명단에서 번호가 유일할 때 다시 이음, 번호가 겹치는데 학년·반이 없으면 거부.
6. **수업 교체 반쪽 남음** — 칸 우클릭 삭제가 확인 뒤 짝까지 지움, 교체 항목 수정 창은 짝 안내와 날짜·교시 잠금, 이미 생긴 반쪽은 「짝이 지워진 교체」 표시.
7. **동기화 충돌 창 [이 기기 유지] 단추**가 글자만 보이던 것(무효 투명도 수식)을 테두리형으로.

서버 쪽 선행 조건: **없음.** 앱 코드만 바뀌었다. 챗봇 KB ingest 는 공개 뒤에 한다.

### 격리된 연습 자료 (쓰기 흐름)

`win-unpacked\쌤핀.exe --user-data-dir=<임시 폴더>` 로 **오너 자료와 분리된** 폴더(개발용 연습 자료 사본, 구글 연결 정보 없음, 통계 전송 끔)에서 확인했다. 오너의 설치본은 그대로 떠 있었다.

- **상태 파일 격리**: 오너 PC 와 같은 모양(0x00 210바이트 두 개)으로 심은 `tasks-sync-state` 원본·백업이 `*.json.corrupt-<UTC 시각>` 으로 옮겨지고(지워지지 않음), 토스트 「구글 할 일 연동 설정을 읽지 못해 연동이 꺼졌어요. 할 일은 그대로예요. 설정에서 다시 켜 주세요.」가 떴다.
- **홈 할 일**: 미완료 62개에서 카드가 「외 42개 · 할 일에서 모두 보기」를 보였다. 확장 창에서 새 할 일(우선순위 없음 → 정렬상 맨 뒤)을 넣자 목록에 보이고 그 줄까지 스크롤됐으며(맨 위 요소 판정 통과), 확장 창은 「외 12개」, 닫은 뒤 카드에도 그 항목이 있었다. 디스크에 63개.
- **하위 할 일**: 더블클릭 → 입력에 포커스 → 글 바꾸고 Enter 로 저장, Esc 는 원래 글 유지, [아래로] 로 순서 변경(화면·디스크 모두 `둘째, 첫째 고침, 셋째`). 단추 12개에 한국어 aria-label, 첫 행 [위로]·끝 행 [아래로] 비활성, 포커스 시 단추 묶음이 보임.

## 알려진 제한과 미검증

- **구글 할 일 연동**: 실제 구글 계정으로 "반복 동기화가 멎는지"·"다른 목록을 골라도 지워지지 않는지"는 확인하지 못했다(자동 테스트만). 다른 목록에 묶인 할 일은 지워지지 않지만 새 목록으로 자동으로 옮겨 올라가지도 않는다.
- **AI 연결 출결**: 쌤핀이 **꺼져 있을 때** 브릿지가 직접 쓰는 경로는 여전히 그 교시를 통째로 바꾼다(브릿지 저장소·동봉 번들 미수정). 담임 출결의 "특정 교시만" 입력은 그 학생의 하루 전체를 바꾸는 기존 동작 그대로다. 실제 AI 도구(Claude 등) 화면에서의 확인은 하지 않았다.
- **번호만 저장된 옛 출결 항목**: 명단에서 번호가 겹치면 자동으로 살릴 수 없다. 출결표는 하루를 통째로 다시 쓰므로 누구 것인지 못 정한 옛 항목은 저장 시 지워진다(기존 동작).
- **수업 교체**: 교체된 칸에 [변동 추가]로 다른 변동을 덮어 등록하면 여전히 반쪽이 생긴다(이제 표시로 보인다).
- **동기화 충돌 창 단추·아이콘 창 빠른 추가 실패 안내·「짝이 지워진 교체」 표시**: 화면으로는 재현하지 못했다(자동 테스트만).
- **사용자 자료 파일이 원본·백업 모두 깨진 경우**: 여전히 오류로 멈춘다. 시작 스냅샷으로 자동 복원하는 것은 넣지 않았다(오너 판단 대기).
- **쌤핀 AI 쪽 출결 의심 결함**(특정 교시만 적어도 다른 교시 기록이 지워질 수 있음): 조사 중 보고됐으나 확인되지 않아 손대지 않았다.
- **메타 테스트 2종**(`Notice.metatest`, `teachingClassArchiveCallSites.meta`)은 이 PC 에서 단독 실행에도 기본 5초를 넘길 때가 있다(디스크 속도). 테스트는 고치지 않았다.
- macOS 실기기, 자동 업데이트 감지·설치(v2.5.9 → 2.5.10), 두 번째 기기(학교 PC)는 확인하지 못했다.
