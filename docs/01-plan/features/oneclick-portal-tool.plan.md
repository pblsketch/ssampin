## 0. 배경 한 문단

교사는 업무포털에 로그인한 뒤 나이스 복무·출장, K-에듀파인 기안·품의까지 매번 같은 3~5클릭을
반복한다. `원클릭업무포털`은 그 이동 경로를 줄여 주는 **윈도우 전용 무료 프로그램**이다.
쌤핀 사용자(교사)와 대상이 정확히 겹치고, 쌤핀이 이미 갖고 있는 "쌤도구" 카드 구조로
자연스럽게 얹을 수 있다. 다만 이 프로그램은 **쌤핀이 직접 구현할 성질이 아니다** —
아래 §2에서 그 이유를 명시한다.

## 1. 그 프로그램이 실제로 하는 일 (firsthand 확인)

- 엣지(Edge)를 **전용 프로필로 띄우고 DevTools 프로토콜로 원격 조종**한다 (`DevToolsAutomation.cs`).
  사용자가 인증서로 직접 로그인한 뒤, 프로그램이 메뉴를 대신 눌러 목적 화면까지 이동시킨다.
- 지원 진입점 6종: 나이스 / 복무(근무상황신청) / 출장(출장신청) / 에듀파인 / 기안(공용 표준서식) /
  품의(학교회계 품의등록).
- 전국 17개 시도교육청별 주소·화면 구조를 각각 대응.
- 세션 자동 연장 — 에듀파인 20분 이하 시 연장, 나이스 5분 간격.
- 스택: C#/.NET + Firebase(Firestore, Cloud Functions) + GitHub Releases 자동 업데이트.
- 로그인 정보·인증서 암호·세션 토큰은 저장하지 않는다고 명시.

**핵심 함정**: 업무포털·나이스는 주소만으로 특정 화면에 바로 들어갈 수 없는 구조다
(로그인·인증서 관문 뒤의 프레임 기반 앱). 저 프로그램이 굳이 브라우저 원격 조종을 택한 이유가
그것이다. **"링크만 모아두면 되겠지"는 성립하지 않는다.**

## 2. 쌤핀이 직접 구현하지 않는 이유 (기각된 안)

| 항목     | 내용                                                                                                                                        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 유지보수 | 교육청 17곳 × 6개 화면의 DOM 구조가 바뀔 때마다 셀렉터 추적 필요                                                                            |
| 오탐     | 학교 PC의 백신·EDR이 원격 디버깅 포트를 매크로로 차단할 소지                                                                                |
| 정책     | 세션 자동 연장은 근무 시스템 세션 정책을 우회하는 성격 — 교육청과 충돌 여지                                                                 |
| 저작권   | 소스는 공개돼 있으나 **LICENSE 파일이 없고 "All rights reserved" 표기.** 라이선스 없는 공개 소스는 복제·2차저작 불가. 코드 참고 자체가 불가 |

→ 결론: **쌤핀은 입구만 제공하고, 어려운 부분은 원 저작자 프로그램이 계속 맡는다.**

## 3. 설계 — 기존 구조 그대로 재사용

쌤핀에는 **외부 링크형 쌤도구 카드**가 이미 있다. `ToolDefinition.externalUrl` 필드가 그것으로,
현재 `tool-supsori`(숲소리), `tool-pblsketch`(PBL스케치), `tool-dorms`(DoRms) 3장이 이 방식이다.

- 정의: `src/adapters/constants/toolDefinitions.ts` — `externalUrl` 필드
- 그리드 렌더: `src/adapters/components/Tools/ToolsGrid.tsx:280` — `externalUrl`이면 `openExternal`,
  아니면 내부 라우팅. `open_in_new` 아이콘 자동 표시
- 위젯: `src/widgets/items/FavoriteTools.tsx:22` — 즐겨찾기 도구 위젯이 `externalUrl`을 이미 처리

즉 **위젯카드는 따로 만들 필요가 없다.** 쌤도구 카드로 등록하면
「쌤도구 즐겨찾기」 위젯에 자동으로 뜬다. 별도 전용 위젯을 새로 만들면 오히려 중복이다
(§5 참조).

### Phase 1 — 카드 1장 (착수 가능, 반나절 미만)

`toolDefinitions.ts`와 `ToolsGrid.tsx` 두 곳에 동일 항목 추가:

```ts
{
  id: 'tool-oneclick-portal',
  name: '원클릭업무포털',
  icon: '🚪',                       // 확정 전 — 프론트엔드 디자인 에이전트와 협의 필요
  color: 'bg-slate-600/20 text-slate-700',
  externalUrl: 'https://원클릭업무포털.com',
}
```

- 한글 도메인은 그대로 써도 된다. `new URL()`이 punycode로 정규화하므로
  `electron/main.ts:4096`의 `shell:openExternal` https 화이트리스트를 통과한다.
  (검증: `new URL('https://원클릭업무포털.com/').href` → `https://xn--py2b01a35uq4au21ay7an4j.com/`)
- `ToolsGrid.tsx` 쪽 항목에는 `description`이 필요하다. 예: "업무포털·나이스·에듀파인 화면까지 한 번에".
- 설명 문구에 **"쌤핀이 만든 기능이 아니라 외부 프로그램"** 임이 드러나야 한다.
  카드 설명 또는 `badge`로 '외부' 표기 검토.

### Phase 2 — 설치돼 있으면 바로 실행 (쌤핀 단독 가능, 1~2일)

배포는 **Velopack**이다 (packId `OneClickPortal`, mainExe `OneClickPortal.exe`, per-user 설치).
자동 업데이트가 내부 폴더를 갈아치우므로 **경로 하드코딩 금지**. 탐지는 레지스트리
`HKCU` → `Software/Microsoft/Windows/CurrentVersion/Uninstall/OneClickPortal`의
`InstallLocation`으로 한다. 상세는 분석서 §4.

- `electron/main.ts:4109`의 `shell:openPath`는 임의 `.exe` 실행을 의도적으로 거부한다
  (허용: dialog 핸들 / userData·downloads·documents·desktop·home·temp 하위 / 존재하는 디렉토리).
  이 방어를 유지한 채 **이 프로그램 하나만** 여는 전용 IPC를 판다.
- **렌더러는 경로를 넘기지 않는다.** "원클릭업무포털을 열어달라"는 의도만 보내고,
  경로 결정은 전적으로 메인이 레지스트리에서 한다. 렌더러가 경로를 정하면 임의 실행 구멍이 된다.
- 실행 파일명이 `OneClickPortal.exe`인지 검증한 뒤에만 실행. 미설치·실패 시 Phase 1로 폴백.
- 그쪽에 단일 인스턴스 처리가 없다 → 이미 실행 중이면 중복 실행하지 말고 안내만 한다.
- **선행 확인 필요**: 실제 `InstallLocation` 값과 exe 위치는 실기 설치로 봐야 한다.
  코드만 보고 단정하지 말 것.

### Phase 3 — 저작자에게 URI 스킴 요청 (가장 가치 큼, 그쪽 협조 필요)

**핵심 제약**: 그 프로그램은 명령줄 인자를 받지 않고(`Main()` 무인자) URI 스킴도 없다.
따라서 Phase 2까지 해도 **"복무 카드를 누르면 복무 화면까지"는 불가능**하다.
카드를 6장 만들어도 전부 같은 동작(프로그램 실행)이 된다. → **카드는 1장으로 족하다.**

저작자가 `oneclickportal://leave` 같은 URI 스킴을 등록해 주면 그때 카드 6장이 의미를 갖는다.
코드가 오가지 않으므로 저작권이 완벽히 보호되고, 쌤핀은 `openExternal` 한 줄이면 되며,
`.exe` 실행 방어를 아예 건드리지 않아도 된다. 상세는 분석서 §5.
**동의 회신을 받은 뒤에 제안한다** (지금 한꺼번에 요구하지 않는다).

## 4. 선행 조건 — 저작자 동의 ✅ 완료

**2026-08-21 동의 확보 완료.** 저작자(청완초 온영범 선생님)께 직접 문의해 승낙받았다.
Phase 1뿐 아니라 **Phase 2(설치돼 있으면 직접 실행)까지 동의**를 받았고,
표기 문구·아이콘에 대한 별도 조건은 제시되지 않았다.

> 사적 연락 내용은 이 공개 저장소에 옮기지 않는다. 문의 초안도 커밋하지 않는다.

법적으로 링크 자체는 문제 삼기 어렵지만, 쌤핀이라는 다른 제품 안에 남의 프로그램을 상설 노출하는
것이므로 사전 양해가 맞다.

## 5. 하지 않기로 한 것

- **전용 위젯 신설 금지** — 위젯은 "지금 상태를 보여주는 것"이 강점인데 이 기능은 표시할 상태가 없다.
  버튼 나열이 전부가 되어 기존 즐겨찾기 위젯과 중복된다. 「쌤도구 즐겨찾기」 위젯 자동 노출로 충분.
- **교육청별 링크 프리셋 자동 등록 금지** — 첫 화면까지만 데려다주므로 이 도구의 가치를 재현하지
  못하면서, 즐겨찾기 목록만 어지럽힌다.
- **브라우저 자동화 직접 구현 금지** — §2.
