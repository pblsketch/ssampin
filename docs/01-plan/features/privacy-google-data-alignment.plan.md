## 범위

T1~T6 을 순서대로 한다. T7 은 오너 몫이거나 별도 승인이다.

### T1. 설정 화면 권한 표기 (작음)

- `AccountSection.tsx`: `drive.appdata` → `drive.file`, 설명은 "쌤핀이 만든 파일만(동기화 폴더·과제 제출 폴더·교무실 자료·서명 시트)".
  `userinfo.email`("연결한 계정 확인용") 줄 추가. 기존 calendar·tasks 줄은 유지.
- 확인: 실제 앱 설정 화면.

### T2. 쌤핀 AI 로 구글 자료를 보내지 않기 (중간)

1. **판정 규칙(domain)** — `domain/rules/` 에 순수 함수 `isGoogleSourcedEvent`·`isGoogleSourcedTodo`.
   - 일정: `source === 'google'`, 또는 구글에서 내용이 바뀌어 들어온 표시가 있는 것(D1).
   - 할 일: 새 표시(예: `origin: 'google'`)가 있는 것, 구글에서 내용이 바뀐 것(D1), 표시 없이 `googleTaskId` 만 있는 옛 항목(D2).
2. **표시 달기(동기화 경로)** — 구글에서 새로 가져올 때와 구글 쪽 수정이 로컬을 덮어쓸 때 표시를 단다.
   할 일은 `useTasksSyncStore.ts`(실사용 경로, 437행·458행 부근)와 `usecases/tasks/SyncTodos.ts`(`fromGoogleTask`·`mergeFromGoogle`) 둘 다.
   일정은 `SyncFromGoogle.ts` 의 `mergeKeepingIdentity`.
3. **모델로 가는 자료** — `get_events`·`get_my_todos`·`get_week_overview` 와 정규식 경로(`buildTodos` 등)에서
   구글 자료를 **원본·개수 모두** 뺀다. 개수도 가공 데이터라 규정 대상이다.
4. **화면 카드** — 구글 자료는 카드에 따로 묶어 보여 준다("구글에서 가져온 일정 — AI에게는 보내지 않았어요").
   카드와 모델이 같은 숫자를 본다는 원칙(P5)의 **의도된 예외**로 주석·테스트에 남긴다.
5. **모델에 주는 안내** — 구글 연동이 켜져 있으면 **항상 같은 고정 문장**("구글에서 가져온 항목은 화면에만 표시돼
   이 목록에 없다. 전부라고 단정하지 말 것")을 붙인다. 실제로 있는지·몇 건인지는 보내지 않는다(그것도 가공 데이터다).
   이 문장은 선생님 설정에서 나온 것이지 구글 자료에서 나온 것이 아니다.
6. **디자인** — 카드의 구글 묶음 표시는 디자인 에이전트와 함께 정한다(작업 규칙).
7. **테스트** — 판정 규칙 단위 테스트, 모델로 가는 요청에 구글 항목 0건(개수 포함)을 고정하는 테스트, 동기화 경로 표시 테스트.

### T3. 옛 버전 대응 — 서버 (D3)

- 새 버전 앱은 요청에 "구글 자료를 뺐다"는 표시 키를 싣는다.
  `_shared/assistRequest.ts` 는 **모르는 키를 400 으로 거절**하므로 서버가 먼저 이 키를 받아들이게 배포한 뒤 앱을 출시한다.
- 게이트(환경변수로 켬): 표시 키가 없는 요청의 `get_events`·`get_my_todos`·`get_week_overview` 결과를 버리고,
  모델에게 "앱을 업데이트해야 일정·할 일을 볼 수 있다"고 안내한다. 새 버전 출시 뒤에 켠다.
- 서버 배포는 오너 승인.

### T4. 연결 해제 시 서버 토큰 삭제 (중간)

1. **서버** — 본인 확인(구글 access token → userinfo, `save-teacher-token` 과 같은 방식) 뒤
   `teacher_tokens` 의 본인 행과 본인이 관리자인 `staffroom_admin_tokens` 행을 지운다.
   새 함수로 둘지 기존 함수에 삭제를 더할지는 구현 때 정한다.
2. **앱** — 연결 해제 순서를 **서버 삭제 → 구글 폐기 → 로컬 삭제**로 바꾼다(폐기 뒤에는 본인 확인을 못 한다).
   서버 삭제나 구글 폐기가 실패하면 조용히 넘기지 않고, 인터넷 확인과 구글 계정 권한 페이지 안내를 띄운다.
3. **서버 안전망** — 토큰 갱신이 `invalid_grant`(폐기됨)로 실패하면 그 행을 지운다(`submit-assignment`,
   `_shared/staffroomDrive.ts`). 오래 안 쓴 토큰 정리 기한은 D4.
4. **바뀌지 않는 것** — 교무실 관리자가 연결을 해제하면 부서 자료실이 멈추는 것은 지금도 같다(폐기 때문).
   다시 연결하고 부서를 열면 새 토큰이 올라가 복구된다(`pushAdminToken`). 과제 수합도 같다(`pushTeacherToken`).
5. **테스트** — 해제 순서·실패 안내 단위 테스트, 서버 함수 검증 로직 테스트, 배포 뒤 실제 호출로 행 삭제 확인.
6. 서버 배포는 오너 승인.

### T5. 앱 안 안내 문구
