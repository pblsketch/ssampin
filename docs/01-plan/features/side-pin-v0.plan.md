# 옆핀(SidePin) 보기 모드 기획 v0.2 — 보관본

- 상태: v0.4 확정 기획서로 대체됨
- 작성일: 2026-08-12
- 구현 여부: 구현하지 않음
- 대상 제품: 쌤핀(SsamPin) Windows 데스크톱 앱

> 최종 기준 문서: [옆핀 v0.4 확정 기획서](./side-pin.plan.md)  
> 아래 내용은 초기 아이디어와 변경 과정을 보존한 v0.2 기록이며, 구현 기준으로 사용하지 않는다.

## 1. 한 줄 정의

**옆핀은 화면 오른쪽 가장자리에 접혀 있다가 필요할 때 펼쳐 보는 빠른 보기 패널이다.**

기존 위젯 모드와 메모 페이지를 하나의 작은 창 안에서 재사용하되, 사용 목적은 분리한다.

- 위쪽: 위젯 카드를 빠르게 확인하는 영역
- 아래쪽: 메모만 모아 보는 영역

옆핀은 새로운 대시보드나 새로운 작업 공간이 아니다. 현재 작업을 가리지 않으면서 쌤핀의 정보를 잠깐 확인하고 다시 닫는 보조 화면이다.

## 3. 이름 검토

### 3.1 옆핀을 추천하는 이유

`옆핀`은 쌤핀의 브랜드인 ‘핀’과 자연스럽게 이어지고, 화면 옆에 고정해 두었다가 꺼내 보는 기능이라는 인상을 짧게 전달한다.

쌤핀 안에서 독립적인 기능 이름으로 사용할 수 있고, 기존 브랜드의 ‘핀’ 체계와도 일관된다.

### 3.2 보완해야 할 점

`옆핀`만 단독으로 쓰면 처음 보는 사용자는 기능을 바로 알기 어려울 수 있다. 첫 노출과 설정 화면에서는 설명을 함께 사용한다.

- 메뉴: `옆핀`
- 첫 안내: `옆핀 · 화면 오른쪽에서 여는 빠른 보기`
- 설정 설명: `화면 오른쪽 가장자리에서 위젯과 메모를 빠르게 확인합니다.`
- 주요 버튼: `옆핀 열기`, `옆핀 고정`, `옆핀 설정`

이름·문구·화면 구조·코드는 쌤핀의 제품 언어와 디자인 시스템으로 만든다.

## 4. 제품 경계

### 옆핀에 포함하는 것

- 현재 쌤핀에 등록된 위젯 중 사용자가 선택한 카드의 요약 확인
- 위젯 카드의 기존 제목·상태·핵심 값·색상 체계 재사용
- 최근 메모 또는 사용자가 고정한 메모 목록 확인
- 메모를 새로 작성하고 기존 메모의 본문을 편집
- 기존 메모 편집기에서 지원하는 색상·글자 크기·이미지·삭제·보관 동작
- 메모를 클릭해 쌤핀의 메모 화면 또는 옆핀 편집 화면으로 이동
- 위젯 카드의 관련 기능을 클릭해 기존 쌤핀 화면으로 이동
- 오른쪽 가장자리 접힘, 호버 펼침, 수동 고정, 단축키 열기
- 모니터 선택과 패널 너비 설정

### 옆핀에 포함하지 않는 것

- 기존 위젯 모드 전체를 복제한 편집 화면
- 옆핀 안에서의 위젯 추가·삭제·자유 배치
- 메모와 위젯을 한 목록에 섞는 통합 피드
- 새로운 메모 저장소나 별도 위젯 데이터 저장소
- 화면 전체를 덮는 새 대시보드

옆핀에서 위젯 설정이 필요하면 `옆핀 설정` 또는 기존 메인 화면으로 보내되, 메모는 옆핀 안에서 작성·편집할 수 있어야 한다. 메모 편집 중에는 자동 접힘을 멈추고 입력에 집중할 수 있게 한다.

## 5. 화면 구조

### 5.1 접힌 상태

화면 오른쪽 끝에 폭이 작은 손잡이를 둔다. 손잡이는 두 영역을 구분해 위쪽은 위젯, 아래쪽은 메모로 인식할 수 있게 한다.

```text
화면 오른쪽 끝
┌──────┐
│ ▦    │  위젯 영역 손잡이
│      │
│ ───  │  영역 구분선
│ ▤    │  메모 영역 손잡이
└──────┘
```

손잡이는 항상 넓게 노출하지 않는다. 기본 폭은 12~16 DIP로 시작하고, 사용자가 쉽게 찾을 수 있도록 충분한 마우스 히트 영역을 별도로 확보한다. 손잡이를 눌렀을 때는 해당 영역을 고정해서 연다.

### 5.2 펼친 상태

```text
┌────────────────────────────┐
│ 옆핀             [고정] [⋯] │
├────────────────────────────┤
│ 위젯                         │
│ ┌──────────┐ ┌──────────┐  │
│ │ 시간     │ │ 일정     │  │
│ │ 핵심 값  │ │ 핵심 값  │  │
│ └──────────┘ └──────────┘  │
│                             │
├──────────── 영역 구분선 ────┤
│ 메모                         │
│ ┌────────────────────────┐  │
│ │ 고정 메모 제목          │  │
│ │ 메모 미리보기           │  │
│ └────────────────────────┘  │
│ ┌────────────────────────┐  │
│ │ 최근 메모 제목          │  │
│ │ 메모 미리보기           │  │
│ └────────────────────────┘  │
└────────────────────────────┘
```

권장 초기 치수는 다음과 같다.

- 펼친 너비: 360~420 DIP
- 최소 너비: 320 DIP
- 최대 너비: 460 DIP
- 높이: 현재 모니터의 작업 영역 전체 높이
- 위젯 영역: 전체 높이의 약 60%
- 메모 영역: 전체 높이의 약 40%

초기 버전은 위젯·메모 영역의 높이를 고정하고, 실제 사용 데이터가 쌓인 뒤 구분선 드래그를 추가한다. 처음부터 자유 조절을 허용하면 저장할 값과 예외 상태가 늘어나므로 핵심 경험을 먼저 검증한다.

## 6. 동작 설계

### 6.1 상태

| 상태          | 화면                               | 진입                                                  | 이탈                               |
| ------------- | ---------------------------------- | ----------------------------------------------------- | ---------------------------------- |
| `collapsed`   | 오른쪽 손잡이만 표시               | 앱 시작, 자동 접힘                                    | 위젯/메모 손잡이 호버·클릭, 단축키 |
| `widget-peek` | 위젯 영역이 펼쳐짐                 | 위젯 손잡이에 호버                                    | 패널 밖으로 이동 후 지연 시간 경과 |
| `memo-peek`   | 메모 영역이 펼쳐짐                 | 메모 손잡이에 호버·클릭                               | 패널 밖으로 이동 후 지연 시간 경과 |
| `open`        | 두 영역을 모두 확인                | 단축키, 손잡이 클릭, 고정 해제 전환                   | 닫기, `Esc`, 바깥 클릭             |
| `pinned`      | 사용자가 클릭으로 고정한 영역 유지 | 위젯 영역 클릭, 메모 영역의 고정 버튼, 전체 고정 버튼 | 고정 해제 후 닫기                  |

두 영역은 탭으로 교체하지 않는다. 위젯 영역을 열었다고 메모 영역이 사라지지 않고, 메모 영역을 열었다고 위젯 카드가 메모 목록으로 섞이지 않는다. 자동 호버로 펼쳐진 영역은 마우스가 떠나면 접히지만, 해당 영역을 클릭하면 고정되어 계속 열린다. 전체 헤더의 `고정`은 두 영역을 함께 고정하는 동작으로 둔다.

### 6.2 위젯 영역

- 위젯 손잡이에 150~200ms 정도 머무르면 패널이 펼쳐진다.
- 위젯 손잡이 또는 위젯 영역의 고정 지점을 클릭하면 위젯 영역이 고정된다. 카드 실행 버튼을 클릭한 것과 혼동하지 않도록 손잡이·영역 제목·고정 아이콘에서만 고정한다.
- 기존 `WidgetCard`와 위젯 레지스트리의 데이터를 재사용한다.
- 옆핀에서는 사용자가 선택한 3~4개 카드를 기본으로 보여 준다.
- 카드가 많으면 옆핀 내부에서만 세로 스크롤한다.
- 카드의 자유 배치·크기 조절은 제공하지 않는다.
- 카드 내부의 실행 버튼은 기존 화면을 열거나 해당 기능을 실행한다.
- 마우스가 카드 위에 있는 동안에는 자동으로 닫지 않는다.
- 고정된 위젯 영역은 포인터가 패널 밖으로 나가도 유지된다.
- 카드가 현재 기능을 모두 표현하기 어렵다면 요약 카드와 `메인에서 열기`를 제공한다.

기존 설정의 `sidebar-right`는 위젯 창 안에서 카드 배치를 정하는 값이다. 옆핀의 화면 가장자리 창 자체를 나타내는 값으로 재사용하지 않는다.

### 6.3 메모 영역

- 메모 영역에는 메모만 표시한다.
- 우선순위는 `고정 메모`이며, 고정 메모가 부족하면 `최근 메모`를 채운다.
- 초기 표시 개수는 3~5개로 제한하고 내부에서만 스크롤한다.
- 메모 카드에는 제목, 짧은 미리보기, 수정 시각을 표시한다.
- 메모 카드를 클릭하면 메모 영역 안에서 해당 메모를 편집 상태로 연다.
- `메모 추가`를 누르면 기존 메모 저장소에 새 메모를 만들고, 메모 영역 안에서 바로 작성한다.
- 기존 `MemoEditor`의 본문 편집, 색상 변경, 글자 크기, 이미지 첨부, 삭제, 보관 동작을 옆핀에서도 제공한다.
- 편집 중에는 옆핀의 자동 접힘과 호버 상태 변경을 멈춘다.
- 저장·편집 취소 후에는 메모 목록으로 돌아오며 옆핀은 열린 상태를 유지한다.
- 메모를 메인 화면에서 크게 보고 싶을 때 사용할 수 있도록 `메인에서 열기`도 제공한다.
- 위젯 영역의 스크롤과 메모 영역의 스크롤은 서로 영향을 주지 않는다.

메모 편집은 별도 창을 새로 만들지 않고 메모 영역이 편집 화면으로 전환되는 방식으로 둔다. 패널 폭은 기존 `MemoEditor`가 사용할 수 있는 360~420 DIP를 보장하고, 입력 중에는 포커스와 키보드 단축키가 메모 편집기에 머물러야 한다.

### 6.4 호버와 포커스

- 호버만으로 메인 창의 포커스를 빼앗지 않는다.
- 호버 펼침은 `showInactive` 성격으로 처리하고, 명시적으로 클릭했을 때만 포커스를 옮긴다.
- 펼침 지연은 150~200ms, 접힘 지연은 300~500ms부터 검증한다.
- 위젯 영역 또는 전체 패널을 클릭해 고정한 상태에서는 마우스가 벗어나도 닫히지 않는다.
- 메모를 작성·편집하는 동안에는 메모 영역을 자동으로 닫지 않는다.
- `Esc`는 고정되지 않은 옆핀을 닫는다.
- 패널 안에 포인터가 있거나 카드의 실행 동작을 처리하는 동안에는 닫지 않는다.
- 키보드 사용자는 단축키로 `open` 상태에 진입하고, `Tab`으로 위젯과 메모 영역을 이동한다.

호버는 빠른 확인을 위한 동작이고, 위젯 영역 클릭은 계속 열어 두기 위한 고정 동작이다. 단축키와 전체 고정 버튼은 두 영역을 함께 사용할 때의 보조 진입 방법이다.

## 7. 정보 선택 정책

### 위젯

옆핀에 표시할 위젯은 전체 위젯 설정과 별도로 선택·순서를 저장한다.

- 기본값: 현재 위젯 모드에서 보이는 카드 중 첫 3개
- 사용자가 옆핀에서 볼 카드를 직접 선택
- 위젯 삭제·추가·전체 배치는 메인 설정에서 처리
- 잠금이 필요한 카드의 기존 보호 규칙을 유지
- 학생 기록 등 민감할 수 있는 데이터는 기본 목록에서 제외하는 정책을 검토

### 메모

메모 목록은 별도 복제하지 않고 현재 메모 저장소의 조회 결과를 사용한다.

- 기본 모드: 고정 메모 우선
- 대안 모드: 최근 수정 메모
- 고정 메모가 없으면 최근 메모로 빈 공간을 채움
- 메모 본문 전체를 미리 로드하지 않고 필요한 미리보기만 표시
- 개인정보·학생 관련 메모가 있는 경우 앱 잠금 상태와 연동해 내용을 가림

## 8. 기존 쌤핀 모드와의 관계

```text
현재 앱 상태
main / widget / icon 중 하나
              │
              └── 옆핀은 별도로 열리고 닫히는 보조 창
                  ├── 위젯 영역
                  └── 메모 영역
```

옆핀을 `WindowMode`에 추가하지 않는 이유는 `WindowMode`가 현재 앱의 주요 화면을 서로 바꾸는 값이기 때문이다. 옆핀을 그 목록에 넣으면 메인·위젯·아이콘 중 하나를 대체하는 모드처럼 보이고, 기존 전환 로직과 창 수명 관리가 복잡해진다.

옆핀은 다음과 같이 동작해야 한다.

- 메인 창을 보고 있어도 열 수 있음
- 위젯 창을 사용 중이어도 열 수 있음
- 아이콘 모드에서도 설정된 경우 열 수 있음
- 메인·위젯·아이콘 창의 내용을 새로 저장하거나 복제하지 않음
- 작업 표시줄에 별도 앱 항목을 만들지 않음

## 9. 쌤핀에 최적화된 구조

### 9.1 도메인 계층

새로운 화면 상태와 저장 규칙을 외부 기술과 무관하게 정의한다.

권장 개념:

- `SidePinZone`: `widget | memo`
- `SidePinVisibility`: `collapsed | widget-peek | memo-peek | open | pinned`
- `SidePinSettings`: 사용 여부, 모니터, 너비, 고정·자동 접힘, 위젯 선택, 메모 정렬 기준
- `normalizeSidePinSettings`: 이전 설정·잘못된 값·범위를 안전한 기본값으로 정리
- `clampSidePinWidth`: 최소·최대 너비 보장
- `shouldCollapseOnPointerLeave`: 고정 상태와 포인터 상태를 반영한 접힘 규칙

저장 설정과 실행 중인 상태를 분리한다.

```ts
type SidePinSettings = {
  enabled: boolean;
  displayId?: string;
  panelWidth: number;
  autoHide: boolean;
  defaultZone: 'widget' | 'memo' | 'both';
  pinnedZone: 'none' | 'widget' | 'memo' | 'both';
  widgetItemIds: string[];
  memoScope: 'pinned-first' | 'recent';
};

type SidePinRuntime = {
  visibility: 'collapsed' | 'widget-peek' | 'memo-peek' | 'open';
  hoverZone?: 'widget' | 'memo';
  pointerInside: boolean;
  pinnedZone: 'none' | 'widget' | 'memo' | 'both';
};
```

위 타입은 구현 코드가 아니라 기획 단계의 계약이다. 실제 필드명은 기존 `Settings` 구조와 저장 마이그레이션 규칙을 확인한 뒤 확정한다.

### 9.2 유스케이스 계층

화면이나 Electron API가 직접 상태를 바꾸지 않도록 다음 행동을 유스케이스로 분리한다.

- `ToggleSidePin`: 옆핀 열기·닫기
- `RevealSidePinZone`: 위젯 또는 메모 영역 펼치기
- `HideSidePin`: 자동 접힘·수동 닫기
- `SetSidePinPinned`: 고정 상태 변경
- `SetSidePinItems`: 위젯 선택·순서 저장
- `BuildSidePinSnapshot`: 현재 위젯·메모 데이터를 옆핀용 읽기 모델로 조합
- `OpenSidePinTarget`: 카드·메모 클릭을 기존 화면 이동 명령으로 변환

옆핀은 데이터를 소유하지 않는다. 기존 위젯 설정과 메모 저장소를 읽어 옆핀에 맞는 요약만 만든다.

### 9.3 어댑터 계층

권장 컴포넌트 구조:

```text
src/adapters/components/SidePin/
├── SidePinApp
├── SidePinRail
├── SidePinPanel
├── SidePinWidgetZone
├── SidePinMemoZone
├── SidePinZoneDivider
└── SidePinSettingsPanel
```

- `SidePinApp`: 옆핀 전용 렌더러 진입점
- `SidePinRail`: 접힌 상태의 위젯·메모 손잡이
- `SidePinPanel`: 펼친 창의 공통 외곽과 상태 전환
- `SidePinWidgetZone`: 기존 위젯 선택기와 `WidgetCard` 재사용
- `SidePinMemoZone`: 기존 메모 조회 결과와 `MemoCard`·`MemoEditor`를 메모 전용으로 표시
- `SidePinZoneDivider`: 영역 구분과 향후 높이 조절 지점
- `SidePinSettingsPanel`: 1차에서는 메인 설정에서 열어도 되며, 옆핀 내부 추가는 후순위

`WidgetCard`를 복사해 `SidePinWidgetCard`를 별도로 만드는 대신, 카드가 `compact`, `readOnly`, `surface` 같은 표시 의도를 받을 수 있는지 먼저 검토한다. 표시만 다른 경우 기존 카드와 공통 프레젠테이션을 사용한다.

### 9.4 인프라 계층

Electron의 큰 메인 파일에 모든 동작을 더하지 않고 옆핀 창 책임을 별도 모듈로 분리한다.

권장 모듈:

```text
electron/
├── sidePinWindow.ts
├── sidePinGeometry.ts
└── sidePinIpc.ts
```

- `sidePinWindow`: 하나의 옆핀 `BrowserWindow` 생성·표시·숨김·수명 관리
- `sidePinGeometry`: 모니터 작업 영역을 받아 접힌·펼친 위치 계산
- `sidePinIpc`: 렌더러와 메인 프로세스 사이의 명령 검증과 전달

창 위치 계산은 화면의 절대 좌표를 저장하지 않는다. 선택된 모니터의 `workArea`와 DIP 너비를 기준으로 매번 오른쪽 끝을 다시 계산한다. 모니터가 제거되면 기본 모니터 또는 현재 유효한 모니터로 자동 대체한다.

권장 IPC 명령:

- `sidePin:show`
- `sidePin:hide`
- `sidePin:toggle`
- `sidePin:reveal-zone`
- `sidePin:set-pinned`
- `sidePin:set-settings`
- `sidePin:open-main-target`

렌더러에서 `ipcRenderer`를 직접 사용하지 않고 기존의 타입이 있는 preload 브리지를 확장한다. 메인 프로세스는 영역 이름, 너비, 대상 식별자 등을 허용 목록으로 검증한다.

## 10. 창 동작과 Windows 세부 정책

- 옆핀은 프레임 없는 투명 보조 창으로 시작한다.
- 작업 표시줄에 별도 항목을 만들지 않는다.
- 마우스 호버 펼침은 포커스를 강제로 빼앗지 않는다.
- 명시적 클릭과 키보드 명령에서만 필요한 경우 포커스를 준다.
- `screen-saver` 수준으로 다른 전체 화면 앱을 덮지 않는다.
- 전체 화면 프레젠테이션·화면 공유 중 숨김 정책은 설정 또는 후속 단계에서 정한다.
- 모니터 추가·제거·해상도·배율 변경 시 위치를 다시 계산한다.
- 앱 잠금·Windows 잠금·절전 복귀 후에는 민감한 메모가 노출되지 않도록 현재 잠금 정책과 연결한다.
- 앱을 다시 시작해도 사용자가 선택한 모니터·너비·위젯 목록·고정 상태를 복원한다.

특히 다중 모니터와 배율 125% 환경에서 오른쪽 가장자리 밖으로 밀리거나, 화면 좌표가 음수인 보조 모니터에서 반대쪽에 나타나는 문제가 주요 위험이다. 위치 계산은 순수 함수로 분리해 테스트한다.

## 11. 설정과 첫 사용

설정 위치는 기존 위젯 설정과 가까운 곳에 `옆핀` 섹션으로 둔다.

1. 앱을 시작하면 오른쪽 가장자리에 접힌 옆핀 손잡이가 표시된다.
2. 사용할 모니터를 선택한다.
3. 옆핀에서 볼 위젯 카드를 고른다.
4. 메모 표시 기준을 `고정 메모 우선` 또는 `최근 메모`로 선택한다.
5. 필요하면 `옆핀 고정`과 단축키를 설정한다.

옆핀의 기본 상태는 **접힌 손잡이 표시**다. 접힌 상태에서는 메모 내용이나 위젯 카드가 화면에 노출되지 않으므로 상시 노출 부담을 줄일 수 있다. 사용자는 설정에서 옆핀을 완전히 끌 수 있고, 처음 한 번만 `오른쪽 가장자리의 손잡이에 마우스를 올리면 위젯을 볼 수 있습니다`라는 안내를 받는다.

## 13. 수용 기준

### 핵심 경험

- [ ] 옆핀을 켜면 지정 모니터의 오른쪽 가장자리에 접힌 손잡이가 나타난다.
- [ ] 위젯 손잡이에 머무르면 기존 위젯 카드 기반의 위젯 영역이 펼쳐진다.
- [ ] 위젯 손잡이 또는 위젯 영역의 고정 지점을 클릭하면 위젯 영역이 계속 열린다.
- [ ] 메모 손잡이 또는 메모 영역을 열면 메모만 보인다.
- [ ] `메모 추가`로 새 메모를 작성하고 저장할 수 있다.
- [ ] 기존 메모를 옆핀 안에서 편집하고 색상·글자 크기·이미지·삭제·보관 동작을 수행할 수 있다.
- [ ] 위젯 영역과 메모 영역의 스크롤이 서로 섞이지 않는다.
- [ ] 패널 밖으로 이동하면 고정되지 않은 옆핀이 지연 후 접힌다.
- [ ] 메모 작성·편집 중에는 패널 밖으로 이동해도 자동 접히지 않는다.
- [ ] 고정하면 마우스가 벗어나도 패널이 유지된다.
- [ ] 메모·위젯 카드를 클릭하면 기존 쌤핀 화면을 재사용해 해당 대상으로 이동한다.

### 기존 기능 보호

- [ ] 옆핀을 켜도 기존 `main`, `widget`, `icon` 모드 전환이 깨지지 않는다.
- [ ] 기존 위젯 카드 설정·순서·잠금 규칙이 원래 화면에서 유지된다.
- [ ] 메모 데이터가 옆핀용으로 중복 저장되지 않는다.
- [ ] 작업 표시줄에 옆핀용 중복 앱 창이 생기지 않는다.
- [ ] 옆핀을 끄면 기존 앱 동작은 옆핀 도입 전과 같다.

### 환경·보호

- [ ] 단일 모니터와 다중 모니터에서 오른쪽 작업 영역 안에 정확히 배치된다.
- [ ] 100%, 125%, 150% 배율에서 패널이 화면 밖으로 밀리지 않는다.
- [ ] 다른 앱을 사용하는 중 호버만으로 포커스를 빼앗지 않는다.
- [ ] 앱 잠금·화면 공유 정책에 따라 메모가 보호된다.
- [ ] `npx tsc --noEmit`, `npm run lint`, `npm run test`, `npm run regression-check` 결과를 기록한다.

## 15. 최종 권고

`옆핀`은 좋은 이름이다. 다만 이름만으로 기능을 설명하려고 하지 말고, 첫 노출에서는 `화면 오른쪽에서 여는 빠른 보기`라는 설명을 붙인다.

구조는 **하나의 오른쪽 보조 창 안에 위젯 영역과 메모 영역을 독립적으로 배치하는 방식**이 쌤핀에 가장 적합하다. 기존 위젯 모드와 메모 페이지를 새로 복제하지 않고, 위젯 카드·설정·메모 저장소·메모 편집기를 재사용한다. 옆핀 자체는 기존 모드를 대체하지 않는 별도 기능으로 유지한다.

첫 구현 범위는 다음으로 제한하는 것이 안전하다.

1. 앱 시작부터 보이는 접힌 오른쪽 손잡이
2. 위젯 영역 호버 펼침과 클릭 고정
3. 메모 전용 영역과 독립 스크롤
4. 옆핀 안에서 메모 작성·편집
5. 카드·메모 클릭 시 기존 화면으로 이동
6. 고정, 단축키, 모니터 선택

구분선 드래그와 옆핀 안에서의 전체 위젯 편집은 실제 사용 데이터를 확인한 뒤 다음 범위로 미룬다. 메모 작성·편집은 1차 범위에 포함한다.

이 문서는 기획 산출물만 추가하며, 기능 코드·설정 데이터·기존 문서는 변경하지 않는다.
