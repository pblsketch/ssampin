# 쌤핀 개발 (Codex)

1. 루트의 `docs/agent-workflow.md`를 읽고 순서대로 실행한다.
2. 승인 설계와 현재 파일을 읽는다. 작은 변경은 직접, 여러 레이어는 순차 구현한다.
3. 현재 런타임의 도구·역할만 사용하고 모델은 부모 설정을 상속한다. 분석·리뷰만 병렬로 위임한다.
4. 주 에이전트가 변경 범위·실제 동작·필수 검사 4종 결과를 확인한다. 하위 에이전트 PASS만으로 완료하지 않는다.
5. 릴리즈 요청은 `docs/release-workflow.md`를 따른다.

중간 산출물은 `_workspace/`, 결정은 `docs/03-decisions/`, 검증 기록은 `docs/progress/`에 남긴다.
