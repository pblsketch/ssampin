# insta-card 디자인 스펙 (잠금)

2026-08 쌤핀 '수업 관리' 카드뉴스에서 사용자가 채택한 스타일이다. **임의 변경 금지.**
레퍼런스는 인스타 `ai.asap.kr` 계열 — 검은 배경, 큰 한글 타이포, 실제 화면.

## 1. 규격

- **1080 × 1350 (4:5)** — 인스타 캐러셀에서 세로를 가장 크게 먹는 비율
- 좌우 여백 66px
- 영상 슬라이드도 같은 규격 / 30fps / H.264 / yuv420p / 음성 없음

## 2. 배경

```css
radial-gradient(1000px 620px at 50% 30%, rgba(37,99,235,.16), transparent 62%),
radial-gradient(760px 520px at 50% 8%,  rgba(245,158,11,.09), transparent 60%),
linear-gradient(180deg, #05070c 0%, #05070c 46%, #080d16 78%, #0a1120 100%)
```

아래쪽 560px에는 검은 그라디언트를 한 겹 더 깔아 글자 대비를 지킨다.

## 3. 세로 배치

| 영역        | 위치               | 내용                           |
| ----------- | ------------------ | ------------------------------ |
| 페이지 표시 | top 56, right 66   | `01 / 06`, 21px/600, 흰색 30%  |
| 화면 영역   | top 84, height 620 | 크롭 이미지 (세로 가운데 정렬) |
| 카피        | top 740            | 아이브로우 → 제목 → 설명 목록  |
| 서명        | bottom 66, 가운데  | 브랜드명 + 한 줄 소개          |

마무리(가운데 정렬) 카드만 카피 top 770.

## 5. 색

| 역할                                          | HEX                   |
| --------------------------------------------- | --------------------- |
| 강조(아이브로우 바 · 목록 마커 · 마무리 버튼) | `#f5a524`             |
| 제목 안 강조어                                | `#7fb2ff`             |
| 배경                                          | `#05070c` → `#0a1120` |

**금지**: 이모지 장식, 3D, 사진 배경, 무지개 그라디언트.

## 6. 화면 크롭 규칙

- 모서리 18px 둥글게 + 테두리 `rgba(255,255,255,.10)` 1px + 그림자 `0 18px 44px rgba(0,0,0,.55)`
- **크롭 폭은 900~990px**. 그래야 카드에서 1:1 근처로 놓여 안 흐려진다
- 한 카드에 화면 2개까지. 나란히 놓을 때는 **높이를 맞춘다**
- 화면 위에 겹치는 알림(토스트)은 실제 앱에서처럼 오른쪽 아래에 겹쳐 놓는다

## 7. 카드 구성 (6장 기본)

| #   | 역할   | 내용                                                                   |
| --- | ------ | ---------------------------------------------------------------------- |
| 1   | 표지   | 마스코트 + 기능 목록이 보이는 탭바 크롭. 제목은 후킹, 서브는 기능 나열 |
| 2~5 | 기능   | 아이브로우=기능명, 제목=그 기능의 한 줄 가치, 목록 4줄=구체 동작       |
| 6   | 마무리 | 마스코트 크게 + 행동 유도(팔로우/좋아요/댓글 또는 링크)                |

## 8. 문장 규칙

- **평서형 종결.** "~합니다", "~됩니다". 느낌표·물음표 남발 금지
- 제목은 **2줄, 각 줄 12자 안팎**. 넘치면 줄바꿈이 깨진다
- 설명 목록은 **동작 중심**. "편리합니다"가 아니라 "엑셀을 그대로 가져옵니다"
- 강조는 줄당 1~2군데. 전부 강조하면 아무것도 안 보인다
- **확인 안 된 기능은 안 쓴다.** 형식·개수·이름은 코드에서 확인한 것만
- 과장 금지 — "혁신", "완벽", "최고" 안 쓴다

## 9. config.json 스키마

```jsonc
{
  "source": "C:/.../녹화.mp4", // 소스 영상
  "out": "docs/.../my-cardnews", // 산출 폴더 (cwd 기준)
  "brand": {
    "name": "쌤핀",
    "tagline": "선생님의 학급 운영 대시보드",
    "mascot": "pin.png", // assets/ 안 파일명. 없으면 마스코트 생략
  },

  "crops": [
    { "id": "tabs", "t": 10, "crop": "690:56:648:162" }, // w:h:x:y (원본 좌표)
  ],

  "cards": [
    {
      "eyebrow": "명렬 관리",
      "h": "나이스 엑셀 그대로<br>올리면 명단이 완성",
      "sub": "선택 — 표지·마무리에서만 쓴다",
      "bullets": [
        // 최대 4줄. <b>로 강조
        "나이스에서 받은 <b>엑셀(.xlsx)</b>을 그대로 가져오기",
      ],
      "center": false, // 마무리 카드만 true
      "steps": ["① 팔로우", "② 좋아요", "③ 댓글 '쌤핀'"], // 선택. 마지막 칩이 앰버
      "stage": {
        "layout": "column", // column | row
        "items": [
          { "type": "mascot", "size": 176 },
          { "type": "shot", "img": "tabs", "w": 944 }, // h 는 자동 계산
          { "type": "shot", "img": "seats", "w": 428, "label": "좌석배치" },
          {
            "type": "shot",
            "img": "roster",
            "w": 980,
            "overlay": { "img": "toast", "w": 392, "right": 22, "bottom": 22 },
          },
        ],
      },
    },
  ],

  "clips": [
    {
      "card": 4, // 몇 번 카드의 영상판인가 (1-base)
      "name": "좌석배치-이름학습", // 파일명에 들어감
      "start": 91,
      "dur": 17,
      "crop": "975:585:655:220",
      "blur": [
        // 선택 — 가려야 할 영역 (크롭 좌표계)
        { "x": 50, "y": 335, "w": 250, "h": 100, "from": 11.3, "to": 17 },
      ],
    },
  ],
}
```

`row` 레이아웃에서 나란히 놓는 화면은 **높이가 같아지도록 `w`를 조절한다.**
자동 계산된 높이는 `build.mjs`가 출력해 주니 보고 맞추면 된다.

## 10. 영상 슬라이드

- 길이 **10~20초**. 한 슬라이드에 동작 하나
- 크롭은 **동작이 그 안에서 다 일어나는 범위**로 잡는다. 화면이 바뀌면 구간을 나눈다
- 정지 카드와 **글자 위치·배경이 같아야** 섞어 올렸을 때 흐름이 안 끊긴다
- 소리는 뺀다 (인스타는 기본 음소거로 재생됨)
