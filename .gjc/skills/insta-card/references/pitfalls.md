## 렌더링

### Chrome 플래그 두 개는 필수다

```
--allow-file-access-from-files         # 없으면 file:// 폰트를 못 읽어 한글이 통째로 깨진다
--run-all-compositor-stages-before-draw # 없으면 큰 그림자가 있는 카드 오른쪽 아래에
                                        # 검은 사각형이 남는다 (실제로 발생)
```

`--hide-scrollbars`, `--force-device-scale-factor=1`, `--virtual-time-budget=6000`도 같이 준다.

### 투명 배경 스크린샷

마스크 PNG를 뽑을 때는 `--default-background-color=00000000`을 준다.

## ffmpeg

### 이 환경 빌드는 `-pattern_type glob`을 지원하지 않는다

```
Pattern type 'glob' was selected but globbing is not supported by this libavformat build
```

`-start_number 1 -i "cards/card-%02d.png"` 로 쓴다.

### tile 필터의 color는 6자리 hex만 받는다

`color=#333` → 파싱 실패. `color=#333333`.

### `-ss`를 `-i` 앞에 두면 키프레임 단위로 어긋난다

프레임을 정확히 집어야 할 때(정지 크롭)는 오차를 감안하고, 뽑은 결과를 **반드시 눈으로 본다.**
"몇 초에 무슨 화면"을 앞서 조사한 결과와 실제 크롭이 다를 수 있다.

### 영상 슬라이드 합성

바탕 프레임(정지 PNG) 위에 영상을 둥근 모서리로 얹는다.

```
[1:v]crop=W:H:X:Y,scale=w:h,setsar=1,fps=30[v];
[2:v]alphaextract[m];          <- 마스크 PNG의 알파를 꺼낸다
[v][m]alphamerge[va];
[0:v][va]overlay=X:Y,format=yuv420p[out]
```

- 바탕 PNG는 `-loop 1`로 넣고 `-t`로 길이를 맞춘다
- 최종 크기는 가로·세로 모두 **짝수**여야 yuv420p로 인코딩된다
- 마스크는 영상 크기와 **정확히 같아야** 한다

## 개인정보

### 사진에 이름이 그림으로 박혀 있을 수 있다

이름 학습 얼굴 카드가 그랬다. UI 텍스트가 아니라 **이미지 안에 렌더된 글자**라 크롭·확대하면 읽힌다.
작게 나오는 구간은 괜찮지만, 크게 나오는 구간은 `boxblur`로 덮는다.

```
[b][bl]overlay=50:335:enable='between(t,11.3,17)'
```

옷처럼 단색인 영역 위라면 흐리게 덮어도 티가 거의 안 난다.

### 더미 데이터라고 단정하지 않는다

명단이 `가가가`·`가나가` 더미여도, **다른 화면의 다른 데이터는 실물일 수 있다.**
실제로 사진 파일에 박힌 이름만 실명 형태였다. 화면마다 따로 확인한다.

### 늘 확인할 것

- 사이드바 교사 이름 / 담임 학급 → 크롭 시작 x를 그 오른쪽으로 잡는다
- 학교명 (파일 목록·문서 제목·설정 화면)
- 창 제목표시줄, 작업 표시줄의 다른 앱 아이콘

## 사실 확인

### 사용자가 말한 기능 사양이 틀릴 수 있다

"한글이나 PDF로 내보내기" → 실제로는 **한글(.hwpx)·엑셀(.xlsx) 두 가지, PDF 없음**이었다.
카드에 쓰기 전에 코드에서 확인한다. 틀렸으면 되는 것만 쓰고 **사용자에게 알린다.**

### 녹화 화면이 출시본과 다를 수 있다

기능 스위치로 막아 놓고 출시한 기능을, 스위치 켠 로컬 빌드로 녹화한 경우가 있었다.
버전 표시가 같아도 **출시 빌드에 그 기능이 있는지 따로 확인한다.**
없으면 만들되 게시 시점을 다음 릴리즈 뒤로 제안한다.

## 디자인

### 하단 서명과 카피가 겹친다

제목 2줄 + 설명 4줄이면 세로가 빠듯하다. 화면 영역 620px / 카피 top 740 / 서명 bottom 66이
검증된 값이다. 제목을 3줄 쓰면 넘친다 — **2줄로 줄인다.**

### 크롭 끝이 어정쩡하게 잘리면 실수처럼 보인다

버튼이나 표 행이 반쯤 걸리지 않도록 경계를 정한다. 몇 px 조절이면 된다.

### 마우스 커서가 글자 위에 얹히는 프레임을 피한다

같은 화면이라도 1~3초 뒤 프레임을 뽑으면 커서가 비켜 있다.
입력칸은 **내용이 채워진 뒤** 프레임이 훨씬 낫다(빈 placeholder보다 설득력 있음).
